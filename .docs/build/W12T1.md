## 目标

Module skeleton: declarations, sub-module placeholders, public exports。

依据 `10-iterator.md §3` 的文件位置约定（`src/iter/{mod.rs, elements.rs, axis.rs, indexed.rs}`）创建模块入口，按 §5.1 / §5.2 / §5.4 的公开 API 边界仅导出公开迭代器类型，并把 `iter` 模块接入 crate root 与 `prelude`。`StrideState` 为 §6.1 / §6.2 描述的内部实现细节，保持 `pub(crate)` 不外泄。

## 前置准备

- W8 已完成：`TensorBase`、`TensorView`、`TensorViewMut`、`shape/strides/offset/as_ptr/as_mut_ptr/is_f_contiguous/has_zero_stride` 等访问器可用（参见 `07-tensor.md §5`）。
- W11 的广播只读约束已确定（参见 `10-iterator.md §6.3`）：可变迭代器不得面向广播 view 暴露。
- `XenonError::InvalidAxis` 已由 W2 提供结构化字段 `{ operation, axis, ndim, shape }`（参见 `26-error.md §5`）。
- 本 task 仅落地模块骨架；具体类型的实现由后续 W12T2-W12T6 完成。

## 实施步骤

### Step 1: 创建 `src/iter/mod.rs` 模块入口

按照 `10-iterator.md §3` 的文件位置约定创建模块入口，仅声明三个子模块为 **占位文件**。**不**在本 task 中添加任何 `pub use` 导出：每个公开类型的 `pub use` 由 **首次落地该类型的下游 task** 自行在自己的实施步骤中追加（参考 `W1T3.md`「lib.rs 模块声明演进协议」的分担思路）。这种切法保证 W12T1 独立可编译，子模块文件为空也不会因为缺失 `pub use` 目标导致链接错误。

```rust
//! Tensor iterators.
//!
//! Defines the public iterator surface area as specified in `10-iterator.md §5`:
//! - `Iter` / `IterMut` (flat element iterators, §5.1, wired up in W12T3 / W12T4)
//! - `AxisIter` / `AxisIterMut` (axis-wise sub-view iterators, §5.2, wired up in W12T5)
//! - `IndexedIter` / `IndexedIterMut` (index-paired iterators, §5.4, wired up in W12T6)
//!
//! Entry methods on `TensorBase` (§5.5) are added in W12T7.

mod axis;
mod elements;
mod indexed;

// `pub use` re-exports are added incrementally by W12T3 / W12T4 / W12T5 /
// W12T6 when each concrete iterator type is introduced; see each task's
// Step 1 for the exact lines appended here.
```

同步创建三个空子模块占位文件，使 `cargo check` 能在 W12T1 结束时独立通过：

```rust
// src/iter/axis.rs — intentionally empty; populated by W12T5.

// src/iter/elements.rs — intentionally empty; populated by W12T2 / W12T3 / W12T4.

// src/iter/indexed.rs — intentionally empty; populated by W12T6.
```

### Step 2: 接入 crate root

按 `W1T3.md`「lib.rs 模块声明演进协议」表中 W12 / W12T1 行的要求，仅在 `src/lib.rs` 中追加 `pub mod iter;`。**prelude 的迭代器导出不在本 task 添加**：下游 task 首次落地对应公开类型时再追加 prelude 条目，使 `cargo check` 在每个阶段都成立（prelude 引用未定义类型会编译失败）。

```rust
// src/lib.rs
pub mod iter;

// prelude 保持既有状态，不在 W12T1 内追加迭代器条目。
// W12T3 追加 `Iter`；W12T4 追加 `IterMut`；W12T5 追加 `AxisIter`/`AxisIterMut`；
// W12T6 追加 `IndexedIter`/`IndexedIterMut`（与每个类型首次可命名的时点对齐）。
```

> 时序参考：`W1T3.md`「lib.rs 模块声明演进协议」只要求 W12T1 追加 `pub mod iter;`，不规定 prelude 的分批次演进；本分担方案与它兼容。

### Step 3: 单元测试

> **强制要求**:
> - 本步骤必须包含一个或者多个单元测试。
> - 测试函数名称和测试内容必须参考对应设计文档的 **「测试计划」** 一节。
> - 编译检查与Lint检查不等同于单元测试。
> - 如果测试没有通过需要修复直至测试通过。
> - **无测试 = 任务未完成。**

W12T1 仅落地模块骨架。`10-iterator.md §8.2` 的全部清单项（`test_elements_*` / `test_axis_iter_*` / `test_indexed_iter_*` / `test_tensor_iter_integration` 等）都要求已实现的公开迭代器类型，全部归属 W12T2–W12T7。本 task 在设计文档的测试计划中没有对应项，因此**不为 W12T1 伪造一条"占位"单元测试**（这会是反模式：测试要么验证真实行为，要么不存在）。

本 task 的完成判定退化为编译级验证：

- `cargo check` 在 W12T1 结束时必须通过（三个空子模块 + `pub mod iter;` 是自洽输入）；
- `cargo clippy --all-targets` 不产生新警告；
- `cargo doc --no-deps` 能生成 `xenon::iter` 模块页（此时页面为空，无类型）。

上述判定与 `10-iterator.md §7-T1`「测试: 编译通过」一致。公开类型的 trait bound 断言由 **首次落地该类型的 task** 自行覆盖：`Iter` / `IterMut` 的 `Iterator + ExactSizeIterator` 由 W12T3 / W12T4 的测试验证，`AxisIter` / `AxisIterMut` 由 W12T5 验证，`IndexedIter` / `IndexedIterMut` 由 W12T6 验证，入口方法的端到端集成由 W12T7 的 `test_tensor_iter_integration` 覆盖。

| 决策 | 依据 |

| W12T1 负责在 `src/lib.rs` 追加 `pub mod iter;`（且仅此一行） | `W1T3.md`「lib.rs 模块声明演进协议」W12 / W12T1 行 |

## 验证方式

1. 编译检查: `cargo check`（必须通过；三个空子模块 + `pub mod iter;` 是自洽输入）
2. Lint 检查: `cargo clippy --all-targets`（不产生新警告）
3. 手动验证: `cargo doc --no-deps --open` 后确认 `xenon::iter` 模块页可打开（此阶段页面为空，无公开类型；完整的 6 个公开类型入口由 W12T6 结束后才齐全，在 `cargo doc --no-deps --open` 下确认 `StrideState` 始终未出现在 public docs）。

## 注意事项

- 不在 `pub use` 中暴露 `StrideState`；它是 §6.1 / §6.2 的内部实现细节，外泄会污染 SemVer 表面（W12T2 落地时自行加 `pub(crate)`）。
- 子模块 `axis` / `elements` / `indexed` 在 W12T1 是**真正意义上的空文件**（只保留注释，无类型定义）。因此 `mod.rs` 不能含有任何 `pub use axis::...` / `pub use elements::...` / `pub use indexed::...`——这些会在链接期指向未定义符号。下游 task 的实施步骤必须显式包含"向 `mod.rs` 追加对应 `pub use`"这一条。
- `Ix0` 零维张量元素迭代必须产出恰好 1 项，不能被当作空数组（§5.1 / §8.2 `test_elements_ix0`）。
- `AxisIter` / `AxisIterMut` 对 rank-0 `IxDyn` 和极端 axis 值必须返回 `XenonError::InvalidAxis`，不能 panic（§5.2 / §8.2）。
- `IterMut` / `IndexedIterMut` 不应构造在零步长广播 view 上；§6.3 通过 `iter_mut()` 仅在 `StorageMut` 上的入口约束在编译期阻断，无需运行时检查。
