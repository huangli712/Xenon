## 目标

Module placeholder：声明 `LayoutFlags(u8)` newtype 与 `LayoutState` 三态枚举的最小类型骨架（含 derive macro），保证 mod.rs 的 `pub use flags::{LayoutFlags, LayoutState}` 可编译。

bitflag 常量、查询/设置方法、`classify()` 映射在 W6T5 中补齐；`compute_layout_flags` 在 W6T11 中实现。

参照 `docs/design/06-layout.md` §5.1（LayoutFlags 位字段）和 §5.3（LayoutState 三态语义）。

## 实施步骤

### Step 1: Create flags module placeholder

向 `src/layout/flags.rs` 写入类型骨架。注意：`LayoutState` 三个变体名必须严格匹配 `06-layout §5.3` —— `FContiguous` / `NonContiguous` / **`BroadcastView`**（不是 `Broadcast`）。

```rust
//! Layout flags and state classification (placeholder — W6T2).
//!
//! Full bitflag constants, query/setter methods, and `LayoutFlags::classify()`
//! are implemented in W6T5; `compute_layout_flags` is implemented in W6T11.

/// 8-bit packed layout flags. Concrete bit layout in `06-layout §5.1`.
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct LayoutFlags(pub(super) u8);

/// Classification of tensor memory layout contiguity (`06-layout §5.3`).
///
/// Variants are mutually exclusive. `BroadcastView` applies only when
/// `product(shape) > 0 && any(stride == 0)`; empty tensors with degenerate
/// zero strides remain `FContiguous`.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LayoutState {
    /// Fortran-contiguous: first stride = 1, F-order progression.
    FContiguous,
    /// Arbitrary non-broadcast view that is not F-contiguous.
    NonContiguous,
    /// Non-empty view with at least one zero-stride axis (broadcast).
    BroadcastView,
}
```

> 关键：内部字段使用 `pub(super) u8` 而非 `u8`，使 W6T5 在同一文件内的 `impl` 块可直接读写位字段，同时不向 layout 模块外暴露内部表示。

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_flags_default_empty() {
        // W6T2 placeholder: verify derive macros (Debug, Clone, Copy,
        // Default, PartialEq, Eq) compile. Query/set methods (`is_*` /

}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `LayoutFlags(u8)` 使用 newtype 封装位域 | `06-layout §5.1` 零依赖，O(1) 查询 |
| 内部字段 `pub(super) u8` 而非 `u8` | W6T5 在同一文件 `impl LayoutFlags` 中需直接读写位字段；同时不向 layout 模块外暴露内部表示 |
| `LayoutState` 三个变体严格使用 `FContiguous` / `NonContiguous` / `BroadcastView` | `06-layout §5.3` 显式规定；W11/W20 已按此命名编写依赖代码 |
| 不在本 task 写 `pub fn is_broadcast_view(&self)` 等查询方法 | 查询方法属于 `LayoutFlags::classify()`（W6T5）或 `TensorBase::layout_state()`（W8），不在 LayoutState 自身定义 |

## 验证方式

1. 编译检查: `cargo check -p xenon`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test layout::flags::tests::test_flags_default_empty`
4. 手动验证: 确认 struct 与 enum 的 derive macro（Debug/Clone/Copy/PartialEq/Eq/Default）正常工作，且 `LayoutState::BroadcastView` 变体名可解析。

## 注意事项

- 本 task 为 **占位符**：不实现 bitflag 常量、query/set 方法、`classify()` 映射——这些属于 W6T5。
- `#[derive(Default)]` 确保 `LayoutFlags::default()` 生成 `LayoutFlags(0)`，与 W6T5 的 `EMPTY` 常量语义一致。
- 变体名 `BroadcastView` 是设计文档 `06-layout §5.3` 与下游 W11T8/W20T3/W22 共同依赖的稳定符号，**任何重命名将打破下游 task**。
