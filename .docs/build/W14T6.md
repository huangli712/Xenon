## 目标

Float + complex dot SIMD: f32/f64/Complex<f32>/Complex<f64> dot kernel with conjugate contract。

## 实施步骤

### Step 1: Implement f32/f64 dot as vector multiply plus lane accumulation

Implement f32/f64 dot as vector multiply plus lane accumulation.

Use `get_arch()` from `mod.rs` (W14T1). Implement f32/f64 dot as vector multiply plus lane accumulation. Apply scalar tail with the same multiplication and accumulation contract. Expose typed dot facades that return `None` when threshold or admission fails.

> **参见 08-simd §6.1**：pulp 0.18 API 契约 — 使用 `simd.f32s_as_simd` / `simd.f64s_as_simd` split helpers、`f32s_mul`/`f32s_add` lane ops。
>
> **FMA 边界**：dot 主循环 mul+accumulate 禁用 FMA（保持与标量逐位一致）；仅 horizontal merge 阶段可在 W14T0 spike 确认 FMA capability bit 后受控使用，且必须注明容差边界。

### Step 2: Implement complex dot as `conj(lhs) * rhs` on split real/imag lanes

complex dot kernel 复用 W14T5 的 split accumulator 模式（real/imag 独立 lane），dot 特有的 conj+mul 封装在 dot kernel 内部，不修改 W14T5 代码。

Implement complex dot as `conj(lhs) * rhs` on split real/imag lanes. The implementation must keep AoS input handling local to the dot kernel, split real and imaginary lanes before accumulation, and recombine the final real/imag accumulators into the returned `Complex<T>` value.

```rust
// BLAS xdotc 契约: dot = sum(conj(lhs_i) * rhs_i)，对左操作数共轭；与 08-simd §6.6 L778 一致；与 12-matrix.md 互通
let product = lhs_i.conj() * rhs_i;
```

### Step 3: Apply scalar tail with the same conjugate contract

Apply scalar tail with the same conjugate contract.

The scalar tail must cover exactly the elements not consumed by the SIMD body. For float dot, the tail computes `lhs_i * rhs_i`. For complex dot, the tail computes `lhs_i.conj() * rhs_i`. The tail must preserve the same tolerance accounting as the vector body because the final merge order can differ from the pure scalar baseline.

### Step 4: Expose typed dot facades that return `None` when threshold or admission fails

Expose typed dot facades that return `None` when threshold or admission fails.

The required facades are:

- `try_dot_f32(lhs: &[f32], rhs: &[f32]) -> Option<f32>`
- `try_dot_f64(lhs: &[f64], rhs: &[f64]) -> Option<f64>`
- `try_dot_complex_f32(lhs: &[Complex<f32>], rhs: &[Complex<f32>]) -> Option<Complex<f32>>`
- `try_dot_complex_f64(lhs: &[Complex<f64>], rhs: &[Complex<f64>]) -> Option<Complex<f64>>`

Admission rules:

- f32/f64 dot 阈值 512（08-simd §5.8 L459）。
- Complex dot 阈值 = 512（来源于 `build/PLAN.md` W14 补充决策）。
- Mismatched slice lengths keep the existing dot contract: the semantic caller or facade must preserve the same panic/error behavior as the scalar path.
- If the active ISA lacks a valid SIMD width or required deinterleave support, return `None` and let the caller keep the scalar fallback.

### Step 5: 单元测试

添加覆盖设计文档测试计划的单元测试，至少包含正常路径和一个边界或回退场景。测试数据长度必须达到对应阈值，避免 `Option::None` 导致静默空跑；每个 SIMD 正常路径均需显式断言 `assert!(simd_result.is_some())`。

```rust
#[cfg(all(test, feature = "simd"))]
mod tests {
    use super::*;
    use crate::complex::Complex;

    #[test]
    fn test_dot_dispatch_simd_float_f32() {
        let lhs: Vec<f32> = (0..1024).map(|v| v as f32 * 0.25).collect();
        let rhs: Vec<f32> = (0..1024).map(|v| (v as f32 + 1.0) * 0.5).collect();
        let simd_result = try_dot_f32(&lhs, &rhs);
        assert!(simd_result.is_some(), "length 1024 must enter f32 dot SIMD admission");

        let simd = simd_result.unwrap();
        let scalar: f32 = lhs.iter().zip(rhs.iter()).map(|(l, r)| l * r).sum();
        // tolerance per 12-matrix.md §10.1 f32 dot:
        //   max(8·ε·n·max_abs_a·max_abs_b, 4·MIN_POSITIVE)
        let max_abs_a = lhs.iter().copied().map(f32::abs).fold(0.0_f32, f32::max);
        let max_abs_b = rhs.iter().copied().map(f32::abs).fold(0.0_f32, f32::max);
        let tolerance = (8.0 * f32::EPSILON * (lhs.len() as f32) * max_abs_a * max_abs_b)
            .max(4.0 * f32::MIN_POSITIVE);
        assert!((simd - scalar).abs() <= tolerance,
            "f32 dot: SIMD={simd}, scalar={scalar}, tol={tolerance}");
    }

    #[test]
    fn test_dot_dispatch_simd_float_f64() {
        let lhs: Vec<f64> = (0..1024).map(|v| v as f64 * 0.25).collect();
        let rhs: Vec<f64> = (0..1024).map(|v| (v as f64 + 1.0) * 0.5).collect();
        let simd_result = try_dot_f64(&lhs, &rhs);
        assert!(simd_result.is_some(), "length 1024 must enter f64 dot SIMD admission");

        let simd = simd_result.unwrap();
        let scalar: f64 = lhs.iter().zip(rhs.iter()).map(|(l, r)| l * r).sum();
        // tolerance per 12-matrix.md §10.1 f64 dot:
        //   max(8·ε·n·max_abs_a·max_abs_b, 4·MIN_POSITIVE)
        let max_abs_a = lhs.iter().copied().map(f64::abs).fold(0.0_f64, f64::max);
        let max_abs_b = rhs.iter().copied().map(f64::abs).fold(0.0_f64, f64::max);
        let tolerance = (8.0 * f64::EPSILON * (lhs.len() as f64) * max_abs_a * max_abs_b)
            .max(4.0 * f64::MIN_POSITIVE);
        assert!((simd - scalar).abs() <= tolerance,
            "f64 dot: SIMD={simd}, scalar={scalar}, tol={tolerance}");
    }

    #[test]
    fn test_dot_dispatch_simd_complex_f32() {
        let lhs: Vec<Complex<f32>> = (0..1024)
            .map(|i| Complex::new(i as f32 * 0.25, (i as f32) * 0.5))
            .collect();
        let rhs: Vec<Complex<f32>> = (0..1024)
            .map(|i| Complex::new(-(i as f32) * 0.125, i as f32 * 0.75))
            .collect();
        let simd_result = try_dot_complex_f32(&lhs, &rhs);
        assert!(simd_result.is_some(), "length 1024 must enter Complex<f32> dot SIMD admission");

        let simd = simd_result.unwrap();
        // Scalar baseline: sum(conj(lhs_i) * rhs_i)
        let scalar: Complex<f32> = lhs.iter().zip(rhs.iter())
            .map(|(l, r)| l.conj() * r)
            .sum();
        // tolerance per 12-matrix.md §10.1 Complex<f32> dot:
        //   max(16·ε·n·max_abs_a·max_abs_b, 4·MIN_POSITIVE)
        // Complex 系数 16.0（复数乘法的 4 次实乘 + 2 次实加）
        let max_abs_a = lhs.iter().map(|c| c.norm()).fold(0.0_f32, f32::max);
        let max_abs_b = rhs.iter().map(|c| c.norm()).fold(0.0_f32, f32::max);
        let tolerance = (16.0 * f32::EPSILON * (lhs.len() as f32) * max_abs_a * max_abs_b)
            .max(4.0 * f32::MIN_POSITIVE);
        // 分量级断言（W14 修复决策 12 + 08-simd §6.6）：real/imag 分别比较，禁用 .norm()
        assert!((simd.re - scalar.re).abs() <= tolerance,
            "Complex<f32> dot real: SIMD={}, scalar={}, tol={tolerance}", simd.re, scalar.re);
        assert!((simd.im - scalar.im).abs() <= tolerance,
            "Complex<f32> dot imag: SIMD={}, scalar={}, tol={tolerance}", simd.im, scalar.im);
    }

    #[test]
    fn test_dot_dispatch_simd_complex_f64() {
        let lhs: Vec<Complex<f64>> = (0..1024)
            .map(|i| Complex::new(i as f64 * 0.25, (i as f64) * 0.5))
            .collect();
        let rhs: Vec<Complex<f64>> = (0..1024)
            .map(|i| Complex::new(-(i as f64) * 0.125, i as f64 * 0.75))
            .collect();
        let simd_result = try_dot_complex_f64(&lhs, &rhs);
        assert!(simd_result.is_some(), "length 1024 must enter Complex<f64> dot SIMD admission");

        let simd = simd_result.unwrap();
        // Scalar baseline: sum(conj(lhs_i) * rhs_i)
        let scalar: Complex<f64> = lhs.iter().zip(rhs.iter())
            .map(|(l, r)| l.conj() * r)
            .sum();
        // tolerance per 12-matrix.md §10.1 Complex<f64> dot:
        //   max(16·ε·n·max_abs_a·max_abs_b, 4·MIN_POSITIVE)
        let max_abs_a = lhs.iter().map(|c| c.norm()).fold(0.0_f64, f64::max);
        let max_abs_b = rhs.iter().map(|c| c.norm()).fold(0.0_f64, f64::max);
        let tolerance = (16.0 * f64::EPSILON * (lhs.len() as f64) * max_abs_a * max_abs_b)
            .max(4.0 * f64::MIN_POSITIVE);
        // 分量级断言（W14 修复决策 12 + 08-simd §6.6）
        assert!((simd.re - scalar.re).abs() <= tolerance,
            "Complex<f64> dot real: SIMD={}, scalar={}, tol={tolerance}", simd.re, scalar.re);
        assert!((simd.im - scalar.im).abs() <= tolerance,
            "Complex<f64> dot imag: SIMD={}, scalar={}, tol={tolerance}", simd.im, scalar.im);
    }

    #[test]
    fn test_dot_dispatch_simd_threshold_rejects_short_inputs() {
        let lhs: Vec<f32> = (0..511).map(|v| v as f32).collect();
        let rhs: Vec<f32> = (0..511).map(|v| v as f32).collect();
        assert!(try_dot_f32(&lhs, &rhs).is_none(), "length below f32/f64 dot threshold 512 must not enter SIMD");

        let lhs: Vec<Complex<f32>> = (0..511)
            .map(|i| Complex::new(i as f32, i as f32 * 0.5))
            .collect();
        let rhs: Vec<Complex<f32>> = (0..511)
            .map(|i| Complex::new(i as f32 * 0.25, -(i as f32)))
            .collect();
        assert!(try_dot_complex_f32(&lhs, &rhs).is_none(), "length below Complex dot threshold 512 must not enter SIMD");
    }
}
```

## 注意事项

- SIMD module does not own scalar fallback loops; callers keep the serial baseline.
- All SIMD entries are internal `pub(crate)` APIs and must stay feature-gated.
- Unsafe code requires explicit length, tail, and alignment proof before vector load/store.
- **FMA 使用规则**（08-simd §1.2/§6.6）：element-wise 与 dot per-element 主循环禁用 FMA（保持与标量逐位一致）；仅 horizontal reduction merge 阶段可在记录容差且 FMA capability bit 独立检测确认后使用。pulp 0.18 的 FMA capability 通过 spike（W14T0）确认。
- Complex dot must keep the BLAS xdotc direction: conjugate the left operand, never the right operand.
- Complex dot 阈值 = 512 来源于 `build/PLAN.md` W14 补充决策（design/08-simd.md §5.8 不直接列出 Complex 阈值）。
- 所有代码注释和 Rust 标识符使用英文，文档说明保持当前实施方案风格。
- 不添加新的第三方依赖，除非设计文档已在 Cargo feature 中声明。
