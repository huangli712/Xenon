## 目标

本任务是 Wave 4 的集成与契约补齐阶段：
1. 校准 `RealScalar` 数学能力边界（§5.3 sanity check）
2. 在 `src/element/mod.rs` 中定义 §5.9.1 的 `CastElement` marker trait 与 §5.6 的 `BoolElement` marker trait

4. 在 `src/element/primitives.rs` 中为 `CastElement`、`BoolElement`、`OrderedCompareElement`（W4T1 已定义 trait 签名）补齐所有具体类型 impl
5. 在 `src/element/mod.rs` 模块级文档注释中描述 `CastTo<T>` 有损转换错误语义

## 实施步骤

### Step 1: 校准 RealScalar 方法边界 — `src/element/real.rs`

对照 `03-element.md` §5.3 的 11 个方法清单（abs/signum/sqrt/sin/exp/ln/floor/ceil/is_nan/is_infinite/is_finite），在 `real.rs` **模块级文档注释**（`//!`）中显式声明当前公开方法集合的"最小公共承诺"，并标注未来加入新方法属于半破坏性变更（需要 SemVer minor bump，但对下游用户代码无破坏性）。

```rust,ignore
//! Real-valued scalar trait.
//!
//! The `RealScalar` trait exposes a deliberately minimal set of 11 real-valued
//! math functions (`abs`, `signum`, `sqrt`, `sin`, `exp`, `ln`, `floor`, `ceil`,
//! `is_nan`, `is_infinite`, `is_finite`). Adding new methods in future
//! versions constitutes a semi-breaking change (SemVer minor bump): new methods
//! do not break existing downstream user code, but they DO break any external
//! types that `impl RealScalar for MyType` — however, the `Sealed` supertrait
//! prevents any such external impls by design.
//!
//! For extended math functions (e.g., `cos`, `tan`, `log2`, `tanh`), use the
//! crate-internal extension traits in `src/element/real_extended.rs` (if added
//! in future waves). Do not expose those on the public `RealScalar` trait.
```

### Step 2: 在 `src/element/mod.rs` 中定义 BoolElement + CastElement marker traits

W4T1 已在 `src/element/mod.rs` 定义了 `Element`、`OrderedCompareElement`、`CastTo<T>` 三个 trait 签名。本任务追加 §5.6 `BoolElement` 与 §5.9.1 `CastElement` 两个 marker trait 定义。

```rust,ignore
// src/element/mod.rs (append to existing file)

/// Internal marker for the bool element type.
///
/// Used by `11-math.md` `not()` to constrain its impl to bool tensors only.
/// Not part of the public API; sealed via `crate::private::Sealed`.
pub(crate) trait BoolElement: Element + Sealed {}

/// Public sealed marker for element types in the cast matrix.
///
/// `cast()` public signature `where A: CastElement, T: CastElement` uses this
/// trait to exclude `bool` from conversion at compile time and narrow the
/// element set to the 6 numeric types.
///
/// Sealed: `CastElement: Element` inherits seal via `Element: Sealed`.
pub trait CastElement: Element {}
```

> **注意**：`BoolElement` 与 `CastElement` 的**具体类型 impl** 分别放在 `src/element/primitives.rs`（bool + 6 个数值类型），由本任务 Step 4 统一落地。

### Step 3: 在 `src/element/mod.rs` 中定义 §5.10 Checked Arithmetic Traits

按 `03-element.md` §5.10 定义 5 个 `pub(crate)` checked arithmetic traits 及其 i32/i64 impl。这些 trait 是整数溢出检测的**唯一权威定义点**，供 `math`、`matrix`、`reduction` 等上层模块复用。上层模块不应重新定义同语义 trait。

```rust,ignore
// src/element/mod.rs (append to existing file)

/// Checked addition for types that support it.
///
/// Returns `None` on overflow instead of wrapping.
/// Only implemented for integer types (`i32`, `i64`).
/// Float types use ordinary `+` (NaN propagation handles the semantics).
///
/// Used by integer `sum()` reduction to guarantee overflow is detected
/// in both debug and release builds (per requirement §14).
pub(crate) trait CheckedAdd: Numeric + Sealed {
    /// Returns `Some(self + rhs)` if no overflow, `None` otherwise.
    fn checked_add(self, rhs: Self) -> Option<Self>;
}

impl CheckedAdd for i32 {
    #[inline]
    fn checked_add(self, rhs: Self) -> Option<Self> {
        i32::checked_add(self, rhs)
    }
}

impl CheckedAdd for i64 {
    #[inline]
    fn checked_add(self, rhs: Self) -> Option<Self> {
        i64::checked_add(self, rhs)
    }
}

/// Checked subtraction for integer-only overflow-sensitive paths.
pub(crate) trait CheckedSub: Numeric + Sealed {
    fn checked_sub(self, rhs: Self) -> Option<Self>;
}

impl CheckedSub for i32 {
    #[inline]
    fn checked_sub(self, rhs: Self) -> Option<Self> { i32::checked_sub(self, rhs) }
}

impl CheckedSub for i64 {
    #[inline]
    fn checked_sub(self, rhs: Self) -> Option<Self> { i64::checked_sub(self, rhs) }
}

/// Checked multiplication for integer-only overflow-sensitive paths.
pub(crate) trait CheckedMul: Numeric + Sealed {
    fn checked_mul(self, rhs: Self) -> Option<Self>;
}

impl CheckedMul for i32 {
    #[inline]
    fn checked_mul(self, rhs: Self) -> Option<Self> { i32::checked_mul(self, rhs) }
}

impl CheckedMul for i64 {
    #[inline]
    fn checked_mul(self, rhs: Self) -> Option<Self> { i64::checked_mul(self, rhs) }
}

/// Checked negation for integer-only overflow-sensitive paths.
pub(crate) trait CheckedNeg: Numeric + Sealed {
    fn checked_neg(self) -> Option<Self>;
}

impl CheckedNeg for i32 {
    #[inline]
    fn checked_neg(self) -> Option<Self> { i32::checked_neg(self) }
}

impl CheckedNeg for i64 {
    #[inline]
    fn checked_neg(self) -> Option<Self> { i64::checked_neg(self) }
}

/// Checked division for integer-only overflow-sensitive paths.
///
/// Returns `None` for divisor zero or for the `MIN / -1` overflow case;
/// callers translate `None` to a panic per the project-wide integer
/// overflow policy (see `26-error.md §6`).
pub(crate) trait CheckedDiv: Numeric + Sealed {
    fn checked_div(self, rhs: Self) -> Option<Self>;
}

impl CheckedDiv for i32 {
    #[inline]
    fn checked_div(self, rhs: Self) -> Option<Self> { i32::checked_div(self, rhs) }
}

impl CheckedDiv for i64 {
    #[inline]
    fn checked_div(self, rhs: Self) -> Option<Self> { i64::checked_div(self, rhs) }
}
```

> **注意**：这些 trait 为 `pub(crate)` 内部实现辅助，不纳入稳定公开 API 面。仅覆盖整数类型（`i32`/`i64`）；浮点和复数类型不实现（IEEE 754 语义处理溢出）。`bool` 不实现（非 Numeric）。

### Step 5: 文档化 CastTo<T> 错误语义 — `src/element/mod.rs`

在 `src/element/mod.rs` 的模块级文档注释（`//!`）中添加 CastTo lossy 转换的错误语义描述：
- 说明哪些转换是有损的（如 `f64 → i32` 截断、溢出返回错误）
- 引用 `03-element.md §5.9` 与 `26-error.md §5.1` 的错误类型定义
- 本 task 不实现 `CastTo<T>` 的具体转换逻辑，仅定义语义契约（具体 impl 由 `21-type.md` Wave 完成）

```rust,ignore
//! Element type hierarchy.
//!
//! # CastTo<T> error semantics
//!
//! `CastTo<T>::cast_to()` returns `Err(XenonError::TypeConversion)` for
//! lossy conversions. Lossy cases include:
//! - Float → integer with truncation (e.g., `1.5f64.cast_to::<i32>()`)
//! - Overflow (e.g., `i64::MAX.cast_to::<i32>()`)
//! - NaN → integer (no finite representation)
//! - Complex → real when imaginary part is non-zero
//!
//! The complete cast matrix and Tier classification (T0 identity, T1 lossless,
//! T2 lossy, T3 excluded) is authoritative in `21-type.md §5`.
//! Error payload layout is in `26-error.md §5.1`.
//!
//! `bool` is excluded from `CastTo<T>` as both source and target (§5.9).
//! This exclusion is enforced at compile time via absence of `impl CastElement for bool`.
```

不修改 `Element`/`Numeric`/`RealScalar`/`ComplexScalar` trait 签名或既有 impl 块，仅编写 `//!` 文档注释。

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_real_scalar_boundary_methods() {
        // §5.3: Verify RealScalar exposes all 11 methods.
        let value = 4.0f64;
        assert_eq!(<f64 as RealScalar>::floor(value), 4.0);
        assert_eq!(<f64 as RealScalar>::ceil(value), 4.0);
        assert!(<f64 as RealScalar>::is_finite(value));
        assert_eq!(<f64 as RealScalar>::abs(-4.0), 4.0);
        assert_eq!(<f64 as RealScalar>::sqrt(9.0), 3.0);
        assert_eq!(<f64 as RealScalar>::sin(0.0), 0.0);
    }

    #[test]
    fn test_marker_trait_impls() {
        // §5.5: OrderedCompareElement for 4 ordered types.
        fn assert_ordered<T: OrderedCompareElement>() {}
        assert_ordered::<i32>();
        assert_ordered::<i64>();
        assert_ordered::<f32>();
        assert_ordered::<f64>();

        // §5.9.1: CastElement for 6 numeric types (bool excluded).
        fn assert_castable<T: CastElement>() {}
        assert_castable::<i32>();
        assert_castable::<i64>();
        assert_castable::<f32>();
        assert_castable::<f64>();
        assert_castable::<Complex<f32>>();
        assert_castable::<Complex<f64>>();

        // §5.6: BoolElement for bool only.
        fn assert_bool<T: BoolElement>() {}
        assert_bool::<bool>();
    }

    #[test]
    fn test_checked_arithmetic_traits() {
        // §5.10: CheckedAdd/CheckedSub/CheckedMul/CheckedNeg/CheckedDiv for i32/i64.
        // Normal cases
        assert_eq!(<i32 as CheckedAdd>::checked_add(1, 2), Some(3));
        assert_eq!(<i64 as CheckedAdd>::checked_add(1, 2), Some(3));
        assert_eq!(<i32 as CheckedSub>::checked_sub(5, 3), Some(2));
        assert_eq!(<i64 as CheckedSub>::checked_sub(5, 3), Some(2));
        assert_eq!(<i32 as CheckedMul>::checked_mul(3, 4), Some(12));
        assert_eq!(<i64 as CheckedMul>::checked_mul(3, 4), Some(12));
        assert_eq!(<i32 as CheckedNeg>::checked_neg(7), Some(-7));
        assert_eq!(<i64 as CheckedNeg>::checked_neg(7), Some(-7));
        assert_eq!(<i32 as CheckedDiv>::checked_div(10, 3), Some(3));
        assert_eq!(<i64 as CheckedDiv>::checked_div(10, 3), Some(3));

        // Overflow cases
        assert_eq!(<i32 as CheckedAdd>::checked_add(i32::MAX, 1), None);
        assert_eq!(<i64 as CheckedAdd>::checked_add(i64::MAX, 1), None);
        assert_eq!(<i32 as CheckedSub>::checked_sub(i32::MIN, 1), None);
        assert_eq!(<i32 as CheckedMul>::checked_mul(i32::MAX, 2), None);
        assert_eq!(<i32 as CheckedNeg>::checked_neg(i32::MIN), None);
        assert_eq!(<i32 as CheckedDiv>::checked_div(1, 0), None);
        assert_eq!(<i32 as CheckedDiv>::checked_div(i32::MIN, -1), None);
    }
}
```

## 关键设计决策

1. **集中补齐 marker trait impls**：本任务在 `primitives.rs` 中统一落地 Wave 4 遗留的所有 marker trait impl（OrderedCompareElement 4个、CastElement 6个、BoolElement 1个），避免分散到多个任务导致遗漏。
2. **§5.10 Checked Arithmetic Traits 集中定义**：5 个 `pub(crate)` checked arithmetic traits（CheckedAdd/CheckedSub/CheckedMul/CheckedNeg/CheckedDiv）及其 i32/i64 impl 在本任务集中落地，作为整数溢出检测的唯一权威定义点。上层模块（`math`、`matrix`、`reduction`）复用这些 trait，不应重新定义同语义 trait。
3. **RealScalar 边界文档化**：通过模块级文档注释显式声明当前公开方法集合的"最小公共承诺"，为未来扩展留下清晰的 SemVer 指引。
4. **CastTo 错误语义前置文档化**：虽然具体 impl 由 W21 负责，但错误语义契约在 W4 阶段文档化，确保类型系统公共 API 契约的完整性。

- `bool` 只实现 Element 和 BoolElement，不实现 Numeric 或 CastElement。
- `usize` 仅作为索引和形状元数据，不属于 tensor element 集合。
- 本任务依赖 W4T10（Complex 类型已就绪），因此 `CastElement` 的 6 个 impl 可以在本任务完整落地。
- `OrderedCompareElement` 的 4 个 impl 本应由 W4T5/W4T6/W4T7 各自落地，但为避免遗漏，本任务集中补齐。
