## 实施步骤

### Step 1: 定位实现边界

在 `src/element/numeric.rs` 中只定义 `03-element.md` §5.2 的 `Numeric` trait。它位于 `Element` 之上、`RealScalar` / `ComplexScalar` 之下，用来表达通用数值元素的算术运算能力和统一共轭入口；本任务不定义实数数学函数、不定义复数专用访问器，也不实现 primitive 类型。

`bool` 仍只属于 `Element`；`usize` 仍只用于索引和形状元数据。整数类型实现 `Numeric` 时，`Add/Sub/Mul/Div/Neg` 只表示运算符语法可用，具体溢出、除零和不可表示结果的策略由运算模块处理。

### Step 2: 实现任务目标

按 `03-element.md` §5.2 写出完整 trait 签名。`Numeric` 继承 `Element` 与 `Sealed`，因此继承基础值语义并在本层明确保持封闭实现集合；同时显式继承五个 `core::ops` 运算 trait。`conjugate(self)` 是全体数值元素的统一共轭入口：实数和整数返回自身，复数类型在后续实现中返回数学共轭。

```rust,ignore
use crate::element::Element;

/// Numeric element trait.
pub trait Numeric:
    Element
    + core::ops::Add<Output = Self>
    + core::ops::Sub<Output = Self>
    + core::ops::Mul<Output = Self>
    + core::ops::Div<Output = Self>
    + core::ops::Neg<Output = Self>
{
    fn conjugate(self) -> Self;
}
```

不要在 `Numeric` 中加入实数函数、复数访问器或类型转换 API；这些能力分别属于 `RealScalar`、`ComplexScalar` 和后续转换模块。

### Step 3: 补齐导出与相邻调用点

在 `src/element/mod.rs` 中为本任务新增 `numeric` 子模块声明并 re-export `Numeric`，让调用方统一从 `crate::element::Numeric` 访问 trait。

> 在 `src/element/mod.rs`（W4T1 已创建）中追加 `mod numeric;` 与 `pub use numeric::Numeric;` 子模块声明。本任务不再修改 W4T1 已写入的 trait/枚举定义。

```rust,ignore
mod numeric;

pub use numeric::Numeric;
```

`numeric.rs` 内只需要依赖 `crate::element::Element` 与共享 `Sealed`。不要为了示例或测试提前引入后续 trait、复数类型或转换模块。

### Step 4: 单元测试

> **强制要求**:
> - 本步骤必须包含一个或者多个单元测试。
> - 测试函数名称和测试内容必须参考对应设计文档的 **「测试计划」** 一节。
> - 编译检查与Lint检查不等同于单元测试。
> - 如果测试没有通过需要修复直至测试通过。
> - **无测试 = 任务未完成。**

```rust
#[cfg(test)]
mod tests {
    use super::*;

    // Compile-time contract: Numeric exposes arithmetic ops + conjugate.
    // Concrete impl arrives in W4T5 (i32) and W4T7 (f32/f64).
    #[allow(dead_code)]
    fn _assert_numeric_contract<A: Numeric>(x: A, y: A) -> A {
        let _ = (x + y - x) * y / y;
        let _ = -x;
        x.conjugate()
    }
}
```

## 关键设计决策

1. 依据 `03-element.md` §5，Element/Numeric/RealScalar/ComplexScalar 分层保持正交，不把复数或实数能力泄漏到基础 Element。
2. 依据 `03-element.md` §5.2，Numeric 的整数运算符 supertrait 只表示语法能力，具体溢出策略由运算模块处理。
3. 依据 `03-element.md` §8，最后一步必须落地可运行单元测试，覆盖封闭类型集合和边界语义。
