## 目标

Project license file matching Cargo.toml package metadata。

本任务交付可审查、可验证的文档改动：LICENSE 文件必须与 `Cargo.toml` package metadata 一致，并符合开源许可的最佳实践。

## 前置准备

- 确认前置依赖 `W1T1` 已完成或不适用。
- 读取 `LICENSE` 当前内容，避免覆盖已有用户修改。
- 对照 01-architecture §1.4、§3 和 §4 中关于项目元数据和许可证的约定准备检查清单。

## 实施步骤

### Step 1: 核对 Cargo.toml metadata

读取 `Cargo.toml` 的 `license` 字段，确认项目声明为 MIT 或明确的等价 SPDX 表达式。

### Step 2: 写入 LICENSE 文件

在 `LICENSE` 写入与 metadata 一致的许可证正文，不添加额外授权条款或未确认的组织名称。

```text
MIT License

Copyright (c) <year> <The Xenon Authors>

Permission is hereby granted, free of charge, to any person obtaining a copy
of this software and associated documentation files (the "Software"), to deal
in the Software without restriction, including without limitation the rights
to use, copy, modify, merge, publish, distribute, sublicense, and/or sell
copies of the Software, and to permit persons to whom the Software is
furnished to do so, subject to the following conditions:

The above copyright notice and this permission notice shall be included in all
copies or substantial portions of the Software.

THE SOFTWARE IS PROVIDED "AS IS", WITHOUT WARRANTY OF ANY KIND, EXPRESS OR
IMPLIED, INCLUDING BUT NOT LIMITED TO THE WARRANTIES OF MERCHANTABILITY,
FITNESS FOR A PARTICULAR PURPOSE AND NONINFRINGEMENT. IN NO EVENT SHALL THE
AUTHORS OR COPYRIGHT HOLDERS BE LIABLE FOR ANY CLAIM, DAMAGES OR OTHER
LIABILITY, WHETHER IN AN ACTION OF CONTRACT, TORT OR OTHERWISE, ARISING FROM,
OUT OF OR IN CONNECTION WITH THE SOFTWARE OR THE USE OR OTHER DEALINGS IN THE
SOFTWARE.
```

实施时将 `<year>` 和 `<The Xenon Authors>` 替换为项目实际年份和版权所有人，例如 `Xenon contributors`。

### Step 3: 检查 README 引用

确认 README 的 License 节指向 `LICENSE`，且文本与 `Cargo.toml` metadata 保持一致。

### Step 4: 单元测试

> **强制要求**: LICENSE 是文本产物，使用元数据一致性检查作为任务测试。

```bash
set -euo pipefail

# 1. Cargo.toml license = "MIT"
python3 - <<'PY'
import tomllib
from pathlib import Path

cfg = tomllib.loads(Path("Cargo.toml").read_text())
assert cfg["package"]["license"] == "MIT", "Cargo.toml package.license must be MIT"
PY

# 2. LICENSE 包含 MIT 标准关键段落
test -s LICENSE
grep -q "Permission is hereby granted, free of charge" LICENSE
grep -q 'THE SOFTWARE IS PROVIDED "AS IS"' LICENSE
```

验收点：`Cargo.toml` license 字段与 LICENSE 文件正文一致。

## 关键设计决策

- LICENSE 文件必须与 `Cargo.toml` package metadata 一致。
- 不添加未确认的版权主体或额外授权条款。
- README 只引用许可证文件，不复制可能漂移的长文本。

## 验证方式

1. 元数据一致性: 使用 Python 解析 `Cargo.toml`，确认 `package.license` 为 `MIT`
2. 文件完整性: `test -s LICENSE` 确认 LICENSE 文件非空
3. 内容匹配: `grep -q "Permission is hereby granted, free of charge" LICENSE` 和 `grep -q 'THE SOFTWARE IS PROVIDED "AS IS"' LICENSE` 确认许可证正文与 metadata 一致
4. README 引用: `grep -n 'LICENSE' README.md` 确认 README 指向 LICENSE 文件

## 注意事项

- LICENSE 文件必须与 `Cargo.toml` package metadata 完全一致，不添加额外条款或未确认的版权主体。
- README 中 License 节只需引用文件名，不复制可能漂移的长文本。
