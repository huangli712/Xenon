## 实施步骤

### Step 1: 创建测试文件与导入

创建或更新目标文件，使用 `xenon::prelude::*` 和 `tests/common` helper。每个测试名称必须描述可观察行为，并保持单文件可独立运行。

```rust
use xenon::prelude::*;
use xenon::error::XenonError;

#[test]
fn test_multi_dim_index() {
    // 实证 W29T7 L100-112：F-order 列主元，[2,3] 数据 [1,2,3,4,5,6] 映射
    // (0,0)=1, (1,0)=2, (0,1)=3, (1,1)=4, (0,2)=5, (1,2)=6。
    let t = Tensor2::from_shape_vec([2, 3], (1..=6).map(|i| i as f64).collect()).unwrap();
    assert_eq!(*t.try_at(&[0, 0]).unwrap(), 1.0);
    assert_eq!(*t.try_at(&[0, 2]).unwrap(), 5.0);  // F-order: offset 0 + 2*2 = 4
    assert_eq!(*t.try_at(&[1, 0]).unwrap(), 2.0);  // F-order: offset 1 + 0*2 = 1
    assert_eq!(*t.try_at(&[1, 2]).unwrap(), 6.0);  // F-order: offset 1 + 2*2 = 5
}

#[test]
fn test_index_out_of_bounds() {
    let t = Tensor1::from_shape_vec([3], vec![1.0_f64, 2.0, 3.0]).unwrap();
    let err = t.try_at(&[3]).unwrap_err();
    assert!(matches!(err, XenonError::IndexOutOfBounds { .. }));
    let err2 = t.try_at(&[100]).unwrap_err();
    assert!(matches!(err2, XenonError::IndexOutOfBounds { .. }));
}

#[test]
fn test_slice_range() {
    let t = Tensor1::from_shape_vec([5], vec![10.0_f64, 20.0, 30.0, 40.0, 50.0]).unwrap();
    // 实证 17-indexing.md L163/L198/L253：`slice<I>(info: SliceInfo<I, D>)`要求显式 `SliceInfo` 构造；design 未提供 `s!` 宏。
    let info = SliceInfo::<Ix1, Ix1>::new(
        SliceInfoIndices::Inline {
            len: 1,
            elems: [Some(SliceInfoElem::Range { start: 1, end: 4 }), None, None, None, None, None],
        },
        Ix1(5),
        Ix1(3),
    ).unwrap();
    let s = t.slice(info).unwrap();
    assert_eq!(s.shape(), &[3]);
    assert_eq!(s.iter().copied().collect::<Vec<_>>(), vec![20.0, 30.0, 40.0]);
}
```

### Step 2: 实现正常路径、边界路径和错误路径

按 28-tests §5.7 清单补齐 `test_slice_subrange`（范围切片子区间）与 `test_slice_mut_broadcast_rejected`（广播视图上的可变切片必须被拒绝）。错误返回必须断言具体的 `XenonError` 变体；浮点路径按 §6.2 使用精确比较。

```rust
#[test]
fn test_slice_subrange() {
    let t = Tensor1::from_shape_vec([6], (0..6).map(|i| i as f64).collect()).unwrap();
    // First slice [1..5], then take a sub-range [1..3] on the slice view.
    // 实证 17-indexing.md L163/L198/L253：design 未提供 `s!` 宏，要求显式 `SliceInfo`。
    let info1 = SliceInfo::<Ix1, Ix1>::new(
        SliceInfoIndices::Inline {
            len: 1,
            elems: [Some(SliceInfoElem::Range { start: 1, end: 5 }), None, None, None, None, None],
        },
        Ix1(6),
        Ix1(4),
    ).unwrap();
    let s1 = t.slice(info1).unwrap();
    let info2 = SliceInfo::<Ix1, Ix1>::new(
        SliceInfoIndices::Inline {
            len: 1,
            elems: [Some(SliceInfoElem::Range { start: 1, end: 3 }), None, None, None, None, None],
        },
        Ix1(4),
        Ix1(2),
    ).unwrap();
    let s2 = s1.slice(info2).unwrap();
    assert_eq!(s2.shape(), &[2]);
    assert_eq!(s2.iter().copied().collect::<Vec<_>>(), vec![2.0, 3.0]);
}

#[test]
fn test_slice_mut_broadcast_rejected() {
    // A broadcast view is read-only; mutable slicing must be rejected
    // by the API surface (compile-time absence).
    //
    // 实证 15-broadcast.md §5.1 L129：唯一公开入口是 `broadcast_to(shape: E)`，返回
    // `TensorView<'_, A, E::Dim>`——这是一个只读视图（`ViewRepr`，未实现 StorageMut），
    // 因此任何可变切片入口会在编译期就不可见；本测试通过只使用 immutable `slice()`
    // 、并验证上游构造返回只读 view 表达该约束。硬契约由 trait 边界在编译期保证
    // （只读视图不实现 StorageMut，可变切片入口在编译期不可见）；W29T25 9-item
    // fixture 范围内未单列 ui_broadcast_view_slice_mut_rejected，亦不必要。
    let base = Tensor1::from_shape_vec([3], vec![1.0_f64, 2.0, 3.0]).unwrap();
    let bcast = base.broadcast_to([2, 3]).unwrap();
    // bcast 是 TensorView，只能 .slice() 不能 .slice_mut()
    // 实证 17-indexing.md L163/L198：design 未提供 `s!` 宏。
    let info = SliceInfo::<Ix2, Ix2>::new(
        SliceInfoIndices::Inline {
            len: 2,
            elems: [
                Some(SliceInfoElem::Range { start: 0, end: 2 }),
                Some(SliceInfoElem::Range { start: 0, end: 3 }),
                None, None, None, None,
            ],
        },
        Ix2(2, 3),
        Ix2(2, 3),
    ).unwrap();
    let sub = bcast.slice(info).unwrap();
    assert_eq!(sub.shape(), &[2, 3]);
}
```

补齐 §5.7 中结构性 SliceInfo 校验测试。`SliceInfoElem::Range` 不含 step，design 未提供 `s!` 宏——所有切片通过显式 `SliceInfo::new(SliceInfoIndices::Inline {...}, in_dim, out_dim)` 构造。

```rust
#[test]
fn test_sliceinfo_structural_validation() {
    let t = Tensor2::from_shape_vec(
        [4, 4],
        (0..16).map(|i| i as f64).collect(),
    ).unwrap();
    // Range only: no step syntax allowed (see 28-tests §5.7 L473).
    // 实证 17-indexing.md L163/L198：design 未提供 `s!` 宏。
    let info = SliceInfo::<Ix2, Ix2>::new(
        SliceInfoIndices::Inline {
            len: 2,
            elems: [
                Some(SliceInfoElem::Range { start: 0, end: 2 }),
                Some(SliceInfoElem::Range { start: 0, end: 2 }),
                None, None, None, None,
            ],
        },
        Ix2(4, 4),
        Ix2(2, 2),
    ).unwrap();
    let s = t.slice(info).unwrap();
    assert_eq!(s.shape(), &[2, 2]);
    assert_eq!(*s.try_at(&[0, 0]).unwrap(), 0.0);
    assert_eq!(*s.try_at(&[0, 1]).unwrap(), 4.0);  // F-order: offset 0 + 1*4 = 4
    assert_eq!(*s.try_at(&[1, 0]).unwrap(), 1.0);  // F-order: offset 1 + 0*4 = 1
    assert_eq!(*s.try_at(&[1, 1]).unwrap(), 5.0);  // F-order: offset 1 + 1*4 = 5
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 集成测试通过公开 API 验证跨模块协作 | 28-tests §1.1 和 §5 将跨模块行为定义为本 wave 职责 |
| 索引只走 `try_at` / `try_at_mut`，错误断言变体而非 `is_err()` | 28-tests §5.7 L473 公开访问入口规约 + §6.2 错误深度 |
| `SliceInfoElem::Range` 仅含 `start`/`end`，禁止 step 语法 | 28-tests §5.7 L473 硬约束 |
| Tier 1 浮点路径默认使用 bitwise/ULP==0 精确比较 | 28-tests §6.2.1 禁止将基础路径自动放宽为容差比较 |
