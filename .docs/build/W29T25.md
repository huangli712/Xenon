## 目标

Compile-fail fixtures: wrong dimension, missing element bound, storage mismatch, unsigned (`usize`), invalid unsigned (`u8/u16/u32/u64`), `bool` sum/unique/arithmetic, blanket scalar add — 共 9 项，逐项与 §3 line 62-71 的权威清单一一对照。

本任务实现 W29 集成测试体系中的一个交付物，覆盖 28-tests §5 的测试文件职责、§6 的数值精度与并行/SIMD 规则、§7 的分层执行安排以及 §8 的测试矩阵。核心 fixture 名称（§5.21 / §3 line 62-71 权威 9 项）：
`wrong_dimension_type`, `missing_element_bound`, `mismatched_storage_type`, `unsigned_tensor_element_rejected`, `invalid_unsigned_element_rejected`, `ui_bool_sum_rejected`, `ui_bool_unique_rejected`, `ui_bool_arithmetic_rejected`, `blanket_scalar_add_rejected`。

## 实施步骤

### Step 1: 创建 9 个 compile-fail fixtures

每个 fixture 单文件，顶部 `use xenon::prelude::*;`（W29T24 harness 已保证可解析）；通过 `//~ ERROR: <token>` 注释声明期望的编译错误 token。

```rust
// === tests/compile-fail/wrong_dimension_type.rs ===
use xenon::prelude::*;

struct NotADimension;
type WrongDimTensor = Tensor<f64, NotADimension>; //~ ERROR: Dimension

fn main() {
    let _x: WrongDimTensor;
}
```

```rust
// === tests/compile-fail/missing_element_bound.rs ===
use xenon::prelude::*;

#[derive(Clone, Debug)]
struct NotElement;

type BadTensor = Tensor<NotElement, Ix1>; //~ ERROR: Element

fn main() {
    let _x: BadTensor;
}
```

```rust
// === tests/compile-fail/mismatched_storage_type.rs ===
// §5.21 line 668: 不合法存储表示组合（Storage representation 不匹配），不是元素类型不匹配。
// 按 05-storage.md，`RawStorage` 暴露 `type Elem`，但没有 `RawRepr` 关联类型；
// 因此改用对具体 storage 表示（`Owned<f64>`）的类型约束。
use xenon::prelude::*;

fn take_owned_only<D>(_t: TensorBase<Owned<f64>, D>)
where
    D: Dimension,
{
}

fn main() {
    let t = Tensor1::<f64>::from_shape_vec([2], vec![1.0, 2.0]).unwrap();
    let v: TensorView1<f64> = t.view(); // ViewRepr<&f64>
    take_owned_only(v); //~ ERROR: expected
}
```

```rust
// === tests/compile-fail/unsigned_tensor_element_rejected.rs ===
// §5.21 line 669: usize 等无符号整数不能作为张量元素类型（仅作为 shape/axis/index 元数据）。
use xenon::prelude::*;

fn main() {
    // 由构造器本身的 Element bound 拒绝 usize（T: Element 仅允许 7 个 element types，usize 不在列）
    // rustc 错误源头位于调用 from_shape_vec 表达式。
    let _t: Tensor1<usize> = Tensor1::<usize>::from_shape_vec([3], vec![1usize, 2, 3]).unwrap(); //~ ERROR: usize
}
```

```rust
// === tests/compile-fail/invalid_unsigned_element_rejected.rs ===
// §5.21 line 670: u8/u16/u32/u64 等非法无符号元素类型在编译期被拒绝。
// 单 fixture 以 u32 作为代表；u8/u16/u64 由同一 Element sealed trait bound
// 一并拒绝（见 03-element.md §5.8），无需为每个类型单独建 fixture——rustc
// 首个类型失败即停止，同一错误路径上再列也不会产生独立证据。
use xenon::prelude::*;

fn main() {
    // Element bound 仅允许 i32/i64/f32/f64/Complex<f32>/Complex<f64>/bool，u32 被 sealed Element
    // 拒绝（见 03-element.md §5.8）。错误起源在构造器表达式；后续 `.sum()` 在同一错误
    // 路径上冗余，但双位点标记访谁能作为独立证据都可。
    let _t: Tensor1<u32> = Tensor1::<u32>::from_shape_vec([2], vec![1u32, 2]).unwrap(); //~ ERROR: u32
}
```

```rust
// === tests/compile-fail/ui_bool_sum_rejected.rs ===
// §5.21 line 671: bool 不参与 sum 归约。
use xenon::prelude::*;

fn main() {
    let t = Tensor1::<bool>::from_shape_vec([2], vec![true, false]).unwrap();
    let _s = t.sum(); //~ ERROR: bool
}
```

```rust
// === tests/compile-fail/ui_bool_unique_rejected.rs ===
// §5.21 line 672: bool 不参与 unique 操作。
use xenon::prelude::*;

fn main() {
    let t = Tensor1::<bool>::from_shape_vec([2], vec![true, false]).unwrap();
    let _u = t.unique(); //~ ERROR: bool
}
```

```rust
// === tests/compile-fail/ui_bool_arithmetic_rejected.rs ===
// §5.21 line 673: bool 不参与四则运算。
use xenon::prelude::*;

fn main() {
    let a = Tensor1::<bool>::from_shape_vec([2], vec![true, false]).unwrap();
    let b = Tensor1::<bool>::from_shape_vec([2], vec![false, true]).unwrap();
    let _r = &a + &b; //~ ERROR: Add
}
```

```rust
// === tests/compile-fail/blanket_scalar_add_rejected.rs ===
// §5.21 line 674: impl<T> Add<TensorBase<...>> for T blanket impl 被孤儿规则拒绝。
use xenon::prelude::*;
use core::ops::Add;

struct MyScalar(i32);

// External blanket impl violates orphan rules and trait coherence.
impl<S, D> Add<TensorBase<S, D>> for MyScalar //~ ERROR: orphan
where
    S: Storage<Elem = f64>,
    D: Dimension,
{
    type Output = TensorBase<S, D>;
    fn add(self, _rhs: TensorBase<S, D>) -> Self::Output {
        unimplemented!()
    }
}

fn main() {}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 9 项 fixture 与 §3 line 62-71 / §5.21 权威清单逐项对齐 | 28-tests §3 line 62-71, §5.21 line 666-675 |
| `mismatched_storage_type` 改为 Storage representation 不匹配（ViewRepr vs OwnedRepr），非元素类型不匹配 | 28-tests §5.21 line 668「不合法存储表示组合」 |
| 拆出 `invalid_unsigned_element_rejected`（覆盖 `u8/u16/u32/u64`）独立于 `unsigned_tensor_element_rejected`（覆盖 `usize`） | 28-tests §5.21 line 669-670 |
| `bool` 三类 fixture（sum / unique / arithmetic）分别独立 | 28-tests §5.21 line 671-673 |
| **不单列** `ui_external_seal_break_rejected`，由 W29T24 harness 在外部 trait coherence 路径上覆盖；本任务 9 项不含此 fixture | §5.21 line 675 由 sealed trait 设计在编译器孤儿规则层面强制；§3 line 62-71 文件清单未列入；以避免与 `blanket_scalar_add_rejected` 重复，相关单元测试断言数量为 9 |
| 不引入 trybuild 等 dev-dep | 28-tests §4.3 line 167-173 |
| harness 通过 W29T24 解析 `//~ ERROR: <token>` | 28-tests §8.4 line 1405-1432 |
