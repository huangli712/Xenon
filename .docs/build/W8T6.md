# 实施方案: W8T6

## 任务概述

| 字段 | 值 |
|------|-----|
| Wave | W8 — Tensor Core |

## 目标

实现 `07-tensor.md §5.4` (指针访问) 与 `§5.5` (连续切片访问) 全部公开方法：`as_ptr`、`as_storage_ptr`、`storage_len`、`as_mut_ptr`、`as_storage_mut_ptr`、`as_slice`、`as_mut_slice`。
本任务对齐 `07-tensor.md §6.2` 空张量指针契约（`as_ptr()` / `as_mut_ptr()` 在 `len == 0` 时返回 `NonNull::dangling().as_ptr()`，**不**对 storage base 做 `add(offset)`），以及 `§5.5` 空张量切片契约（`as_slice()` 在空张量返回 `Some(&[])`）。

## 前置准备

- 确认 W7 已提供 `RawStorage::as_ptr`、`Storage<Elem = A>` trait、`RawStorageMut::as_mut_ptr` 与 `StorageMut<Elem = A>` trait。
- 确认 W6T5 已提供 `LayoutFlags::is_f_contiguous / has_zero_stride`。
- 确认 W8T4 已提供 `len()` / `is_empty()` / `flags()` / `is_f_contiguous()` / `has_zero_stride()` 查询入口。

## 实施步骤

### Step 1: 不可变路径（`Storage<Elem = A>` bound）

在 `src/tensor/impls.rs` 中按 `07-tensor.md §5.4 / §5.5` 实现指针访问与切片方法。本 step 覆盖 `Storage<Elem = A>` bound 下的不可变路径；可变路径见 Step 2。

**不可变路径代码**：

```rust
impl<S, D, A> super::TensorBase<S, D>
where
    S: crate::storage::Storage<Elem = A>,
    D: crate::dimension::Dimension,
{
    /// Raw storage base pointer (DOES NOT add `offset`).
    ///
    /// Per `07-tensor.md §5.4` L465-476: callers using this pointer must
    /// account for `self.offset()` manually when computing element addresses.
    pub fn as_storage_ptr(&self) -> *const A {
        self.storage.as_ptr()
    }

    /// Underlying storage buffer length in elements.
    ///
    /// Per `07-tensor.md §5.4` L478-484: differs from `len()` (logical
    /// element count). For views, `storage_len()` may exceed `len()` because
    /// the backing storage can extend beyond the visible portion.
    pub fn storage_len(&self) -> usize {
        self.storage.len()
    }

    /// Raw pointer to the logical first element.
    ///
    /// Per `07-tensor.md §5.4` L458-463 and `§6.2` L1200: empty tensors
    /// return `NonNull::<A>::dangling().as_ptr()` (no pointer arithmetic on
    /// the storage base). Otherwise returns `storage.as_ptr().add(offset)`.
    pub fn as_ptr(&self) -> *const A {
        if self.is_empty() {
            // SAFETY: dangling pointer is never dereferenced for empty tensors
            // (callers must guard on `is_empty()` / `len() == 0`).
            core::ptr::NonNull::<A>::dangling().as_ptr() as *const A
        } else {
            // SAFETY: validate_access_range (W8T7) ensures `offset` and
            // `(offset + max_stride_span)` lie within `storage_len`, so
            // `storage.as_ptr().add(offset)` is in-bounds (or one-past-the-end
            // for a non-derefable address).
            unsafe { self.storage.as_ptr().add(self.offset) }
        }
    }

    /// Returns `Some(&[A])` when ALL of the following hold (per
    /// `07-tensor.md §5.5` L523-537):
    ///
    /// 1. `flags().is_f_contiguous()` is true (F-order contiguous)
    /// 2. `!flags().has_zero_stride()` (no broadcast dims)
    /// 3. `as_ptr()` points at the logical first element (enforced by the
    ///    construction-time `compute_layout_flags` contract; we rely on the
    ///    `F_CONTIGUOUS` flag implying this here)
    ///
    /// Empty tensors return `Some(&[])` per §5.5 L537.
    ///
    /// Implementation note: uses `LayoutFlags::is_f_contiguous` /
    /// `LayoutFlags::has_zero_stride` directly (W6T5) rather than the
    /// TensorBase delegations `self.is_f_contiguous()` / `self.has_zero_stride()`
    /// (W8T5), because W8T6 is parallel with W8T5 in PLAN.md (批次4) and
    /// SUMMARY.md only declares W8T6 ← W8T4. Going through `self.flags`
    /// avoids creating a hidden W8T6 → W8T5 dependency.
    pub fn as_slice(&self) -> Option<&[A]> {
        if self.is_empty() {
            // Empty fast-path: dangling+0 slice is valid per
            // `slice::from_raw_parts` contract (ZST-free element set).
            return Some(unsafe {
                core::slice::from_raw_parts(self.as_ptr(), 0)
            });
        }
        if !self.flags.is_f_contiguous() || self.flags.has_zero_stride() {
            return None;
        }
        // SAFETY: F-contiguous + no zero stride + non-empty + len <= storage_len
        // (guaranteed by construction validators). `as_ptr()` returns the
        // logical first element, which lies within storage.
        Some(unsafe { core::slice::from_raw_parts(self.as_ptr(), self.len()) })
    }
}
```

### Step 2: 可变路径（`StorageMut<Elem = A>` bound）

```rust
impl<S, D, A> super::TensorBase<S, D>
where
    S: crate::storage::StorageMut<Elem = A>,
    D: crate::dimension::Dimension,
{
    /// Raw mutable storage base pointer (DOES NOT add `offset`).
    ///
    /// Per `07-tensor.md §5.4` L500-511.
    pub fn as_storage_mut_ptr(&mut self) -> *mut A {
        self.storage.as_mut_ptr()
    }

    /// Raw mutable pointer to the logical first element.
    ///
    /// Per `07-tensor.md §5.4` L492-498 and `§6.2` L1200: empty tensors
    /// return `NonNull::<A>::dangling().as_ptr()`.
    pub fn as_mut_ptr(&mut self) -> *mut A {
        if self.is_empty() {
            core::ptr::NonNull::<A>::dangling().as_ptr()
        } else {
            // SAFETY: same construction-time invariant as `as_ptr`.
            unsafe { self.storage.as_mut_ptr().add(self.offset) }
        }
    }

    /// Returns `Some(&mut [A])` when all of the following hold (per
    /// `07-tensor.md §5.5` L552-560):
    ///
    /// - Tensor is F-contiguous and has no zero strides
    /// - Logical first element is uniquely writable (the `StorageMut` bound
    ///   plus `validate_non_overlapping_layout` in W8T7 ensures this)
    ///
    /// Empty tensors return `Some(&mut [])` per §5.5 L559.
    ///
    /// Same flag-direct-access rationale as `as_slice` above.
    pub fn as_mut_slice(&mut self) -> Option<&mut [A]> {
        if self.is_empty() {
            return Some(unsafe {
                core::slice::from_raw_parts_mut(self.as_mut_ptr(), 0)
            });
        }
        if !self.flags.is_f_contiguous() || self.flags.has_zero_stride() {
            return None;
        }
        let len = self.len();
        let ptr = self.as_mut_ptr();
        // SAFETY: same as as_slice; StorageMut bound + non-overlap invariant
        // (enforced at construction) guarantees exclusive write access.
        Some(unsafe { core::slice::from_raw_parts_mut(ptr, len) })
    }
}
```

测试依据: 覆盖 `07-tensor.md §8.2` 的 `test_tensor_as_ptr`、`test_tensor_as_mut_ptr`、`test_tensor_as_storage_ptr`、`test_tensor_as_slice`、`test_tensor_as_slice_empty`、`test_tensor_as_mut_slice`，并补充 `as_storage_mut_ptr` 与 `storage_len` 的最小覆盖。

```rust
#[cfg(test)]
mod tests {
    use crate::dimension::Ix2;
    use crate::layout::{compute_f_strides, LayoutFlags};
    use crate::storage::Owned;
    use crate::tensor::TensorBase;

    fn f_contig(data: Vec<i32>, shape: Ix2, offset: usize)
        -> TensorBase<Owned<i32>, Ix2>
    {
        let strides = compute_f_strides(&shape);
        let storage = unsafe { Owned::from_vec(data) };
        let flags = LayoutFlags::F_CONTIGUOUS;
        unsafe { TensorBase::new_unchecked(storage, shape, strides, offset, flags, false) }
    }

    #[test]
    fn test_tensor_as_storage_ptr() {
        let tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2), 0);
        let ptr = tensor.as_storage_ptr();
        assert!(!ptr.is_null());
    }

    #[test]
    fn test_tensor_storage_len() {
        let tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2), 0);
        assert_eq!(tensor.storage_len(), 4);
    }

    #[test]
    fn test_tensor_as_ptr() {
        let tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2), 0);
        let ptr = tensor.as_ptr();
        assert!(!ptr.is_null());
        // offset == 0 → as_ptr == as_storage_ptr
        assert_eq!(ptr, tensor.as_storage_ptr());
    }

    #[test]
    fn test_tensor_as_mut_ptr() {
        let mut tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2), 0);
        let ptr = tensor.as_mut_ptr();
        assert!(!ptr.is_null());
        unsafe { *ptr = 99; }
        assert_eq!(tensor.as_slice().unwrap()[0], 99);
    }

    #[test]
    fn test_tensor_as_storage_mut_ptr() {
        let mut tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2), 0);
        let ptr = tensor.as_storage_mut_ptr();
        assert!(!ptr.is_null());
    }

    #[test]
    fn test_tensor_as_slice() {
        let tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2), 0);
        assert_eq!(tensor.as_slice().unwrap(), &[1, 2, 3, 4]);
    }

    #[test]
    fn test_tensor_as_mut_slice() {
        let mut tensor = f_contig(vec![1, 2, 3], Ix2(1, 3), 0);
        tensor.as_mut_slice().unwrap()[1] = 9;
        assert_eq!(tensor.as_slice().unwrap(), &[1, 9, 3]);
    }

    /// Empty tensor returns `Some(&[])` per §5.5 L537.
    #[test]
    fn test_tensor_as_slice_empty() {
        let tensor = f_contig(Vec::<i32>::new(), Ix2(0, 3), 0);
        let slice = tensor.as_slice().expect("empty tensor must yield Some(&[])");
        assert!(slice.is_empty());
    }

    /// Empty mutable tensor returns `Some(&mut [])` per §5.5 L559.
    #[test]
    fn test_tensor_as_mut_slice_empty() {
        let mut tensor = f_contig(Vec::<i32>::new(), Ix2(0, 3), 0);
        let slice = tensor.as_mut_slice().expect("empty tensor must yield Some(&mut [])");
        assert!(slice.is_empty());
    }

    /// Non-contiguous (e.g. transposed) → as_slice returns None.
    #[test]
    fn test_tensor_as_slice_non_contiguous() {
        let shape = Ix2(2, 2);
        let storage = unsafe { Owned::from_vec(vec![1_i32, 2, 3, 4]) };
        // Fabricate non-F-contiguous flags (transpose-like) — empty flags.
        let tensor: TensorBase<Owned<i32>, Ix2> = unsafe {
            TensorBase::new_unchecked(
                storage,
                shape,
                compute_f_strides(&shape),
                0,
                LayoutFlags::empty(),
                false,
            )
        };
        assert!(tensor.as_slice().is_none());
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `as_ptr()` / `as_mut_ptr()` 对空张量返回 `NonNull::dangling().as_ptr()`，不对 storage base 做 `add(offset)` | `07-tensor.md §6.2` L1200 — 空张量做 `add(offset)` 会触发 UB（不在已分配对象内） |
| `as_storage_ptr()` / `as_storage_mut_ptr()` 返回 storage base，**不**应用 `offset` | `07-tensor.md §5.4` L465-476 / L500-511 — 与 `as_ptr` 形成显式分工 |
| 新增 `storage_len()` 方法（`Storage` impl 块） | `07-tensor.md §5.4` L478-484 —— raw-parts 与 view 构造路径都依赖它 |
| 空张量 `as_slice()` / `as_mut_slice()` 返回 `Some(&[])` 而非 `None` | `07-tensor.md §5.5` L537 / L559 — 空切片是合法零拷贝快路径 |
| 非空快路径要求 `is_f_contiguous() && !has_zero_stride()` | `07-tensor.md §5.5` L523-528 —— precondition 3 (logical-first 指针) 由构造期 `compute_layout_flags` 保证 |
| 指针算术用 `add` 而非 `wrapping_add` | `validate_access_range`（W8T7）已保证 `offset` 在 storage 范围内，无需 wrapping |

## 注意事项

- 空张量 `as_slice()` 的 `slice::from_raw_parts(dangling, 0)` 在 03-element 约定的「非 ZST 元素集」上是 well-defined（参见 `07-tensor.md §5.5` L539-543）。
- `StorageMut` bound 排除了 `ViewRepr` 和 `ArcRepr` —— 它们没有 `as_mut_slice`/`as_mut_ptr`/`as_storage_mut_ptr`。
- `as_slice()` / `as_mut_slice()` 的 `len()` 调用依赖 W8T4 已实现的 `shape.checked_size().expect(...)`。
- 实现中**直接读 `self.flags` 字段**调用 `LayoutFlags::is_f_contiguous` / `has_zero_stride`（W6T5 提供），**不**借用 W8T5 的 TensorBase 委托方法。这样 W8T6 严格只依赖 W8T4（按 SUMMARY.md / PLAN.md 批次4 中 W8T5 与 W8T6 并行的安排）。
