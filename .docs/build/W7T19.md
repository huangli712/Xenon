## 实施步骤

### Step 1: Add module-level storage tests in src/storage/mod.rs

In `src/storage/mod.rs` `#[cfg(test)] mod tests`, add module sanity, sealed marker, and conversion matrix coverage from `05-storage.md` §5.10 and §5.11.

```rust
#[test]
fn test_storage_module_compiles() {
    let owned = Owned::from_vec(vec![1_i32, 2, 3]).unwrap();
    let view = ViewRepr::from_slice(owned.as_slice());
    let shared = ArcRepr::try_from(vec![1_i32, 2, 3]).unwrap();

    assert_eq!(view.as_slice(), &[1, 2, 3]);
    assert_eq!(shared.as_slice(), &[1, 2, 3]);
}

#[test]
fn test_marker_traits_sealed() {
    fn assert_owned<T: IsOwned>() {}
    fn assert_view<T: IsView>() {}
    fn assert_view_mut<T: IsViewMut>() {}
    fn assert_shared<T: IsShared>() {}

    assert_owned::<Owned<i32>>();
    assert_view::<ViewRepr<'_, i32>>();
    assert_view_mut::<ViewMutRepr<'_, i32>>();
    assert_shared::<ArcRepr<i32>>();
}

#[test]
fn test_storage_into_owned_matrix() {
    let owned = Owned::from_vec(vec![1_i32, 2, 3]).unwrap();
    let shared = owned.clone().into_shared();
    let owned_view = ViewRepr::from_slice(owned.as_slice());
    let copied_from_view = owned_view.into_owned_storage();
    let shared_view = ViewRepr::from_slice(shared.as_slice());
    let copied_from_shared = shared.clone().into_owned_storage();

    assert_eq!(owned.as_slice(), &[1, 2, 3]);
    assert_eq!(shared.as_slice(), &[1, 2, 3]);
    assert_eq!(owned_view.as_slice(), &[1, 2, 3]);
    assert_eq!(copied_from_view.as_slice(), &[1, 2, 3]);
    assert_eq!(shared_view.as_slice(), &[1, 2, 3]);
    assert_eq!(copied_from_shared.as_slice(), &[1, 2, 3]);
}
```

### Step 2: Add Owned tests in src/storage/owned.rs

In `src/storage/owned.rs` `#[cfg(test)] mod tests`, cover constructors, alignment, deep clone, thread traits, shared conversion, ZST, and empty storage from `05-storage.md` §6.2 and §8.2.

Test functions:

- `test_owned_new` — empty storage has `len() == 0`
- `test_owned_zeros` — zero-initialized numeric storage has requested length and zero content
- `test_owned_from_vec` — input `Vec` is copied into owned aligned storage
- `test_owned_from_elem` — repeated element construction fills all slots
- `test_owned_alignment_from_zeros` — `as_ptr() as usize % 64 == 0`
- `test_owned_alignment_from_vec` — `as_ptr() as usize % 64 == 0`
- `test_owned_clone_deep` — clone allocates independent backing storage and preserves content
- `test_owned_send_sync` — compile-time `Send + Sync` assertion
- `test_owned_into_shared` — `Owned::into_shared()` preserves content through `ArcRepr`
- `test_owned_zst_zeros_1000` — `Owned::<()>::zeros(1000)` reports length without allocation UB
- `test_owned_empty` — `Owned::<f64>::new().len() == 0` and pointer is non-null dangling

### Step 3: Add View and ViewMut tests in src/storage/view.rs and src/storage/viewmut.rs

In `src/storage/view.rs` and `src/storage/viewmut.rs`, cover borrowed read-only and exclusive mutable semantics from `05-storage.md` §5.1, §6.5, and §6.6.

Test functions:
