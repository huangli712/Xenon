## 目标

在 W6 范围内验证 layout 各子模块协同工作：

1. `compute_f_strides` 产出的 strides 必然被 `is_f_contiguous` 识别为 F-连续（§5.6 与 §5.7 的"构造-识别对称性"）。
2. `compute_layout_flags`（W6T11）在四种主要调用上下文（construction / broadcast / shape / index）下产出正确分类（§5.12 调用方清单）。
3. 空数组、size=1 轴、广播零步长三类边界场景的 flag 行为（§5.11 边界情形表）。

跨模块（tensor / shape / index / ffi / simd）的集成测试不在 W6T10 范围内 —— 这些测试文件由 W29（Integration Tests）创建并维护。W6T10 不假设它们已存在。

参照 `docs/design/06-layout.md §5.7`、§5.11、§5.12、§8.4（属性不变量）、§8.5（集成测试表）。

## 实施步骤

### Step 1: In-module integration test in `src/layout/mod.rs`

在 W6T1 已经写入的 `#[cfg(test)] mod tests { ... }` 之后追加一个**独立命名**的 `#[cfg(test)] mod integration_tests { ... }`（避免与 W6T1 的 `mod tests` 重名冲突）。集成测试访问 layout 公开 API + crate-internal `compute_layout_flags`。

```rust
// Append to `src/layout/mod.rs` (after the W6T1 `mod tests { ... }` block).

#[cfg(test)]
mod integration_tests {
    use super::*;
    use crate::dimension::{Ix0, Ix2, Ix3};

    // === Construction context (§5.12 row 4) ===

    #[test]
    fn test_layout_integration_construction_f_order() {
        // §5.6/§5.7 symmetry: compute_f_strides ⇒ is_f_contiguous == true.
        let shape = Ix3(2, 3, 4);
        let strides = compute_f_strides(&shape).unwrap();
        assert_eq!(strides.as_slice(), &[1, 2, 6]);
        assert!(is_f_contiguous(&shape, &strides));

        // §5.12: compute_layout_flags on this layout ⇒ F_CONTIGUOUS bit set,
        // HAS_ZERO_STRIDE clear; classify ⇒ FContiguous.
        // Pointer alignment is undefined here; test only the contiguity bit.
        let dangling = core::ptr::NonNull::<u8>::dangling().as_ptr() as *const u8;
        let flags = compute_layout_flags::<u8, Ix3>(&shape, &strides, dangling);
        assert!(flags.is_f_contiguous());
        assert!(!flags.has_zero_stride());
        assert_eq!(flags.classify(), LayoutState::FContiguous);
    }

    // === Broadcast context (§5.11 + §5.12 row 1) ===

    #[test]
    fn test_layout_integration_broadcast_view() {
        // Non-empty broadcast view: shape [5, 4], strides [1, 0].
        let shape = Ix2(5, 4);
        let strides = Strides::new(Ix2(1, 0));
        let dangling = core::ptr::NonNull::<u8>::dangling().as_ptr() as *const u8;
        let flags = compute_layout_flags::<u8, Ix2>(&shape, &strides, dangling);
        assert!(flags.has_zero_stride());
        // §5.11: broadcast view ⇒ NOT F_CONTIGUOUS.
        assert!(!flags.is_f_contiguous());
        assert_eq!(flags.classify(), LayoutState::BroadcastView);
    }

    #[test]
    fn test_layout_integration_empty_degenerate_zero_stride() {
        // §5.11 boundary: empty shape `[0, 3]` with degenerate zero stride
        // ⇒ HAS_ZERO_STRIDE MUST stay false; F_CONTIGUOUS may stay true.
        let shape = Ix2(0, 3);
        let strides = Strides::new(Ix2(1, 0));
        let dangling = core::ptr::NonNull::<u8>::dangling().as_ptr() as *const u8;
        let flags = compute_layout_flags::<u8, Ix2>(&shape, &strides, dangling);
        assert!(!flags.has_zero_stride(),
                "empty array degenerate zero stride must NOT set HAS_ZERO_STRIDE");
        assert!(flags.is_f_contiguous(),
                "empty F-order metadata should remain F_CONTIGUOUS (§5.11)");
        // §5.9: empty tensor ⇒ ALIGNED true regardless of pointer.
        assert!(flags.is_aligned());
        assert_eq!(flags.classify(), LayoutState::FContiguous);
    }

    // === Shape (transpose) context (§5.12 row 2) ===

    #[test]
    fn test_layout_integration_transpose_non_contiguous() {
        // Transpose of [2, 3] (F-order strides [1, 2]) ⇒ shape [3, 2],
        // strides [2, 1] — no longer F-contiguous, no zero strides.
        let shape = Ix2(3, 2);
        let strides = Strides::new(Ix2(2, 1));
        let dangling = core::ptr::NonNull::<u8>::dangling().as_ptr() as *const u8;
        let flags = compute_layout_flags::<u8, Ix2>(&shape, &strides, dangling);
        assert!(!flags.is_f_contiguous());
        assert!(!flags.has_zero_stride());
        assert_eq!(flags.classify(), LayoutState::NonContiguous);
    }

    // === Index (slice) context (§5.12 row 3) ===

    #[test]
    fn test_layout_integration_slice_size1_axis() {
        // size=1 axis along axis 1 with arbitrary stride; full layout
        // still F-contiguous (§5.7 size=1 axis rule).
        let shape = Ix3(5, 1, 4);
        let strides = Strides::new(Ix3(1, 999, 5));
        let dangling = core::ptr::NonNull::<u8>::dangling().as_ptr() as *const u8;
        let flags = compute_layout_flags::<u8, Ix3>(&shape, &strides, dangling);
        assert!(flags.is_f_contiguous());
        assert!(!flags.has_zero_stride());
    }

    // === Scalar / 0-D ===

    #[test]
    fn test_layout_integration_scalar() {
        // §5.11 boundary: 0-D scalar (`product == 1`) ⇒ F-contiguous,
        // no zero stride; alignment depends on pointer (use aligned alloc).
        let shape = Ix0;
        let strides = Strides::new(Ix0);
        let dangling = core::ptr::NonNull::<u8>::dangling().as_ptr() as *const u8;
        let flags = compute_layout_flags::<u8, Ix0>(&shape, &strides, dangling);
        assert!(flags.is_f_contiguous());
        assert!(!flags.has_zero_stride());
        assert_eq!(flags.classify(), LayoutState::FContiguous);
    }
}
```

> 关于 `core::ptr::NonNull::<u8>::dangling()`：layout 模块 §6.5 明确允许 dangling pointer 用作对齐检查输入，因为 `is_aligned_to` 仅做整数 modulo、不解引用。

### Step 2: Create `tests/test_layout.rs` external integration

新建 `tests/test_layout.rs`，验证 layout 模块作为 crate 公共 API 的可用性（不依赖 `tensor` / `shape` / `index` / `ffi` / `simd` 等下游模块的存在）。`compute_layout_flags` 是 `pub(crate)`，在外部 integration test 中不可访问，因此外部测试只覆盖 `pub` API。

```rust
//! External integration tests for the layout module.
//!
//! Limited to the public layout API (`compute_f_strides`,
//! `is_f_contiguous`, `Strides::*`, `is_aligned*`, `LayoutFlags`,
//! `LayoutState`). The crate-internal `compute_layout_flags` and
//! `flags_for_f_layout` are exercised by the in-module
//! `integration_tests` mod inside `src/layout/mod.rs`.
//!
//! Per `06-layout.md §8.5`, cross-module integration with tensor / shape /
//! index / ffi / simd is owned by W29 (those test files are created in
//! W29Tx) — not by W6T10.

use xenon::dimension::{Ix2, Ix3};
use xenon::layout::{compute_f_strides, is_f_contiguous, LayoutFlags, LayoutState, Strides};

#[test]
fn external_f_strides_symmetry() {
    // §5.6/§5.7 round-trip on common shape patterns.
    let cases: [&dyn Fn() -> bool; 4] = [
        &|| {
            let shape = Ix3(2, 3, 4);
            let s = compute_f_strides(&shape).unwrap();
            s.as_slice() == [1, 2, 6] && is_f_contiguous(&shape, &s)
        },
        &|| {
            let shape = Ix2(3, 1);
            let s = compute_f_strides(&shape).unwrap();
            is_f_contiguous(&shape, &s)
        },
        &|| {
            let shape = Ix2(1, 3);
            let s = compute_f_strides(&shape).unwrap();
            is_f_contiguous(&shape, &s)
        },
        &|| {
            let shape = Ix2(4, 5);
            let s = compute_f_strides(&shape).unwrap();
            s.as_slice() == [1, 4] && is_f_contiguous(&shape, &s)
        },
    ];
    for (idx, case) in cases.iter().enumerate() {
        assert!(case(), "case {idx} failed F-order symmetry");
    }
}

#[test]
fn external_c_order_is_not_f_contiguous() {
    // [2, 3] with C-order strides [3, 1] ⇒ NOT F-contiguous.
    let shape = Ix2(2, 3);
    let c_strides = Strides::new(Ix2(3, 1));
    assert!(!is_f_contiguous(&shape, &c_strides));
}

#[test]
fn external_flags_default_classify_non_contiguous() {
    // Default flags (all zero) ⇒ classify() returns NonContiguous
    // (no F_CONTIGUOUS bit, no HAS_ZERO_STRIDE bit).
    let flags = LayoutFlags::default();
    assert_eq!(flags.classify(), LayoutState::NonContiguous);
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| in-module 集成测试用独立 mod 名 `integration_tests` | 避免与 W6T1 的 `mod tests` 在同一 `mod.rs` 内重定义 |
| 外部测试只在新建的 `tests/test_layout.rs` 内 | `tests/test_tensor.rs` 等其他文件由 W29 拥有，W6T10 不创建/不修改这些文件 |
| 外部测试不调用 `compute_layout_flags` | 该函数是 `pub(crate)`（§5.12）；外部 integration 测试无法访问 |
| in-module 集成测试覆盖 §5.12 四个调用上下文 | 设计文档明确：实现必须同时覆盖 broadcast / shape / index / construction；用对应 stride 模式构造各类场景 |
| 使用 `NonNull::<u8>::dangling()` 作为对齐参数 | §6.5 明确允许 dangling pointer 输入；不解引用 |

## 验证方式

1. 编译检查: `cargo check -p xenon --all-targets`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证（in-module）: `cargo test layout::integration_tests`
4. 测试验证（external）: `cargo test --test test_layout`
5. 全量回归: `cargo test --all-targets`

## 注意事项

- W6T10 **不**修改 `tests/test_tensor.rs` / `tests/test_shape.rs` / `tests/test_index.rs` / `tests/test_ffi.rs` / `tests/test_simd.rs`。这些文件归 W29 所有；W29 在添加 tensor/shape/index/ffi/simd 集成时按 §8.5 引用 layout 模块。
- in-module 测试访问 crate-internal 的 `compute_layout_flags` 与 `LayoutState::BroadcastView` 等符号；外部 integration 测试只能访问 `pub use` 列表。
- 集成测试中**不可**直接传入 `[usize; N]`：`Dimension` 仅由 `Ix0..Ix6`/`IxDyn` 实现。
- `tests/test_layout.rs` 由 W6T10 创建；该文件名与 W29 计划中的其他 `tests/test_*.rs` 不冲突（W29 未声明 `test_layout.rs`）。
- 集成测试**不**重复 in-module 单元测试的覆盖内容（只验证跨子模块协同与 `compute_layout_flags` 调用上下文）。
