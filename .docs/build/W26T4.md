## 目标

在 `src/format/display.rs` 中：
1. 定义 `TensorDisplay<'a, S, D, A>` 包装结构（设计 §5.2）；
2. 为 `TensorBase` 实现 `display_with(config)` 入口；
3. 为 `TensorBase` 与 `TensorDisplay` 分别实现 `core::fmt::Display`，按 ndim 三分支（0D / 1D / ND）路由到 W26T3 helper（设计 §5.3）。

### Step 2: Define TensorDisplay wrapper + display_with

新建 `src/format/display.rs`：

```rust
use core::fmt;

use crate::dimension::Dimension;
use crate::element::Element;
use crate::storage::Storage;
use crate::tensor::TensorBase;

use super::config::FormatConfig;
use super::pretty::{fmt_1d_display, fmt_nd_display, fmt_scalar_display, read_logical};

/// A wrapper that formats a tensor with a specific [`FormatConfig`].
///
/// Constructed via [`TensorBase::display_with`]. Implements [`core::fmt::Display`]
/// so it can be used directly in `format!` / `write!` macros.
pub struct TensorDisplay<'a, S, D, A>
where
    S: Storage<Elem = A>,
    D: Dimension,
{
    tensor: &'a TensorBase<S, D>,
    config: FormatConfig,
}

impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Element,
{
    /// Returns a display wrapper that formats this tensor with the given config.
    ///
    /// # Examples
    ///
    /// ```ignore
    /// let tensor = Tensor1::from_shape_vec([3], vec![1.0_f64, 2.0, 3.0]).unwrap();
    /// let config = FormatConfig { precision: Some(2), ..Default::default() };
    /// println!("{}", tensor.display_with(config));
    /// ```
    pub fn display_with(&self, config: FormatConfig) -> TensorDisplay<'_, S, D, A> {
        TensorDisplay { tensor: self, config }
    }
}
```

### Step 3: Implement Display for TensorBase and TensorDisplay

按设计 §5.3 line 235-249 在 Display impl 内直接按 `ndim()` 分支；**不引入** `fmt_display_with_config` 中间 helper（保持 W26T3 暴露的 helper 集合不变）。

```rust
impl<S, D, A> fmt::Display for TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Element + fmt::Display,
{
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        format_tensor_display(f, self, FormatConfig::default())
    }
}

impl<'a, S, D, A> fmt::Display for TensorDisplay<'a, S, D, A>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Element + fmt::Display,
{
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        format_tensor_display(f, self.tensor, self.config)
    }
}

/// Internal Display dispatch: 0D → `Tensor0(...)`; 1D → `fmt_1d_display`;
/// ND (n ≥ 2) → `fmt_nd_display`. Mirrors `22-output §5.3` line 235-249.
fn format_tensor_display<S, D, A>(
    f: &mut fmt::Formatter<'_>,
    tensor: &TensorBase<S, D>,
    config: FormatConfig,
) -> fmt::Result
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Element + fmt::Display,
{
    match tensor.ndim() {
        0 => {
            // §5.3 line 237-242 + 决策 3 line 793-799: explicit Tensor0(...) marker.
            write!(f, "Tensor0(")?;
            fmt_scalar_display(f, read_logical(tensor, &[]), config)?;
            write!(f, ")")
        }
        1 => fmt_1d_display(f, tensor, config),
        _ => fmt_nd_display(f, tensor, config),
    }
}
```

> **关于 `format_tensor_display`**: 这是 `src/format/display.rs` **模块内私有**的小调度器，仅服务于本文件两个 Display impl。它**不是**跨模块 helper，因此不需要在 W26T3 中预先声明 ── 这与原方案错误声明的 `fmt_display_with_config`（M3 缺陷）不同。

#[cfg(test)]
mod tests {
    use super::*;
    use crate::complex::Complex;
    use crate::tensor::{Tensor0, Tensor1};

    #[test]
    fn test_display_tensor() {
        let tensor = Tensor1::from_shape_vec([3], vec![1, 2, 3]).unwrap();
        assert_eq!(format!("{}", tensor), "[1, 2, 3]");
    }

    #[test]
    fn test_fmt_float_precision() {
        let tensor = Tensor1::from_shape_vec([1], vec![1.234_f64]).unwrap();
        let config = FormatConfig { precision: Some(2), ..Default::default() };
        assert_eq!(format!("{}", tensor.display_with(config)), "[1.23]");
    }

    #[test]
    fn test_fmt_zero_dim() {
        // 18-construction.md §5 — Tensor0::from_scalar returns Result.
        let tensor = Tensor0::from_scalar(42_i32).unwrap();
        assert_eq!(format!("{}", tensor), "Tensor0(42)");
    }

    /// 22-output.md §8.2 line 681 (中优先级) — 复数默认格式化
    /// (正虚部)。验证 W5T7 `Complex<T>::Display` 通过 W26T4 routing
    /// 进入张量输出后仍遵守 §6.1 line 502-515 的拼接规则。
    #[test]
    fn test_display_complex_f64() {
        let tensor = Tensor1::from_shape_vec(
            [2],
            vec![Complex::new(1.0_f64, 2.0_f64), Complex::new(3.0_f64, 4.0_f64)],
        )
        .unwrap();
        // Rust f64 Display: `1.0_f64` 默认输出 "1"；Complex Display 在 im≥0
        // 时 拼接符 为 "+"（§6.1 line 504 row）。
        assert_eq!(format!("{}", tensor), "[1+2j, 3+4j]");
    }

    /// 22-output.md §8.2 line 682 (中优先级) — 复数负虚部拼接。
    /// 验证 §6.1 line 507 row：im<0 时 `is_sign_negative()` 选择 "-"。
    #[test]
    fn test_display_complex_negative_imag() {
        let tensor = Tensor1::from_shape_vec(
            [2],
            vec![Complex::new(1.0_f64, -2.0_f64), Complex::new(-3.0_f64, -4.0_f64)],
        )
        .unwrap();
        // im=-2 选 "-"， mag=|im|=2 输出“2”（f64 Display 默认）。
        // im=-4 同理。§6.1 line 514-515：`im.abs()` 统一幅值。
        assert_eq!(format!("{}", tensor), "[1-2j, -3-4j]");
    }

    /// 22-output.md §8.3 line 703 — NaN/Inf 边界场景。
    /// 验证浮点特殊值通过 W26T3 `fmt_scalar_display` 委托到 Rust
    /// 默认 `f64::Display`：NaN→"NaN", ±∞→"±inf"（§6.1 line 378）。
    #[test]
    fn test_display_nan_inf_f64() {
        let tensor = Tensor1::from_shape_vec(
            [3],
            vec![f64::NAN, f64::INFINITY, f64::NEG_INFINITY],
        )
        .unwrap();
        assert_eq!(format!("{}", tensor), "[NaN, inf, -inf]");
    }
}

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `TensorDisplay` 采用 3 类型参数 `<'a, S, D, A>` | `22-output §5.2` line 167-174 显式声明 3 参 wrapper |
| `display_with` 加 `A: Element` bound | 与 §5.2 line 176-181 完整 bound 集对齐，避免推断失败 |
| Display impl 内直接按 ndim 三分支，不抽 cross-module helper | `22-output §5.3` line 235-249；避免 W26T3 暴露面扩散 |
| 0D 张量输出 `Tensor0(...)` 显式标记 | `22-output §5.5` line 370-374 与决策 3 line 793-799；区分裸标量 |
| `Tensor0` 通过 `from_scalar(value).unwrap()` 构造 | `18-construction.md` line 486-506：`from_scalar` 返回 `Result` |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test --lib format::display::tests`
4. 手动验证: `println!("{}", tensor)` 与 `println!("{}", tensor.display_with(config))` 分别输出默认和自定义格式；构造 `Tensor0::from_scalar(42).unwrap()`，确认输出 `Tensor0(42)`。

## 注意事项

- Display 面向用户：仅数据 + 截断后缀，不输出 shape/strides/dtype/layout（那些归 Debug，W26T5）。
- 零维张量输出 `Tensor0(...)`，避免与裸标量混淆。
- 不要给 Display impl 加 `std` feature gate（设计 §5.3 line 215）。
- `display_with(config)` 必须返回 `TensorDisplay<'_, S, D, A>` 而**不是** `TensorDisplay<'_, S, D>` ── 类型参数 A 由设计 §5.2 显式声明（修复 W26T4 早期版本的 S3 缺陷）。
