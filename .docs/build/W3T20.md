## 目标

按 `02-dimension.md` §8.5 line 1123 规划，`tests/test_index.rs` 用于覆盖 dimension 与索引/切片入口的 `D: Dimension` bound 协同验证。其中 Tensor 索引/切片 API 在 W11+ 引入，**本 W3 阶段尚不存在**——本 task 采用**占位 + 后置激活**策略：

- **W3 可运行**：dimension 层的索引数据契约（`Ix1` 和 `Ix2` 的 `Index<usize>`、所有静态/动态维度的 `axis()` 访问、`Axis` helper 方法在索引语境中的应用）。
- **W11+ 激活**：用 `#[ignore]` 占位 Tensor 索引/切片路径。

`Index<usize>` 在本 W3 阶段仅 `Ix1` 和 `Ix2` 实现（W3T5/W3T6），更高维度（Ix3-Ix6）**不**实现 `Index<usize>`——访问轴长度统一通过 `axis(Axis)` 方法。本 task 在测试中明确该 API 边界。

本 task **不**重复 W3T2 已覆盖的 `Axis` 单元测试（`test_axis_next_prev`、`test_axis_checked_next`、`test_axis_is_first_last`）。

### Step 2: W3 可运行的 Index / axis 访问测试

```rust
/// `Index<usize>` impl on Ix1 (per W3T5 / §5.4).
#[test]
fn test_ix1_index_via_usize() {
    let d = Ix1(42);
    assert_eq!(d[0], 42);
}

/// `Index<usize>` impl on Ix2 (per W3T6 / §5.4).
#[test]
fn test_ix2_index_via_usize() {
    let d = Ix2(10, 20);
    assert_eq!(d[0], 10);
    assert_eq!(d[1], 20);
}

/// Ix1 out-of-bounds index panics per Index<usize> default semantics.
#[test]
#[should_panic]
fn test_ix1_index_out_of_bounds_panics() {
    let d = Ix1(5);
    let _ = d[1];
}

/// Ix2 out-of-bounds index panics.
#[test]
#[should_panic]
fn test_ix2_index_out_of_bounds_panics() {
    let d = Ix2(5, 6);
    let _ = d[2];
}

/// `Dimension::axis(Axis)` is the canonical API for axis access on all
/// dimension types (Ix0-Ix6, IxDyn). Higher-rank static types (Ix3-Ix6) do
/// NOT implement `Index<usize>` — verify via `axis()`.
#[test]
fn test_higher_rank_axis_access_uses_axis_method() {
    let d3 = Ix3(2, 3, 4);
    assert_eq!(d3.axis(Axis::new(0)), Ok(2));
    assert_eq!(d3.axis(Axis::new(1)), Ok(3));
    assert_eq!(d3.axis(Axis::new(2)), Ok(4));
    assert!(matches!(d3.axis(Axis::new(3)), Err(XenonError::InvalidAxis { .. })));
}

/// IxDyn axis access via `axis()` (Index<usize> not implemented on IxDyn).
#[test]
fn test_ixdyn_axis_access() {
    let d = IxDyn::from_vec(vec![7, 8, 9]);
    assert_eq!(d.axis(Axis::new(0)), Ok(7));
    assert_eq!(d.axis(Axis::new(1)), Ok(8));
    assert_eq!(d.axis(Axis::new(2)), Ok(9));
    assert!(matches!(d.axis(Axis::new(3)), Err(XenonError::InvalidAxis { .. })));
}

/// Ix0 axis access always fails: scalar has no axes.
#[test]
fn test_ix0_axis_access_always_invalid() {
    assert!(matches!(Ix0.axis(Axis::new(0)), Err(XenonError::InvalidAxis { .. })));
}

/// `Axis` navigation in indexing context: traversing axes of an Ix3.
#[test]
fn test_axis_navigation_traverses_dimensions() {
    let d = Ix3(2, 3, 4);
    let mut current = Axis::new(0);
    let mut visited: Vec<usize> = Vec::new();
    loop {
        match d.axis(current) {
            Ok(len) => visited.push(len),
            Err(_) => break,
        }
        match current.next() {
            Some(n) if n.index() < d.ndim() => current = n,
            _ => break,
        }
    }
    assert_eq!(visited, vec![2, 3, 4]);
}
```

## 关键设计决策

1. 依据 `02-dimension.md` §5.4，**仅** `Ix1` 和 `Ix2` 实现 `Index<usize>`（W3T4/W3T5 完成）；Ix3-Ix6 与 IxDyn **不**实现 `Index<usize>`，统一通过 `axis(Axis)` 访问。本 task 在测试中明确该 API 边界。
2. 依据 §5.1 lines 162-169，`Dimension::axis(Axis)` 返回 `Result<usize, XenonError>`：合法轴 `Ok(length)`，越界 `Err(InvalidAxis)`。**禁止**测试中使用 `Option` 形式。
3. 依据 §5.7，`Axis::next` / `prev` 等导航方法在索引语境中用于遍历轴；W3T2 已实现 `Axis` 自身的单元测试，本 task 在 `test_axis_navigation_traverses_dimensions` 中演示 `Axis` + `Dimension::axis()` 协同——这是 W3T2 测试之外的新场景。
4. `Index<usize>` 越界 panic 与 Rust 默认 `Index` trait 行为一致，使用 `#[should_panic]` 测试覆盖。
5. **W11+ 激活点** 使用 `#[ignore]` panic 占位。
6. 本 task 与 W3T17/W3T18/W3T19 边界：W3T17 白盒、W3T18 IntoDimension 兼容性、W3T19 shape contract + axis 协同、W3T20 **索引专用**（`Index<usize>` + axis 在索引语境中的使用）。**互不重叠**。

## 注意事项

- **`Index<usize>` 仅在 Ix1/Ix2 上实现**；Ix3-Ix6 与 IxDyn 不实现。设计依据 §5.4。
- `Dimension::axis(Axis)` 返回 `Result`；**禁止**测试中使用 `Some(..)/None`。
- 占位测试必须 `panic!` 加明确消息。
- W11+ 实施者完成 Tensor 索引/切片 API 时，必须移除对应 `#[ignore]`。
- 本 task 与 W3T2 的 `Axis` 单元测试**不重叠**——W3T2 测试 `Axis` 方法本身，本 task 测试 `Axis` 与 `Dimension::axis()` 的协同。
