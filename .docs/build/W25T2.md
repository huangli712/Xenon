## 目标

ConvertTo sealed trait signature + CastTo ownership doc: trait signatures only, no impls

按照 `build/SUMMARY.md` 中 W25T2 的定义，在 `src/convert/cast.rs` 中声明 `ConvertTo` sealed trait 签名，并在 `src/convert/mod.rs` 中补上对应的 `pub(crate) use` 再导出。需保持与 `docs/design/21-type.md` §5（公共 API）、§6（实现细节）、§7（任务拆分/约束）和 §8（测试计划）一致。

## 前置准备

- 完成 W25T1（`src/convert/mod.rs` 已声明 `mod cast;`，`src/convert/cast.rs` 占位文件已存在）。
- 确认 `private::Sealed`、`CastElement` 和 `CastTo` 已由 element 模块提供。

## 实施步骤

### Step 1: Define crate-private ConvertTo shim

替换 `src/convert/cast.rs` 中 W25T1 留下的占位内容，加入 sealed trait 签名。trait 必须 crate-private，不得为外部 crate 暴露新的转换扩展点。

```rust
//! Type conversion implementation.
//!
//! The public `CastTo` and `CastElement` traits are owned by `crate::element`;
//! this module only provides tensor-level conversion dispatch and the crate-private `ConvertTo` shim.

use crate::element::CastElement;
use crate::error::Result;

pub(crate) trait ConvertTo<B>: CastElement
where
    B: CastElement,
{
    fn convert(self) -> Result<B>;
}
```

### Step 2: Re-export ConvertTo from convert module root

在 `src/convert/mod.rs` 的 `mod cast;` 下方补上 crate-private 再导出。该 `pub(crate) use` 之所以从 W25T1 推迟到本 task 落地，是因为 W25T1 时 trait 尚未定义；只有等本 task 引入 trait 签名后再添加，才能保证每个 task 单独执行都可通过 `cargo check`。

```rust
mod cast;

pub(crate) use cast::ConvertTo;
```

### Step 3: 单元测试

参考 `docs/design/21-type.md` 的「测试计划」为 trait signature 增加 compile-only test helper，后续 impl task 会补充行为测试。

> **强制要求**:
> - 本步骤必须包含一个或者多个单元测试。
> - 测试函数名称和测试内容必须参考对应设计文档的 **「测试计划」** 一节。
> - 编译检查与Lint检查不等同于单元测试。
> - 如果测试没有通过需要修复直至测试通过。
> - **无测试 = 任务未完成。**

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_convert_to_trait_signature_accepts_cast_elements() {
        fn require_cast_element<A: CastElement>() {}
        require_cast_element::<i32>();
        require_cast_element::<f64>();
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `ConvertTo` 用 `pub(crate)` 且通过 `CastElement: Element: Sealed` 链结构化封闭 | `21-type §5.1` + `03-element §5.9.1` 内部分流，防止外部 crate 扩展转换矩阵 |
| trait 签名 `convert(self) -> Result<B>` 返回 Result，非裸值 | `21-type §6.1.3` Tier-1 identity 也统一 Ok 路径 |
| 本 task 仅声明签名，不实现任何 impl | `21-type §7 T1` impl 跨越 W25T3-W25T5，每个 task 负责一个 tier |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test test_convert_to_trait_signature_accepts_cast_elements`
4. 手动验证: 确认 `cargo doc` 中不出现公开 `ConvertTo` API。

## 注意事项

- 本 task 必须在 `src/convert/mod.rs` 同步补上 `pub(crate) use cast::ConvertTo;` 再导出，否则 crate 内其它模块无法解析 `crate::convert::ConvertTo`。
- 本 task 不实现任何转换矩阵 cell，避免和 W25T3-W25T5 重叠。
- `ConvertTo` 返回 `Result<B>`，不要让 Tier-1 走 panic 或不可恢复路径。
- `bool` 不能满足 `CastElement`，不要为它设计例外路径。
