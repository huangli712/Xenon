## 目标

StrideState: F-order index increment state machine。

实现 `10-iterator.md §6.2` 描述的 F-order 索引递增状态机，作为 `Iter` / `IterMut` / `IndexedIter` 的内部驱动。**`StrideState` 是 §6.1 / §6.2 的内部实现细节，使用 `pub(crate)` 可见性，不进入 `pub use`**（W12T1 已对齐）。

## 前置准备

- W12T1 已建立 `src/iter/{mod.rs, elements.rs, axis.rs, indexed.rs}` 骨架。
- `Dimension`、`Ix0`~`Ix6`、`IxDyn` 已可用（02-dimension §5）；本 task 暂以 `&[usize]` 作为 shape 输入，方便后续 W12T3 / W12T4 直接对 `view.shape()`（`&[usize]`）取用。
- 索引存储采用 `Vec<usize>`：状态机在 `IxDyn` 与所有静态 `Ix*` 上统一工作；W12T6 在产出索引时再按 `D::try_from_slice(&index_slice).expect(...)` 转回 `D`（参见 02-dimension §5.1 `Dimension::try_from_slice`；`IxDyn` 另有 inherent `from_slice` 便捷构造，参见 02-dimension §5.5）。

## 实施步骤

### Step 1: 实现 F-order 状态机数据结构与递增逻辑

按照 `10-iterator.md §6.2` 的伪码实现 `advance()`：从最低轴（轴 0）开始 +1，若达到该轴 shape 则归零并向更高轴进位；所有轴都进位完毕则置 `finished = true`。零维张量 (`shape = []`) 视为"产出 1 个空索引后立即结束"，因此初始 `finished = false`，调用一次 `advance()` 后转 `finished = true`。空数组 (`shape` 中任一 dim 为 0) 视为"零产出"，初始即 `finished = true`。

```rust
//! Flat element iterators and the F-order stride state machine that drives them.
//!
//! `StrideState` is an internal implementation detail (see `10-iterator.md §6.1`,
//! §6.2`). It is `pub(crate)` so `IndexedIter` / `Iter` in sibling modules can
//! reuse it without leaking the type into the public API surface.

#[derive(Debug, Clone)]
pub(crate) struct StrideState {
    shape: Vec<usize>,
    index: Vec<usize>,
    finished: bool,
}

impl StrideState {
    /// Build a new state for the given shape.
    ///
    /// Empty shape (`Ix0` / rank-0 `IxDyn`) starts at the empty index and yields
    /// exactly one position before finishing. Shapes containing a zero dimension
    /// start as finished (zero yields total). See `10-iterator.md §6.2` and
    /// §8.3 boundary scenarios.
    pub(crate) fn new(shape: &[usize]) -> Self {
        let finished = shape.iter().any(|&dim| dim == 0);
        Self {
            shape: shape.to_vec(),
            index: vec![0; shape.len()],
            finished,
        }
    }

    /// Current logical index (length == `ndim`).
    pub(crate) fn index(&self) -> &[usize] {
        &self.index
    }

    /// Advance one step in F-order; mark finished after the last position.
    ///
    /// Implements the pseudocode in `10-iterator.md §6.2`:
    ///
    /// ```text
    /// for i in 0..ndim:
    ///     index[i] += 1
    ///     if index[i] < shape[i]:
    ///         return  // no carry
    ///     index[i] = 0  // carry to next dimension
    /// ```
    pub(crate) fn advance(&mut self) {
        if self.finished {
            return;
        }
        if self.shape.is_empty() {
            // Ix0 / rank-0 IxDyn: yield exactly one (empty) index, then finish.
            self.finished = true;
            return;
        }
        for axis in 0..self.shape.len() {
            self.index[axis] += 1;
            if self.index[axis] < self.shape[axis] {
                return;
            }
            self.index[axis] = 0;
        }
        // All axes carried out → exhausted.
        self.finished = true;
    }
}
```

### Step 2: 提供完成状态查询

```rust
impl StrideState {
    /// Whether the state machine has exhausted all logical positions.
    pub(crate) fn is_finished(&self) -> bool {
        self.finished
    }
}
```

对应设计文档：

- §8.3 「空数组 `shape=[0, 3]`：`iter()` 立即结束」与「零维张量 `Ix0`：产出 1 项」要求对应内部白盒测试 `test_stride_state_ix0`、`test_stride_state_empty`。

```rust
#[cfg(test)]
mod tests {
    use super::*;

    /// F-order increment: index[0] varies fastest; carry propagates to higher axes.
    /// Reference: 10-iterator §6.2.
    #[test]
    fn test_stride_state_increment() {
        let mut state = StrideState::new(&[2, 3]);
        assert!(!state.is_finished());
        assert_eq!(state.index(), &[0, 0]);

        state.advance();
        assert_eq!(state.index(), &[1, 0]);

        state.advance();
        // Carry from axis 0 (2 -> 0) into axis 1 (0 -> 1).
        assert_eq!(state.index(), &[0, 1]);

        state.advance();
        assert_eq!(state.index(), &[1, 1]);

        state.advance();
        assert_eq!(state.index(), &[0, 2]);

        state.advance();
        assert_eq!(state.index(), &[1, 2]);

        // Final advance exhausts the state machine.
        state.advance();
        assert!(state.is_finished());

        // Further advances are no-ops.
        state.advance();
        assert!(state.is_finished());
    }

    /// Ix0 / rank-0 IxDyn yields exactly one (empty) index before finishing.
    /// Reference: 10-iterator §8.3 "零维张量 `Ix0` / rank-0 `IxDyn`".
    #[test]
    fn test_stride_state_ix0() {
        let mut state = StrideState::new(&[]);
        assert!(!state.is_finished());
        assert_eq!(state.index(), &[] as &[usize]);

        state.advance();
        assert!(state.is_finished());
    }

    /// Empty array (`shape=[0, 3]`) finishes before producing any index.
    /// Reference: 10-iterator §8.3 "空数组 `shape=[0, 3]`".
    #[test]
    fn test_stride_state_empty() {
        let state = StrideState::new(&[0, 3]);
        assert!(state.is_finished());
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 状态机为内部实现细节，`pub(crate)` 可见 | 10-iterator §6.1 / §6.2 把它列为 "Internal fields"，不在 §5 公开 API 中暴露 |
| F-order 索引递增（轴 0 最快变化） | 10-iterator §6.2 提供原文伪码 |
| `shape = []` 初始未完成、调用 `advance()` 后完成（对应 Ix0 / rank-0 IxDyn 产出 1 项） | 10-iterator §5.1、§8.3 |
| `shape` 含 0 维时初始即 `finished = true`（对应空数组零产出） | 10-iterator §8.3 「空数组 `iter()` 立即结束」 |
| 多次调用 `advance()` 在 finished 状态下是幂等 no-op | 10-iterator §1.2 `ExactSizeIterator` 要求 `next()` 返回 `None` 时不再产出 |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test iter::elements::tests::test_stride_state_increment iter::elements::tests::test_stride_state_ix0 iter::elements::tests::test_stride_state_empty`
4. 手动验证: 在 REPL / 临时 binary 中构造 `StrideState::new(&[3, 2, 1])`，循环 `advance()` 直至 `is_finished()`，验证产出索引数量 == `product(shape) == 6`，顺序为 `[0,0,0], [1,0,0], [2,0,0], [0,1,0], [1,1,0], [2,1,0]`。

## 注意事项

- **绝不要在 `advance()` 函数体内嵌入 `#[test]`**——所有测试函数必须放在 `mod tests` 内，避免 W12T2 在历史草稿中出现的模板复制错误。
- 状态机对 `shape` 仅作 F-order 递增，**不**计算物理偏移；偏移计算由 `Iter` / `IterMut`（W12T3 / W12T4）基于 `view.strides()` + `view.offset()` 完成。
- `IxDyn` 与所有静态 `Ix*` 在本 task 统一以 `&[usize]` shape 入口处理；维度类型回写到 `D` 是 W12T6 `IndexedIter` 的职责。
- 不支持负步长（10-iterator §6.2 边界说明）；状态机本身不感知步长，只递增逻辑索引。
