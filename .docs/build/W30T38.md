### Step 2: 编写类型/函数级 doc comment

为目标 API 写入英文 `///` 文档，按 29-documentation §5.4.2 添加必要章节，并为 sealed public trait 添加 `# Sealed`。

- `from_shape_vec` 必须包含失败路径 doctest，并匹配 `XenonError::InvalidShape { kind: InvalidShapeKind::ElementCountMismatch, .. }`。

```rust
/// ```rust
/// # use xenon::prelude::*;
/// # use xenon::error::{InvalidShapeKind, XenonError};
/// # fn demo() -> xenon::Result<()> {
/// let eye = Tensor::<f64, _>::eye(3)?;
/// assert_eq!(eye.shape(), &[3, 3]);
/// let values = Tensor::<f64, _>::from_shape_vec([4], vec![1.0, 1.0, 2.0, 2.0])?;
/// // 实证 14-set.md §5.1 L181：`pub fn unique(&self) -> Tensor<A, Ix1>` 返 Tensor 非 Result，无需 `?`

/// let r = Tensor::<f64, _>::from_shape_vec([2, 3], vec![1.0, 2.0]);
/// assert!(matches!(
///     r,
///     Err(XenonError::InvalidShape { kind: InvalidShapeKind::ElementCountMismatch, .. })
/// ));
/// # Ok(())
/// # }
/// ```
```
