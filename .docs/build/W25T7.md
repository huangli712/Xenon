## 实施步骤

### Step 1: Implement to_owned canonical clone

Add `to_owned()` for all readable tensors. It must clone logical elements into a canonical F-order owned tensor, not preserve padding or offset. Use `from_shape_vec_aligned_unchecked` (as in `21-type.md §5.2`) for zero-overhead infallible construction — the iteration guarantees length/shape consistency (see §5.6 for the helper's safety contract).

```rust
impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Element + Clone,
{
    /// Clones logical elements into a new owned tensor in canonical F-order.
    ///
    /// Skips padding and offset; always allocates fresh storage.
    /// See `21-type.md §5.5` for the full doc surface (W30 will expand).
    pub fn to_owned(&self) -> Tensor<A, D> {
        let mut data: Vec<A> = Vec::with_capacity(self.len());
        for elem in self.iter().cloned() {
            data.push(elem);
        }
        // SAFETY: data.len() == self.len() == product(self.raw_dim()); see §5.6.
        // The unchecked path is infallible (no expect/panic needed) because the
        // loop invariant proves shape/data consistency.
        unsafe { Tensor::from_shape_vec_aligned_unchecked(self.raw_dim(), data) }
    }
}
```

### Step 2: Implement into_owned consume path via StorageIntoOwned

Use `StorageIntoOwned` trait dispatch (defined in `05-storage.md §5.9`) to avoid overlapping inherent impl blocks between `Tensor<A, D>` and `TensorBase<S, D>`. A single generic impl dispatches to storage-level `into_owned_storage()`:
- `Owned<A>` returns storage directly → zero-copy O(1)
- `ViewRepr` / `ViewMutRepr` / `ArcRepr` → O(n) allocate + copy

```rust
impl<S, D, A> TensorBase<S, D>
where
    S: StorageIntoOwned<Elem = A>,
    D: Dimension,
    A: Element + Clone,
{
    /// Consume the tensor into an owned tensor.
    ///
    /// - `Tensor` (S=Owned<A>): returned directly, O(1), same data
    /// - `TensorView` / `TensorViewMut` / `ArcTensor`: O(n) allocate+copy into canonical F-order
    pub fn into_owned(self) -> Tensor<A, D> {
        let owned_storage = self.storage.into_owned_storage();
        // Helper re-wraps Owned storage with inherited shape/strides/offset/flags
        // and re-derives canonical F-order metadata when needed (see Step 3).
        Self::into_owned_from_owned_storage(owned_storage, self.dim)
    }
}
```

### Step 3: Implement the `into_owned_from_owned_storage` helper (self-contained)

依据「前置准备」中的归属声明，该 helper 在 `src/convert/cast.rs` 内以 `pub(crate) fn` 形式自含实现。**不**作为 `TensorBase` 的 inherent method 公开，仅供本 task 的 `into_owned()` 调用。

行为契约：
1. 输入 `(owned_storage: Owned<A>, dim: D)`；
2. 通过 `layout::compute_f_strides(&dim)` 计算 canonical F-order strides；
3. 通过 `layout::compute_layout_flags(&dim, &strides, owned_storage.as_ptr())` 计算 flags；
4. 调用 `TensorBase::new_unchecked(owned_storage, dim, strides, /*offset=*/ 0, flags, /*derived_from_view_mut=*/ false)` 构造 `Tensor<A, D>`。

```rust
/// Reconstruct a canonical F-order `Tensor<A, D>` from an `Owned<A>` storage
/// produced by `StorageIntoOwned::into_owned_storage()`.
///
/// Self-contained helper local to the convert module; if `07-tensor.md` later
/// publishes an equivalent helper, migrate the body without changing callers.
///
/// # Safety
///
/// `into_owned_storage()` 已保证 `owned_storage.len() == product(dim)`，且
/// `dim` 来自一个有效的 `TensorBase`，因此 shape 不变式已满足。所有其它
/// 不变式由 `TensorBase::new_unchecked` 兜底（参见 `07-tensor.md §5.6`）。
pub(crate) fn into_owned_from_owned_storage<A, D>(
    owned_storage: crate::storage::Owned<A>,
    dim: D,
) -> crate::tensor::Tensor<A, D>
where
    A: crate::element::Element,
    D: crate::dimension::Dimension,
{
    let strides = crate::layout::compute_f_strides(&dim);
    let flags = crate::layout::compute_layout_flags(&dim, &strides, owned_storage.as_ptr());
    // SAFETY: see function-level safety doc above.
    unsafe {
        crate::tensor::TensorBase::new_unchecked(
            owned_storage,
            dim,
            strides,
            /* offset = */ 0,
            flags,
            /* derived_from_view_mut = */ false,
        )
    }
}
```

> 注意：上面 `Self::into_owned_from_owned_storage(...)` 在 `into_owned()` 中调用的是**模块级**函数，不是 trait 方法。若 `Self::` 路径在 inherent impl 内不可见，改写为 `into_owned_from_owned_storage(owned_storage, self.dim)` 即可（同模块自由函数）。

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_to_owned_from_view() {
        let tensor = Tensor1::from_shape_vec([3], vec![1, 2, 3]).unwrap();
        let owned = tensor.view().to_owned();
        assert_eq!(owned.to_vec(), vec![1, 2, 3]);
    }

    #[test]
    fn test_to_owned_from_arc() {
        let tensor = Tensor1::from_shape_vec([3], vec![1, 2, 3]).unwrap().to_shared();

        assert_eq!(owned.to_vec(), vec![4.0, 5.0]);
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `to_owned()` 跳过 padding/offset，产出 canonical F-order | `21-type §5.5` canonical 输出契约，后续 contiguous 快路径依赖 |
| `to_owned()` 输出走 `from_shape_vec_aligned_unchecked` infallible 构造 | `21-type §5.6` 循环一致性已证明形状/数据匹配，零额外检查开销 |
| `into_owned()` 使用 `StorageIntoOwned` trait dispatch 避免 inherent impl 冲突 | `05-storage §5.9` 单 impl block 覆盖 Owned(O(1))/View/Arc(O(n))，消除 coherence |
| `into_owned_from_owned_storage` 作为本模块 `pub(crate) fn` 自含实现 | 该 helper 当前未在 `07-tensor.md` 或 W8 任务清单中定义；本 task 自含以保证可独立完成 |
| 本 task 仅限同类型 owned 化，不添加 cross-type 或其他存储模式互转 | `21-type §7 T3` "不在本模块扩展 view/view_mut/into_shared" |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test test_to_owned_from_view test_to_owned_from_arc test_into_owned_tensor`
4. 手动验证: 对带 padding 或 offset 的 view 调用 `to_owned()`，确认输出 `offset == 0` 且 F-contiguous。

## 注意事项

- `to_owned()` 是同类型 owned 化，不是 `cast()` 的 bool 替代扩展。
- 输出必须 canonical，否则 W24T4 的 `to_contiguous()` 快路径会失效。
- `into_owned()` 依赖 `StorageIntoOwned` trait（W7），确保 `05-storage.md §5.9` 的 trait 及其 4 个 storage 实现已就位。
- 不要新增 view/view_mut/into_shared 等存储模式互转 API。
- `into_owned_from_owned_storage` 是 convert 模块的 `pub(crate) fn` 自含 helper，**不要**把它当作 `TensorBase` 的公开 inherent method 重新组织。
