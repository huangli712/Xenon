2. 阅读 `17-indexing §5.2`（`try_at` / `get` / `get_unchecked` 的签名契约）、§6.1–§6.2（offset 不变式）、§6.4（unsafe 安全性论证）、§8.2（测试清单）。
3. 确认上游 API（W7 / W8）：
   - `crate::storage::Storage`：提供 `unsafe fn get_unchecked(&self, idx: usize) -> &Self::Elem`。
   - `crate::tensor::TensorBase`：提供 `dim()`, `strides()`, `offset()`, `storage()`, `ndim()`（07-tensor §5.1）。
4. 打开 `src/index/access.rs`（W21T1 留下的 stub），确认只修改本任务目标范围。
5. **错误字段占位符约定（继承自 W21T2）**：`get` 路径自己构造 `XenonError::InvalidLayout` 时，因为 `TensorBase` 持有 storage 上下文，可以**填充真实 `storage_kind` 与 `storage_len`**——但本 task 选择仍用占位符（`Default::default()` + `0`），理由：
   - 与 W21T2 `NdIndex::index_checked` 的错误形状保持一致，便于 `try_at` 路径与 `get` 路径的错误结构在调用方处可以等价比较。
   - 上层若需要精确 `storage_len` 用于诊断，可在 W21 后续修订或集成 W7 实际 API 后统一回填（受限于 W7 是否暴露 `storage().len()` getter）。
   - W21 实施阶段须先核对 W7 交付物，再决定是改为真实值还是沿用占位符。本方案优先稳定性。
6. **`get_unchecked` 安全前提与 `unchecked_*` 选用约定**：本 task 的 `get_unchecked` 调用方契约（17-indexing §5.2 line 248–251）已要求"index 合法 + offset 不溢出 usize"。实施时优先采用 `usize::unchecked_mul` + `usize::unchecked_add`（rustc 1.79+ stable）以表达**严格的安全前提**：违反 → UB（与 trait 契约一致），debug 模式下 panic。若 MSRV（01-architecture §1.4 line 40：1.85+）覆盖该 API 则直接使用；否则需在 `unsafe` 块中加 `debug_assert!` + `wrapping_*` 作为退化方案（详见 Step 2 注释）。

## 实施步骤

### Step 1: 确认实现边界与命名

依据 `17-indexing §5.2`：本 task 落地三个 inherent methods 在 `impl<S, D, A> TensorBase<S, D> where S: Storage<Elem = A>, D: Dimension`：
- `try_at<I: NdIndex<D>>(&self, index: I) -> Result<&A, XenonError>`：规范主入口，走 `NdIndex` trait 分派。
- `get(&self, index: &[usize]) -> Result<&A, XenonError>`：convenience wrapper，**独立于 trait 分派路径**，原因见设计文档 line 280（`IxDyn` 与静态 `NdIndex<Ix2>` 之间的 trait bound 不兼容）。
- `get_unchecked(&self, index: &[usize]) -> &A`：`get` 的 unsafe 对偶，**签名也是 `&[usize]`**（设计文档 line 251），不走 `NdIndex` 分派。

本 task **不**实现 mutable 变体（归 W21T5），**不**实现 `slice()`（归 W21T6）。

### Step 2: 实现任务目标

在 `src/index/access.rs` 中追加：

```rust
use crate::dimension::Dimension;
use crate::error::{InvalidLayoutReason, Result, XenonError};
use crate::index::NdIndex;
use crate::storage::Storage;
use crate::tensor::TensorBase;

impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
{
    /// Canonical safe read entry point — accepts any `NdIndex<D>` (tuples,
    /// `&[usize]` for `D == IxDyn`).
    ///
    /// Errors as per `17-indexing §5.2`:
    /// - rank mismatch → `XenonError::DimensionMismatch`
    /// - per-axis out of bounds → `XenonError::IndexOutOfBounds`
    /// - offset arithmetic overflow → `XenonError::InvalidLayout`
    pub fn try_at<I>(&self, index: I) -> Result<&A>
    where
        I: NdIndex<D>,
    {
        let offset = index.index_checked(self.dim(), self.strides())?;
        // SAFETY: index_checked verified bounds and checked-offset arithmetic.
        Ok(unsafe { self.storage().get_unchecked(self.offset() + offset) })
    }

    /// Convenience wrapper accepting `&[usize]`. Independent of `try_at`'s
    /// trait dispatch path — see `17-indexing §5.2` line 280 for rationale.
    pub fn get(&self, index: &[usize]) -> Result<&A> {
        let shape = self.dim().slice();
        let strides = self.strides().slice();
        // Rank mismatch → DimensionMismatch per 17-indexing §5.2 line 280.
        if index.len() != shape.len() {
            return Err(XenonError::DimensionMismatch {
                operation: "TensorBase::get".into(),
                expected: shape.len(),
                actual: index.len(),
            });
        }
        let mut offset = 0usize;
        for (axis, ((&idx, &extent), &stride)) in
            index.iter().zip(shape).zip(strides).enumerate()
        {
            if idx >= extent {
                return Err(XenonError::IndexOutOfBounds {
                    operation: "TensorBase::get".into(),
                    attempted_index: index.to_vec(),
                    axis,
                    shape: shape.to_vec(),
                });
            }
            // storage_kind / storage_len placeholders — see 前置准备 第 5 条.
            // Final form depends on W7's StorageKindTag API. The same placeholder
            // shape is used in W21T2 and W21T5 to keep error structures uniform
            // across the read/write/index paths.
            let term = idx
                .checked_mul(stride)
                .ok_or_else(|| XenonError::InvalidLayout {
                    operation: "TensorBase::get".into(),
                    storage_kind: Default::default(), // placeholder; W7-dependent
                    shape: shape.to_vec(),
                    strides: strides.to_vec(),
                    offset,
                    storage_len: 0, // placeholder; W7-dependent
                    reason: InvalidLayoutReason::AccessRangeExceedsStorage,
                })?;
            offset = offset
                .checked_add(term)
                .ok_or_else(|| XenonError::InvalidLayout {
                    operation: "TensorBase::get".into(),
                    storage_kind: Default::default(), // placeholder; W7-dependent
                    shape: shape.to_vec(),
                    strides: strides.to_vec(),
                    offset,
                    storage_len: 0, // placeholder; W7-dependent
                    reason: InvalidLayoutReason::AccessRangeExceedsStorage,
                })?;
        }
        // SAFETY: rank and per-axis bounds verified above; offset computed
        // with checked arithmetic.
        Ok(unsafe { self.storage().get_unchecked(self.offset() + offset) })
    }

    /// Unsafe dual of `get`. Signature is `&[usize]` per `17-indexing §5.2`
    /// line 251 — NOT generic over `NdIndex` (that would duplicate `try_at`).
    ///
    /// # Safety
    ///
    /// Caller must ensure:
    /// - `index.len() == self.ndim()`
    /// - each `index[i] < shape[i]`
    /// - resulting offset does not overflow `usize`
    pub unsafe fn get_unchecked(&self, index: &[usize]) -> &A {
        let strides = self.strides().slice();
        let mut offset = 0usize;
        for (&idx, &stride) in index.iter().zip(strides) {
            // SAFETY: caller's # Safety contract guarantees no overflow.
            // unchecked_* expresses that contract precisely: violations are UB
            // (debug build will panic via debug_assertions). Prefer over
            // wrapping_* which would silently produce a bogus offset on
            // contract violation.
            debug_assert!(idx.checked_mul(stride).is_some());
            let term = idx.unchecked_mul(stride);
            debug_assert!(offset.checked_add(term).is_some());
            offset = offset.unchecked_add(term);
        }
        // self.offset() + offset: also under caller's contract.
        // Use unchecked_add for consistency; debug_assert guards in builds.
        debug_assert!(self.offset().checked_add(offset).is_some());
        self.storage().get_unchecked(self.offset().unchecked_add(offset))
    }
}
```

#[cfg(test)]
mod tests {
    use super::*;
    use crate::tensor::Tensor;

    #[test]
    fn test_try_at_2d() {
        // F-order [2, 3], vec in logical (col-major) order:
        // col 0: [1, 2]; col 1: [3, 4]; col 2: [5, 6].
        // tensor[(1, 2)] = 6.
        let tensor = Tensor::from_shape_vec([2, 3], vec![1, 2, 3, 4, 5, 6]).unwrap();
        assert_eq!(*tensor.try_at((1usize, 2usize)).unwrap(), 6);
    }

    #[test]
    fn test_try_at_out_of_bounds() {
        // Per 17-indexing §8.2 priority "高" — out-of-bounds via NdIndex path.
        let tensor = Tensor::from_shape_vec([2, 3], vec![1, 2, 3, 4, 5, 6]).unwrap();
        let err = tensor.try_at((2usize, 0usize)).unwrap_err();
        assert!(matches!(err, XenonError::IndexOutOfBounds { axis: 0, .. }));
    }

    #[test]
    fn test_get_returns_index_out_of_bounds() {
        // Per 17-indexing §8.2 priority "高" — out-of-bounds via &[usize] path.
        let tensor = Tensor::from_shape_vec([2, 2], vec![1, 2, 3, 4]).unwrap();
        let err = tensor.get(&[2, 0]).unwrap_err();
        assert!(matches!(err, XenonError::IndexOutOfBounds { .. }));
    }

    #[test]
    fn test_get_rank_mismatch_is_dimension_mismatch() {
        // Per 17-indexing §5.2 line 280: rank mismatch → DimensionMismatch.
        let tensor = Tensor::from_shape_vec([2, 2], vec![1, 2, 3, 4]).unwrap();
        let err = tensor.get(&[0, 0, 0]).unwrap_err();
        assert!(matches!(err, XenonError::DimensionMismatch { expected: 2, actual: 3, .. }));
    }
}

## 关键设计决策

1. 依据 `17-indexing §5.2 line 251`，`get_unchecked` 的签名是 `&[usize]`（不是泛型 `NdIndex<D>`）。它是 `get` 的 unsafe 对偶，专为"调用方已证明索引合法"的热点路径服务；若用泛型 `NdIndex<D>`，会与 `try_at` 重复且制造 `IxDyn` / 静态 rank 间的 trait-bound 冲突（§5.2 line 280）。
2. 依据 `17-indexing §5.2 line 280`，`get` 作为 convenience wrapper 独立走 rank + bounds 校验，不通过 `try_at<I: NdIndex<D>>` 委托。原因：对静态 `D = Ix2`，`IxDyn`（`&[usize]` 的 `NdIndex` 实现归属）没有 `NdIndex<Ix2>` 实现，强转会触发 trait bound 不满足。
3. 依据 `17-indexing §5.2 line 280` 与 `26-error §5`，rank 不一致一律返回 `XenonError::DimensionMismatch { operation, expected, actual }`（**不是** `InvalidArgument`），偏移溢出返回 `XenonError::InvalidLayout { reason: AccessRangeExceedsStorage, .. }`。
4. 依据 `17-indexing §8.2`，本 task 落地 4 个单元测试覆盖高优先级场景：正常 2D 访问、NdIndex 越界、`&[usize]` 越界、rank 不匹配。`test_try_at_mut_requires_storage_mut` 归 W21T5。
5. **`get_unchecked` 的 `unchecked_*` 选用**：依据 17-indexing §5.2 line 248–251 的 Safety 契约（caller 保证 "rank match + per-axis bounds + no offset overflow"），实施时优先使用 `usize::unchecked_mul` / `unchecked_add`（Rust 1.79+ stable，01-architecture §1.4 MSRV 1.85+ 覆盖）以精确表达契约：违反前提 → UB（debug 模式下 `debug_assert!` 会 panic）。**不**使用 `wrapping_*` —— 后者在前提被违反时会静默回绕产生错误数据，不符合"unsafe 接口只跳过检查，不改变 offset 语义"（§6.4）的安全性论证。
6. **错误占位符**（与 W21T2 一致）：`get` 路径构造 `InvalidLayout` 时，`storage_kind` / `storage_len` 字段沿用 W21T2 的占位符约定，便于与 `try_at` 路径错误结构对齐（详见前置准备第 5 条）。

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets -- -D warnings`
3. 测试验证: `cargo test --lib index::access::tests`（4 个 `#[test]` 全通过）。
4. 手动验证: 构造 `Tensor::from_shape_vec([2, 3], vec![1..=6])`，依次调用 `.try_at((1, 2))`、`.get(&[1, 2])`、`.try_at((2, 0))`、`.get(&[0, 0, 0])`，确认 Ok 值为 6 且越界 / rank 错误各自返回对应 `XenonError` 变体。

## 注意事项

- `usize` 只作为索引和 shape 元数据，不扩展负索引或高级索引。
- unsafe 接口只跳过检查，不改变 offset 语义。
- 切片必须更新 offset、shape、stride 和布局状态，不能复制数据。
