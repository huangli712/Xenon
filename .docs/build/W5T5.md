## 实施步骤

### Step 1: Add imaginary and real constructors

Add the purely imaginary constructor, conjugate method, and explicit real conversion in `src/complex/mod.rs`. Pure real construction must use `From<T>` rather than mixed arithmetic operators.

```rust
impl<T: ComplexFloat> Complex<T> {
    #[inline]
    pub fn from_imag(im: T) -> Self {
        Self::new(T::default(), im)
    }

    #[inline]
    pub fn conj(self) -> Self {
        Self::new(self.re, -self.im)
    }
}

impl<T: ComplexFloat> From<T> for Complex<T> {
    #[inline]
    fn from(re: T) -> Self {
        Self::new(re, T::default())
    }
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_from_imag_and_conj() {
        let z = Complex::from_imag(4.0_f64);
        assert_eq!(z, Complex::new(0.0, 4.0));
        assert_eq!(z.conj(), Complex::new(0.0, -4.0));
    }

    #[test]
    fn test_from_real() {
        assert_eq!(Complex::from(5.0_f64), Complex::new(5.0, 0.0));
        assert_eq!(Complex::from(-1.0_f64), Complex::new(-1.0, 0.0));
    }
}
```

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test --lib complex::tests`
4. 手动验证: 构造 `Complex::from_imag(4.0)`、`Complex::from(5.0)` 和 `z.conj()`，分别验证结果等于 `Complex::new(0,4)`、`Complex::new(5,0)` 和 `Complex::new(re, -im)`。

## 注意事项

- 不实现跨精度运算，也不实现 `Complex<T> op T` 便捷运算符。
- `NaN != NaN` 由底层浮点 `PartialEq` 自然保证，不要实现 `Eq`。
- FFI 布局测试必须覆盖 size、align 和字段偏移意图。
