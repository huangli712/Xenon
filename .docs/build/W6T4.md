参考 `06-layout §8.2`「test_f_contig_empty」用例。占位体永远返回 `true`，因此只在「设计文档定义为 true 的退化情形」上做断言（避免与 W6T7 的真实算法冲突）：

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::dimension::Ix2;

    #[test]
    fn test_f_contig_empty_placeholder() {
        // `shape = [0, 3]` is empty (product == 0) → §5.7 fast path says
        // `is_f_contiguous` MUST return true. The placeholder satisfies
        // this case unconditionally, which is consistent with the
        // permanent algorithm to be installed by W6T7.
        let shape = Ix2(0, 3);
        let strides = Strides::new(Ix2(1, 0));
        assert!(is_f_contiguous(&shape, &strides));
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 占位体返回 `true` | `06-layout §5.7` 的空数组/标量/单元素快速路径总是连续；占位体在「永远连续」语义上与真实算法的退化分支一致，仅在「需要识别非连续」时与 W6T7 算法不同——这正是占位的目的 |
| 测试仅覆盖空数组（永远 true） | 避免与 W6T7 的真实算法在「非连续」语义上冲突；`test_f_contig_false` / `test_f_contig_true` / `test_f_contig_size1_axis` 等用例由 W6T7 引入 |
| 测试参数使用 `Ix2(0, 3)` 而非 `[0_usize, 3]` | `is_f_contiguous` 的签名是 `<D: Dimension>`；`[usize; N]` 仅实现 `IntoDimension` |

## 验证方式

1. 编译检查: `cargo check -p xenon`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test layout::contiguous::tests::test_f_contig_empty_placeholder`
4. 手动验证: 占位函数对任意输入始终返回 `true`；W6T7 将替换为实际检测逻辑。

## 注意事项

- 本 task 为 **占位符**：真正的 F-contiguity 检测算法在 W6T7 中实现。
- 骨架函数签名必须与设计文档 §5.7 一致，确保 W6T7 可无缝替换。
- 当前函数忽略所有输入参数——W6T7 将使用 `shape` + `strides` 进行 §5.7 算法识别。
- 测试中**不可**直接传入 `[usize; N]`：`Dimension` 仅由 `Ix0..Ix6`/`IxDyn` 实现。
