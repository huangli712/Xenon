## 目标

在 `src/broadcast/view.rs` 中放置 view 模块骨架：
1. 在 `impl<S, A, D> TensorBase<S, D> where S: Storage<Elem = A>, D: Dimension` 块内声明 `broadcast_to` inherent 方法骨架，签名严格对齐 `15-broadcast.md §5.1` line 124-132；
2. 声明 `pub(crate) fn broadcast_with(...)` 自由函数骨架，签名严格对齐 §5.1 line 134-148，含双向 `BroadcastDim` bound；
3. 两个函数 body 均为 `todo!()`，由 W11T7-T9 逐步实现。

### Step 2: 定义 `broadcast_with` `pub(crate)` 自由函数骨架

按 §5.1 line 134-148 完整复刻双向 `BroadcastDim` bound（见 §5.1 line 151-160 关于可满足性的论证）：

```rust
/// Dual-input broadcast. Internal entry consumed by `math` / `overload`. See
/// `15-broadcast.md §5.1` line 134-148 and §5.2 line 170.
///
/// The bidirectional `BroadcastDim` bound (D: BroadcastDim<E> and E: BroadcastDim<D,
/// Output = ...>) is satisfiable for every `(D, E) ∈ {Ix0..Ix6, IxDyn}` per
/// 02-dimension §5.10 line 703 symmetry guarantee.
pub(crate) fn broadcast_with<'a, A, S1, D, S2, E>(
    a: &'a TensorBase<S1, D>,
    b: &'a TensorBase<S2, E>,
) -> Result<
    (
        TensorView<'a, A, <D as BroadcastDim<E>>::Output>,
        TensorView<'a, A, <D as BroadcastDim<E>>::Output>,
    ),
    XenonError,
>
where
    S1: Storage<Elem = A>,
    S2: Storage<Elem = A>,
    D: Dimension + BroadcastDim<E>,
    E: Dimension + BroadcastDim<D, Output = <D as BroadcastDim<E>>::Output>,
{
    let _ = (a, b);
    todo!("implemented by W11T9")
}
```

```rust
mod tests {

    #[test]
    fn test_broadcast_to_signature_compiles() {

            t.broadcast_to(s)
        };
        let _ = |t: &Tensor2<f64>, s: Vec<usize>| -> Result<TensorView<'_, f64, IxDyn>, XenonError> {
            t.broadcast_to(s)
        };
    }

    #[test]
    fn test_broadcast_with_bidirectional_bound_satisfiable() {
        // Verify the bidirectional `BroadcastDim` bound is satisfiable for representative

        let _ = _same_rank;
    }

```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `broadcast_to` 作为 `TensorBase` inherent 方法（不是自由函数） | 15-broadcast §5.1 line 124-132、§5.2 line 172 |
| `broadcast_with` 严格 `pub(crate)`（不放宽为 `pub`） | 15-broadcast §5.1 line 134、§5.2 line 172 |
| 保留双向 `BroadcastDim` bound 不简化 | 15-broadcast §5.1 line 151-160 论证 + 02-dimension §5.10 line 703 对称性保证；简化为单向会拒绝部分合法组合 |
| 本 task 不引入任何函数体逻辑 | 设计 §7 Wave 1 T1 仅要求"模块声明、规则函数声明、视图相关入口占位" |

## 验证方式

1. 编译检查: `cargo check`（确认 view.rs 中 `impl TensorBase` 块与 `broadcast_with` 签名通过类型检查）
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test --lib broadcast::view::tests`
4. 手动验证: 在临时 example 中写 `let _: fn(&Tensor2<f64>, _) -> _ = Tensor2::<f64>::broadcast_to;` 应编译通过，确认 inherent 方法已注册到 `TensorBase`。

## 注意事项

- `broadcast_to` 必须放在 `impl<S, A, D> TensorBase<S, D> where S: Storage<Elem = A>, D: Dimension { ... }` 块内；W11T7 / W11T8 将在同一块内替换其 `todo!()` body，不得另起 `impl` 块或写成自由函数。
- `broadcast_with` 必须使用 `pub(crate)` 可见性；W11T9 实现时不得放宽为 `pub`。
- 不要导入 `crate::layout` 或 `crate::dimension::IxDyn` 等 W11T7-T9 才用到的项 —— 本 task 仅占位，过早导入会产生未使用警告。
