### Step 2: 并行一致性（§5.19 高优 3 项）

```rust
#[test]
fn test_sum_parallel_feature_consistency() {
    let n = 1000;
    let t = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| i as f64).collect()).unwrap();
    // 实证 13-reduction.md §5.1 L120：sum() -> A（标量、非 Result）。
    let parallel_result: f64 = t.sum();
    let serial: f64 = t.iter().copied().sum();

    // sum 跨路径：Tier 2 文档化容差——直接对标量为 ULP 比较。
    // 实证 W29T1 L140：cross_path_sum(n: usize) 需运行期 n；L161 ulp_eq_f64_with_tolerance(a, b, t: MathTolerance)。
    let tol = MathTolerance::cross_path_sum(n);
    assert!(
        ulp_eq_f64_with_tolerance(parallel_result, serial, tol),
        "sum parallel vs serial: parallel={parallel_result}, serial={serial}, ulp={}", tol.ulp
    );
}

#[test]
fn test_par_add_consistency() {
    // add 是 IEEE 754 路径无关运算 → Tier 1 精确
    let n = 1024;
    let a = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| i as f64).collect()).unwrap();
    let b = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| (i * 2) as f64).collect()).unwrap();
    let parallel = (&a + &b).unwrap();

    // 显式标量 baseline
    let scalar: Vec<f64> = a.iter().zip(b.iter()).map(|(x, y)| x + y).collect();
    let baseline = Tensor1::<f64>::from_shape_vec([n], scalar).unwrap();
    assert_tensor_exact_real(&parallel, &baseline, "par add vs scalar");
}

#[test]
fn test_par_dot_consistency() {
    // dot 是归约：跨路径走 Tier 2
    let n = 256;
    let a = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| (i + 1) as f64).collect()).unwrap();
    let b = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| ((i % 7) + 1) as f64).collect()).unwrap();
    // 12-matrix.md §5.1 L171：dot() -> Result<A, _>。返回标量。
    let parallel: f64 = a.dot(&b).unwrap();
    let serial: f64 = a.iter().zip(b.iter()).map(|(x, y)| x * y).sum();
    // cross_path_dot(n) 需 n；ulp_eq_f64_with_tolerance 取 MathTolerance 结构体。
    let tol = MathTolerance::cross_path_dot(n);
    assert!(
        ulp_eq_f64_with_tolerance(parallel, serial, tol),
        "par dot vs serial: parallel={parallel}, serial={serial}, ulp={}", tol.ulp
    );
}
```

### Step 3: 并发读取与嵌套回退（§5.19 高优/中优）

```rust
#[test]
fn test_parallel_read() {
    // ArcTensor 多线程只读访问，结果一致
    let t = Tensor1::<f64>::from_shape_vec([8], (0..8).map(|i| i as f64).collect()).unwrap();
    // 实证 05-storage.md L622, 28-tests.md L428：ArcTensor 转换公开入口是
    // `Owned<A>::into_shared(self) -> ArcRepr<A>`；TensorBase 层体现为 `t.into_shared()`。
    let arc: ArcTensor1<f64> = t.into_shared();

    let handles: Vec<_> = (0..4).map(|_| {
        let a = arc.clone();
        std::thread::spawn(move || a.iter().copied().sum::<f64>())
    }).collect();

    let expected: f64 = (0..8).map(|i| i as f64).sum();
    for h in handles {
        assert!(ulp_eq_f64_exact(h.join().unwrap(), expected));
    }
}

#[test]
fn test_nested_parallel_falls_back_to_serial() {
    // 设计要求（28-tests §5.19 L646）：嵌套并行检测后自动回退串行，
    // 结果与串行一致；不得 panic。
    // 注：09-parallel §5.6 的 `par_map` 为 `pub(crate)`，测试 crate 不可见；
    // 用 std::thread 并发触发多个会走 parallel dispatcher 的归约
    // （.sum()）来模拟嵌套场景：dispatcher 在 worker 上下文中检测
    // IN_PARALLEL 应回退串行而非 panic。测试只断言对外可观测语义：
    // 所有线程结果在文档化容差内与串行 baseline 一致 + 无 panic。
    let n = 1024;
    let t = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| i as f64).collect()).unwrap();
    let arc: ArcTensor1<f64> = t.into_shared();  // 05-storage.md L622 公开入口

    // sum() 返回标量 f64（§5.1 L120）。
    let handles: Vec<_> = (0..8).map(|_| {
        let a = arc.clone();
        std::thread::spawn(move || a.sum())
    }).collect();

    let serial: f64 = (0..n).map(|i| i as f64).sum();
    // cross_path_sum(n)；ulp_eq_f64_with_tolerance 取 MathTolerance 。
    let tol = MathTolerance::cross_path_sum(n);
    for h in handles {
        let r: f64 = h.join().expect("nested parallel must not panic");
        assert!(
            ulp_eq_f64_with_tolerance(r, serial, tol),
            "nested parallel result must match serial within tolerance: r={r}, serial={serial}, ulp={}", tol.ulp
        );
    }
}
```

### Step 4: 确定性测试（§6.3.4 全部 4 项）

```rust
#[test]
fn test_determinism_add_same_path() {
    // 同执行路径下重复执行 add → 逐元素 ULP==0 一致
    let a = Tensor1::<f64>::from_shape_vec([512], (0..512).map(|i| i as f64).collect()).unwrap();
    let b = Tensor1::<f64>::from_shape_vec([512], (0..512).map(|i| (i * 3) as f64).collect()).unwrap();
    let r1 = (&a + &b).unwrap();
    let r2 = (&a + &b).unwrap();
    assert_tensor_exact_real(&r1, &r2, "determinism: par add same path");
}

#[test]
fn test_determinism_sum_same_path() {
    // sum() 返回标量。
    let t = Tensor1::<f64>::from_shape_vec([1024], (0..1024).map(|i| i as f64).collect()).unwrap();
    let r1: f64 = t.sum();
    let r2: f64 = t.sum();
    // 同执行路径 → ULP==0
    assert!(ulp_eq_f64_exact(r1, r2),
        "determinism: par sum same path must be bitwise identical");
}

#[test]
fn test_determinism_dot_same_path() {
    // dot() 返 Result<A, _>；A = f64 标量。
    let a = Tensor1::<f64>::from_shape_vec([512], (0..512).map(|i| (i + 1) as f64).collect()).unwrap();
    let b = Tensor1::<f64>::from_shape_vec([512], (0..512).map(|i| ((i % 5) + 1) as f64).collect()).unwrap();
    let r1: f64 = a.dot(&b).unwrap();
    let r2: f64 = a.dot(&b).unwrap();
    assert!(ulp_eq_f64_exact(r1, r2));
}

#[test]
fn test_determinism_across_dispatch() {
    // serial / SIMD / parallel 三路径结果在文档化容差内一致
    let n = 1024;
    let t = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| (i as f64) * 0.5).collect()).unwrap();
    let parallel: f64 = t.sum();
    let scalar: f64 = t.iter().copied().sum();
    let tol = MathTolerance::cross_path_sum(n);
    assert!(
        ulp_eq_f64_with_tolerance(parallel, scalar, tol),
        "determinism across dispatch (serial/SIMD/parallel): parallel={parallel}, scalar={scalar}, ulp={}", tol.ulp
    );
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 嵌套并行：自动回退串行（**非 panic**） | 28-tests §5.19 L646 `test_nested_parallel_falls_back_to_serial` |
| `add` 用 `assert_tensor_exact_real`（Tier 1） | §6.2.1 / §6.3.3 add 路径无关 |
| `sum` / `dot` 跨路径用 `assert_tensor_close_real_cross_path` + `MathTolerance::cross_path_sum/dot` | §6.2 Tier 2 文档化容差 |
| ArcTensor 转换入口使用 `t.into_shared()` | 05-storage.md L622 明示 `Owned<A>::into_shared(self) -> ArcRepr<A>`；28-tests.md L428 同例。不存在 `ArcTensor::from_tensor` 构造器 API |
| 测试整体 `#![cfg(feature = "parallel")]` | §7-T19 / §8.3 要求与 feature gate 绑定 |

## 验证方式

1. 编译检查: `cargo check --tests --features parallel`
2. Lint 检查: `cargo clippy --tests --features parallel -- -D warnings`
3. 测试验证: `cargo test --test test_parallel --features parallel`
4. 手动验证: 抽检嵌套回退测试日志，确认 dispatcher 未 panic 而是落到串行路径。

## 注意事项

- **禁止裸 `< 1e-10` 容差**；任何跨路径浮点比较必须走 W29T1 提供的 documented tolerance helper。
- ArcTensor 转换入口使用 `t.into_shared()`（TensorBase 层取自 05-storage.md L622 `Owned::into_shared`）；不得用 `Arc::new(t).into()` 或虚构的 `ArcTensor::from_tensor`。
- 嵌套并行的回退由 dispatcher 内部记录线程局部状态实现；测试只断言「结果正确 + 不 panic」，不锁定回退实现。`par_map` 等并行入口在 09-parallel §5.6 为 `pub(crate)`，测试不能直接调用，因此嵌套测试通过多线程并发触发对外公开归约（`sum`）来跨越 worker 上下文。
- 0-dim 标量提取统一使用 `.iter().next().unwrap()`，而非 `.first()`（design 未公开 `.first()` 方法）。
- 命名严格对齐 §5.19 表头。
