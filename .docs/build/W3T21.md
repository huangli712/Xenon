### Step 3: §8.4 不变量 1 — 静态维度 roundtrip

`Ix{N}::try_from_dyn(dim.clone().into_dyn()) == Ok(dim)` 对所有 Ix1-Ix6 成立。`Ix0` 是 ZST 平凡 roundtrip，单独测试。

```rust
/// §8.4: roundtrip invariant for Ix0 (trivial — Ix0 is a ZST).
#[test]
fn test_ix0_roundtrip() {
    let dim = xenon::dimension::Ix0;
    assert_eq!(xenon::dimension::Ix0::try_from_dyn(dim.into_dyn()), Ok(xenon::dimension::Ix0));
}

proptest! {
    /// §8.4: roundtrip invariant for Ix1.
    #[test]
    fn test_ix1_roundtrip(a in 0usize..1024) {
        let dim = Ix1(a);
        prop_assert_eq!(Ix1::try_from_dyn(dim.into_dyn()), Ok(dim));
    }

    /// §8.4: roundtrip invariant for Ix2.
    #[test]
    fn test_ix2_roundtrip(a in 0usize..1024, b in 0usize..1024) {
        let dim = Ix2(a, b);
        prop_assert_eq!(Ix2::try_from_dyn(dim.into_dyn()), Ok(dim));
    }

    /// §8.4: roundtrip invariant for Ix3.
    #[test]
    fn test_ix3_roundtrip(a in 0usize..512, b in 0usize..512, c in 0usize..512) {
        let dim = Ix3(a, b, c);
        prop_assert_eq!(Ix3::try_from_dyn(dim.into_dyn()), Ok(dim));
    }

    /// §8.4: roundtrip invariant for Ix4.
    #[test]
    fn test_ix4_roundtrip(
        a in 0usize..256, b in 0usize..256,
        c in 0usize..256, d in 0usize..256,
    ) {
        let dim = Ix4(a, b, c, d);
        prop_assert_eq!(Ix4::try_from_dyn(dim.into_dyn()), Ok(dim));
    }

    /// §8.4: roundtrip invariant for Ix5.
    #[test]
    fn test_ix5_roundtrip(
        a in 0usize..128, b in 0usize..128, c in 0usize..128,
        d in 0usize..128, e in 0usize..128,
    ) {
        let dim = Ix5(a, b, c, d, e);
        prop_assert_eq!(Ix5::try_from_dyn(dim.into_dyn()), Ok(dim));
    }

    /// §8.4: roundtrip invariant for Ix6.
    #[test]
    fn test_ix6_roundtrip(
        a in 0usize..64, b in 0usize..64, c in 0usize..64,
```

### Step 4: §8.4 不变量 2 — checked_size 等于 slice 乘积（无溢出时）

```rust
proptest! {
    /// §8.4: `dim.checked_size()? == dim.slice().iter().product()` for non-overflowing shapes.
    ///
    /// Strategy generates IxDyn shapes with rank ∈ [0, 6] and axis values that
    /// guarantee the product fits in `usize`.
    #[test]
    fn test_checked_size_equals_slice_product(
        shape in proptest::collection::vec(0usize..16, 0..7)
    ) {
        let dim = IxDyn::from_vec(shape.clone());
        let expected: Option<usize> = shape.iter().try_fold(1usize, |acc, &x| acc.checked_mul(x));
        match (dim.checked_size(), expected) {
            (Ok(actual), Some(exp)) => prop_assert_eq!(actual, exp),
            (Err(XenonError::InvalidShape { .. }), None) => {
                // Strategy bound ensures product fits, so this branch should not occur.
                // If reached, the test still passes (both report overflow consistently).
            }
            other => prop_assert!(false, "size/product disagree: {:?}", other),
        }
    }
}
```

### Step 5: 额外不变量 — overflow path 包含 offending_dim

```rust
proptest! {
    /// Overflow invariant: if `checked_size()` returns Err, it must be
    /// `InvalidShape::ProductOverflow` with `offending_dim` filled.
    ///
    /// Strategy: place `usize::MAX` at a random axis to force overflow.
    #[test]
    fn test_overflow_includes_offending_dim(
        idx in 0usize..4,
        other in 2usize..16,
    ) {
        // Build a shape with `usize::MAX` at position `idx`, `other` elsewhere.
        // Total rank 4; product at `idx` makes subsequent axes overflow.
        let mut shape = vec![other; 4];
        shape[idx] = usize::MAX;
        let dim = IxDyn::from_vec(shape);
        match dim.checked_size() {
            Err(XenonError::InvalidShape {
                kind: xenon::error::InvalidShapeKind::ProductOverflow,
                offending_dim,
                ..
            }) => {
                prop_assert!(offending_dim.is_some(),
                    "offending_dim must be filled on overflow, got None");
                // The offending axis index must be ≥ idx (since overflow occurs
                // at or after the MAX axis when multiplied by `other`).
                let off = offending_dim.unwrap();
                prop_assert!(off >= idx,
                    "offending_dim {} must be >= injection point {}", off, idx);
            }
            other_result => {
                // No overflow if MAX is at the last axis multiplied by 1, but
                // strategy ensures `other >= 2`, so overflow is always triggered.
                prop_assert!(false, "expected ProductOverflow, got {:?}", other_result);
            }
        }
    }
}
```

## 关键设计决策

1. 依据 `02-dimension.md` §8.4 (lines 1110-1115) 与项目级测试约定，property tests 必须使用 **`proptest` 框架**（不接受手动枚举替代）。
2. **添加 `proptest` 到 dev-dependencies 是本 task 范围内的修改**——若 W1T1 未添加，本 task 在 `Cargo.toml` 追加；目标文件范围因此包含 `Cargo.toml`。
3. roundtrip 测试覆盖 Ix0（平凡）+ Ix1-Ix6（proptest）共 7 个静态维度。每个维度的 axis 上界按 rank 缩减（避免 `into_dyn → try_from_dyn` 期间的中间 Vec 分配开销，并保持 proptest 默认 256 用例运行时间可控）。
4. 不变量 2（`checked_size == product`）使用 `IxDyn` + 随机 shape，rank ∈ [0, 6]，每轴 ∈ [0, 16]，保证产品 ≤ 16^6 = ~16M 不溢出。
5. 额外不变量验证 W3T4-W3T11 的 overflow 路径填入 `offending_dim`——这是 §8.2 line 1093 的关键诊断要求。
6. `proptest_eq!` / `prop_assert_eq!` 替代标准 `assert_eq!`，以便 proptest 失败时给出收缩（shrink）后的最小用例。

## 验证方式

1. 编译检查: `cargo check`（含 dev-dependency 解析）
2. Lint 检查: `cargo clippy --tests`
3. dev-dependency 核查: `cargo tree --depth 1 -e dev | grep proptest` 返回 `proptest v1.x`
4. 测试验证: `cargo test --test property_tests` — 所有 proptest 块通过
5. 手动验证: 对照 §8.4 不变量清单逐项确认；对照 §8.2 line 1093 确认 overflow `offending_dim` 已检查。

## 注意事项

- **必须使用 `proptest`**，不接受手动枚举（违反 §8.4 规范）。
- `Cargo.toml` 修改**只**追加 `proptest` 到 dev-dependencies，**不**改 features、不改 main dependencies。
- roundtrip 测试的 axis 上界经过精心选择：Ix1 上界 1024，Ix6 上界 64——既保证用例多样性，又确保 256 默认用例在 CI 中运行时间合理（< 30 秒）。
- proptest 默认 256 用例；不需要 `proptest_config!` 显式配置。
- `prop_assert!` / `prop_assert_eq!` 必须用于 proptest 块内（替代标准 assert！）；否则 proptest 无法收缩失败用例。
- 若 `Cargo.toml` 已含 `proptest` dev-dependency（W1T1 已添加），本 task 跳过 Step 1，但仍需验证版本约束兼容。
- overflow proptest 中的 `prop_assert!(off >= idx, ...)` 假设乘法是从 axis 0 顺序累积；若实现改为其他顺序，需同步调整断言。
