## 目标

`view()` / `view_mut()` 视图创建。
本任务按 `07-tensor.md §5.3` rule (3) (L424) 和 L177-186 实现 **ViewMut→View 降级 provenance 追踪**：当 `view()` 调用对象为 `TensorBase<ViewMutRepr<'a, A>, D>` 时，结果必须设置 `derived_from_view_mut = true`，使 `access_semantics()` 后续判定为 `SharedReadOnly` 而非 `ReadOnly`；其他来源（Owned / 普通 ViewRepr / Arc）保持 `false`。`view_mut()` 链式 reborrow 保持 `ViewMutRepr`，**不**设置 downgrade 标记。

## 前置准备

- 确认 W8T6 已提供 `as_storage_ptr()` / `as_storage_mut_ptr()` / `storage_len()`。
- 确认 W7 已提供 `ViewRepr<'a, A>::from_raw_parts(ptr: *const A, len: usize)` 与 `ViewMutRepr<'a, A>::from_raw_parts_mut(ptr: *mut A, len: usize)`。
- 确认 W7 已提供 `Storage<Elem = A>` / `StorageMut<Elem = A>` trait bound。

## 实施步骤

### Step 1: 实现核心代码

按 `07-tensor.md §5.3` rule (3) 拆为 **3 个 impl 块**：

#### 1a. 通用 `view()` —— 来源 Owned / Arc / 普通 ViewRepr，`derived_from_view_mut` **透传源张量字段**

```rust
impl<S, D, A> super::TensorBase<S, D>
where
    S: crate::storage::Storage<Elem = A>,
    D: crate::dimension::Dimension + Clone,
{
    /// Creates an immutable view sharing the underlying storage.
    ///
    /// Default path: for Owned/Arc/普通 ViewRepr sources, `derived_from_view_mut`
    /// is inherited from `self` (typically `false`). The specialized
    /// `impl TensorBase<ViewMutRepr<'a, A>, D>::view()` (below) overrides
    /// this path to set `derived_from_view_mut = true` per
    /// `07-tensor.md §5.3` rule (3) and L177-186.
    ///
    /// **NOTE on impl coherence**: this generic impl is the default path. For
    /// `S = ViewMutRepr<'a, A>` the specialized impl below is selected by
    /// Rust's method resolution preferring the more-specific receiver type.
    /// `S = ViewRepr<'a, A>` continues to use this generic impl and therefore
    /// correctly propagates an existing `derived_from_view_mut` tag from a
    /// previously-demoted source (see `07-tensor.md §5.3` L181-186 — the tag
    /// propagates through view() chains and slicing).
    pub fn view(&self) -> super::TensorBase<crate::storage::ViewRepr<'_, A>, D> {
        // SAFETY: storage exposes a valid base pointer + len; ViewRepr
        // borrows it for the duration of `&self`.
        let storage = unsafe {
            crate::storage::ViewRepr::from_raw_parts(
                self.storage.as_ptr(),
                self.storage.len(),
            )
        };
        // SAFETY: shape/strides/offset/flags are inherited verbatim from a
        // valid tensor; `compute_layout_flags` re-derivation is unnecessary
        // because the logical-first pointer and layout are unchanged.
        unsafe {
            super::TensorBase::new_unchecked(
                storage,
                self.shape.clone(),
                self.strides.clone(),
                self.offset,
                self.flags,
                self.derived_from_view_mut,
            )
        }
    }
}
```

#### 1b. **专用** `view()` —— `ViewMutRepr` 降级路径，强制 `derived_from_view_mut = true`

> Rust 方法解析对**更具体的 receiver type**优先（specialization-by-receiver-type 不需要 `feature(min_specialization)`）—— 由于 `TensorBase<ViewMutRepr<'a, A>, D>` 比 `TensorBase<S: Storage<Elem = A>, D>` 更具体，下面 impl 块在 `view_mut().view()` 链路上会被选中。

```rust
impl<'a, A, D> super::TensorBase<crate::storage::ViewMutRepr<'a, A>, D>
where
    A: crate::element::Element,
    D: crate::dimension::Dimension + Clone,
{
    /// Demotes the mutable view to an immutable view, marking the result
    /// with `derived_from_view_mut = true` per `07-tensor.md §5.3` rule (3)
    /// (L424) and L177-186.
    ///
    /// **Why this specialization is required**: a plain `ViewRepr` produced
    /// by this path is layout-identical to a non-downgraded `ViewRepr`
    /// (typically contiguous, no zero stride), so `LayoutFlags` alone cannot
    /// distinguish them. The `derived_from_view_mut` provenance bit lets
    /// `access_semantics()` correctly classify the demoted view as
    /// `SharedReadOnly` rather than `ReadOnly`.
    pub fn view(&self) -> super::TensorBase<crate::storage::ViewRepr<'_, A>, D> {
        let storage = unsafe {
            crate::storage::ViewRepr::from_raw_parts(
                self.storage.as_ptr(),
                self.storage.len(),
            )
        };
        // SAFETY: same metadata invariants as 1a, with `derived_from_view_mut`
        // forced to `true` to mark the ViewMut→View provenance.
        unsafe {
            super::TensorBase::new_unchecked(
                storage,
                self.shape.clone(),
                self.strides.clone(),
                self.offset,
                self.flags,
                true,
            )
        }
    }
}
```

#### 1c. `view_mut()` —— 可写视图，**保持 `ViewMutRepr`，不设 downgrade 标记**

```rust
impl<S, D, A> super::TensorBase<S, D>
where
    S: crate::storage::StorageMut<Elem = A>,
    D: crate::dimension::Dimension + Clone,
{
    /// Creates a mutable view sharing the underlying storage.
    ///
    /// Per `07-tensor.md §5.3` L182-185: `view_mut()` reborrow chained on a
    /// `ViewMutRepr` stays `ViewMutRepr` (writable) and does NOT set the
    /// `derived_from_view_mut` provenance bit — the marker is reserved for
    /// `ViewMut → View` demotion paths only.
    pub fn view_mut(&mut self) -> super::TensorBase<crate::storage::ViewMutRepr<'_, A>, D> {
        let storage = unsafe {
            crate::storage::ViewMutRepr::from_raw_parts_mut(
                self.storage.as_mut_ptr(),
                self.storage.len(),
            )
        };
        // SAFETY: StorageMut bound guarantees exclusive write access; the
        // reborrow is bounded by `&mut self` lifetime.
        unsafe {
            super::TensorBase::new_unchecked(
                storage,
                self.shape.clone(),
                self.strides.clone(),
                self.offset,
                self.flags,
                false,
            )
        }
    }
}
```

测试依据: 覆盖 `07-tensor.md §8.2` 的 `test_tensor_view` (`view()` 创建正确视图) 与 `test_tensor_view_mut`，并补充关键的 **downgrade provenance** 测试 `test_view_from_view_mut_sets_derived_flag`（验证 §5.3 rule (3)）。

```rust
#[cfg(test)]
mod tests {
    use crate::dimension::Ix2;
    use crate::layout::{compute_f_strides, LayoutFlags};
    use crate::storage::Owned;
    use crate::tensor::{AccessSemantics, TensorBase};

    fn f_contig(data: Vec<i32>, shape: Ix2) -> TensorBase<Owned<i32>, Ix2> {
        let strides = compute_f_strides(&shape);
        let storage = unsafe { Owned::from_vec(data) };
        let flags = LayoutFlags::F_CONTIGUOUS;
        unsafe { TensorBase::new_unchecked(storage, shape, strides, 0, flags, false) }
    }

    /// §8.2 test_tensor_view: view() shares data with the source tensor.
    #[test]
    fn test_tensor_view_data_shared() {
        let mut tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2));
        let v = tensor.view();
        assert_eq!(v.shape(), tensor.shape());
        assert_eq!(v.as_slice().unwrap(), &[1, 2, 3, 4]);
        // Modify source; view reflects the change.
        drop(v);
        tensor.as_mut_slice().unwrap()[0] = 99;
        let v2 = tensor.view();
        assert_eq!(v2.as_slice().unwrap()[0], 99);
    }

    /// §8.2 test_tensor_view_mut: view_mut() creates a writable view.
    #[test]
    fn test_tensor_view_mut() {
        let mut tensor = f_contig(vec![1, 2], Ix2(1, 2));
        tensor.view_mut().as_mut_slice().unwrap()[0] = 9;
        assert_eq!(tensor.as_slice().unwrap()[0], 9);
    }

    /// §5.3 rule (3): view() on a ViewMutRepr must set derived_from_view_mut
    /// so that access_semantics() returns SharedReadOnly, not ReadOnly.
    #[test]
    fn test_view_from_view_mut_sets_derived_flag() {
        let mut tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2));
        let view_mut = tensor.view_mut();
        let downgraded = view_mut.view();
        // Direct field access works because we are in the crate-internal test
        // module (pub(crate) field).
        assert!(downgraded.derived_from_view_mut,
                "ViewMut→View downgrade must set derived_from_view_mut = true");
        assert_eq!(
            downgraded.access_semantics(),
            AccessSemantics::SharedReadOnly,
            "Demoted view must report SharedReadOnly per §5.3 rule (3)"
        );
    }

    /// view_mut() chained reborrow keeps ViewMutRepr and does NOT set the
    /// downgrade marker (per §5.3 L182-185).
    #[test]
    fn test_view_mut_reborrow_does_not_set_derived_flag() {
        let mut tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2));
        let mut view_mut1 = tensor.view_mut();
        let view_mut2 = view_mut1.view_mut();
        assert!(!view_mut2.derived_from_view_mut,
                "view_mut() reborrow must NOT set derived_from_view_mut");
        assert_eq!(
            view_mut2.access_semantics(),
            AccessSemantics::Writable,
            "ViewMut reborrow must report Writable per §5.3 rule (2)"
        );
    }

    /// view() on an Owned source: derived_from_view_mut stays false; result
    /// reports ReadOnly per §5.3 rule (4).
    #[test]
    fn test_view_from_owned_is_read_only() {
        let tensor = f_contig(vec![1, 2, 3, 4], Ix2(2, 2));
        let v = tensor.view();
        assert!(!v.derived_from_view_mut);
        assert_eq!(v.access_semantics(), AccessSemantics::ReadOnly);
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `view()` 拆为 **2 个 impl 块**：通用 `S: Storage` 与专用 `ViewMutRepr` | `07-tensor.md §5.3` rule (3) L424；L177-186 强制要求 `ViewMutRepr::view()` 设 `derived_from_view_mut = true` |
| 专用 impl 选中机制：Rust 对**更具体 receiver type**优先（不需要 nightly specialization） | Rust 方法解析规则；`TensorBase<ViewMutRepr<'a, A>, D>` 比 `TensorBase<S: Storage<Elem = A>, D>` 更具体 |
| 通用 `view()` **透传**源 tensor 的 `derived_from_view_mut` | `07-tensor.md §5.3` L181-186：tag 必须跨 view() / slicing 链路传播 |
| `view_mut()` 单一通用 `impl<S: StorageMut, D>` —— 链式 reborrow 保持 `ViewMutRepr` | `07-tensor.md §5.3` L182-185：reborrow 不是降级路径，不设标记 |
| 视图保留源 tensor 完整 shape/strides/offset/flags | 视图与源 tensor 元数据独立，但共享底层 storage buffer；零拷贝 |
| 不重新计算 `LayoutFlags` | 视图的 logical-first pointer 与源相同（offset 不变），layout 几何不变 |

## 注意事项

- `view()` 创建的 `ViewRepr` 借用 `&self`，不能在持有期间通过 `&mut self` 修改源 tensor。
- `view_mut()` 要求 `&mut self`，同一时刻只能存在一个活跃 `view_mut()`。
- **provenance 不变量**: 来自 Owned/Arc 的 `view()` 始终 `derived_from_view_mut = false`；来自 `ViewMutRepr` 的 `view()` 始终 `true`；来自 `ViewRepr` 的 `view()` 透传源字段（含可能为 `true` 的传染情形）。
- `ViewRepr::from_raw_parts` / `ViewMutRepr::from_raw_parts_mut` 是 W7 提供的 storage 级 unsafe API，与 W8T7 的 tensor 级 `from_raw_parts` 不同（前者只负责 storage wrapping，不做 layout 校验）。
- 跨模块 API 一致性检查：若 W7 未提供 `ViewRepr::from_raw_parts(*const A, usize)` 或 `ViewMutRepr::from_raw_parts_mut(*mut A, usize)` 这两个签名，需在 W7 审计中补齐；本 task 实现假设它们存在。
- 测试中直接读 `pub(crate)` 的 `derived_from_view_mut` 字段，仅 crate 内单元测试可见；外部集成测试（W8T10）通过 `access_semantics()` 间接验证。
