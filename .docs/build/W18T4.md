## 目标

Implement `sum_axis_keepdims()` by reusing axis accumulation while retaining the original rank and replacing the reduced axis length with one.

## 实施步骤

### Step 1: Introduce a local `dim_with_axis_set` helper

`02-dimension.md §5.1 line 123-153` 定义的 `Dimension` trait 稳定面**不包含** `set_axis` 方法；公开 API 也未提供对单一 axis 进行原地长度替换的入口。要实现 keepdims 的"将被归约轴长度置为 `1`"语义，本 task 在 `src/reduction/sum.rs` 内部新增 `pub(crate) fn dim_with_axis_set`，通过 `Dimension::slice()` + `Dimension::try_from_slice()` 的现有 API 重建维度，**不**改动 `02-dimension.md` 的 trait 公开面。

```rust
use std::borrow::Cow;

/// Construct a new dimension whose `axis` component has been replaced with
/// `value`, leaving every other axis unchanged.
///
/// Uses only the stable `Dimension` API surface from
/// `02-dimension.md §5.1`: `slice(&self) -> &[usize]` for read-out and
/// `try_from_slice(&[usize]) -> Result<Self, _>` for reconstruction. This
/// keeps the 0D / static-rank / dynamic-rank cases on the same code path
/// and avoids extending the public trait surface.
///
/// Returns `XenonError::InvalidAxis` when `axis.index() >= dim.ndim()`,
/// matching `13-reduction.md §5.2` axis OOB error contract.
pub(crate) fn dim_with_axis_set<D: Dimension>(
    dim: &D,
    axis: Axis,
    value: usize,
    operation: &'static str,
) -> Result<D, XenonError> {
    let mut dims: Vec<usize> = dim.slice().to_vec();
    if axis.index() >= dims.len() {
        return Err(XenonError::InvalidAxis {
            operation: Cow::Borrowed(operation),
            axis: axis.index(),
            ndim: dims.len(),
            shape: dims,
        });
    }
    dims[axis.index()] = value;
    D::try_from_slice(&dims)
}
```

### Step 2: Implement the keepdims helper

`sum_axis_keepdims_impl` 复用 W18T3 中 `pub(crate) fn validate_axis`（同文件内、不重复定义）。`Tensor::zeros` 接收 `D::Smaller`/`D` 形状并返回 `Result<Self, XenonError>`（`18-construction.md line 167`）。元素写回使用 `try_at_mut`（`17-indexing.md §5.2`）；累加复用 W18T2 的 `checked_add_step`。

实现该步骤时只修改任务范围内的目标文件，保持与现有模块风格一致。

```rust
use crate::reduction::sum::{checked_add_step, dim_with_axis_set, validate_axis};

pub(crate) fn sum_axis_keepdims_impl<S, D, A>(
    tensor: &TensorBase<S, D>,
    axis: Axis,
) -> Result<Tensor<A, D>, XenonError>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Numeric + Copy + 'static,
{
    validate_axis(tensor.raw_dim(), axis, "sum_axis_keepdims")?;
    // SAFETY-of-flow: axis is validated above; dim_with_axis_set cannot fail
    // for axis OOB here. `try_from_slice` succeeds because the slice length
    // equals `ndim`, which `Dimension::try_from_slice` accepts.
    let output_dim = dim_with_axis_set(&tensor.raw_dim(), axis, 1, "sum_axis_keepdims")?;
    let mut output = Tensor::<A, D>::zeros(output_dim)?;
    accumulate_axis_keepdims(tensor, axis, &mut output)?;
    Ok(output)
}

/// Per-slot accumulation, mapping input coordinates onto keepdims output
/// coordinates by forcing the reduced axis component to `0`. Numeric
/// semantics inherit from `checked_add_step` (13-reduction §6.1):
/// integers panic on overflow, floats / complex follow IEEE 754.
fn accumulate_axis_keepdims<S, D, A>(
    tensor: &TensorBase<S, D>,
    axis: Axis,
    output: &mut Tensor<A, D>,
) -> Result<(), XenonError>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Numeric + Copy + 'static,
{
    for (input_index, &value) in tensor.indexed_iter() {
        // axis was pre-validated; this construction cannot fail.
        let output_index = dim_with_axis_set(&input_index, axis, 0, "sum_axis_keepdims")
            .expect("axis pre-validated; dim_with_axis_set cannot fail here");
        // `TensorBase` does not impl `IndexMut<D>`; use `try_at_mut`
        // (17-indexing.md §5.2). Index is provably in-bounds because
        // `output` has the reduced axis length 1 and `output_index[axis] = 0`.
        let slot = output
            .try_at_mut(output_index)
            .expect("output_index is within keepdims-shape bounds");
        *slot = checked_add_step(*slot, value).unwrap_or_else(|| {
            panic!(
                "integer overflow in reduction sum_axis_keepdims at input index {:?}",
                input_index
            )
        });
    }
    Ok(())
}
```

### Step 3: Add the public method

```rust
impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
    A: Numeric + Copy + 'static,
{
    /// Reduces along `axis` and keeps the reduced axis with length 1.
    /// See `13-reduction.md §5.1`. For 0D tensors, every `axis` returns
    /// `XenonError::InvalidAxis` (no axis is valid at rank 0).
    pub fn sum_axis_keepdims(&self, axis: Axis) -> Result<Tensor<A, D>, XenonError> {
        crate::reduction::sum_axis_keepdims_impl(self, axis)
    }
}
```

### Step 4: 单元测试

按 `13-reduction.md §7 Wave 2 T4` 测试清单（line 353）添加单元测试，覆盖 `test_sum_axis_keepdims`、`test_sum_axis_keepdims_invalid_axis`、`test_sum_axis_keepdims_zero_len_axis`。

```rust
#[cfg(test)]
mod tests {
    use crate::{Axis, Ix2, Tensor, XenonError};

    #[test]
    fn test_sum_axis_keepdims() {
        let x = Tensor::<i32, Ix2>::from_shape_vec((2, 3), vec![1, 2, 3, 4, 5, 6]).unwrap();
        let y = x.sum_axis_keepdims(Axis(1)).unwrap();
        assert_eq!(y.shape(), &[2, 1]);
        assert_eq!(y.as_slice().unwrap(), &[6, 15]);
    }

    #[test]
    fn test_sum_axis_keepdims_invalid_axis() {
        let x = Tensor::<i32, Ix2>::zeros((2, 3)).unwrap();
        assert!(matches!(
            x.sum_axis_keepdims(Axis(2)),
            Err(XenonError::InvalidAxis { .. })
        ));
    }

    /// 13-reduction §7 T4 / §8.3: zero-length reduced axis preserves
    /// rank with the reduced axis length 1; all output slots are zero.
    #[test]
    fn test_sum_axis_keepdims_zero_len_axis() {
        let x = Tensor::<i32, Ix2>::from_shape_vec((0, 3), vec![]).unwrap();
        let y = x.sum_axis_keepdims(Axis(0)).unwrap();
        assert_eq!(y.shape(), &[1, 3]);
        assert_eq!(y.as_slice().unwrap(), &[0, 0, 0]);
    }
}
```

## 关键设计决策

- Keepdims does not require `RemoveAxis` because the output dimension type remains `D` (`13-reduction.md §5.1 line 130-134`).
- 0D tensors still return `InvalidAxis` for every axis (`13-reduction.md §5.1 line 139`).
- Accumulation logic shares the same `checked_add_step` helper as `sum()` / `sum_axis()`, so all three public APIs have identical numeric semantics (`13-reduction.md §6.1` "整数语义" / "浮点/复数语义" 不变量).
- `dim_with_axis_set` 是本 task 在 `src/reduction/sum.rs` 内部引入的私有 `pub(crate)` 辅助，**不**扩展 `02-dimension.md` 的 Dimension trait 公开面（保留"最小依赖、最小新 API"原则，与 `13-reduction.md §1.2` 一致）。
- `validate_axis` 复用 W18T3 在同一文件内提供的版本，不重复定义。

## 注意事项

- Do not treat rank-0 keepdims as a no-op; the design requires `InvalidAxis`.
- 不要使用 `tensor[index]` 下标语法访问 `TensorBase` 元素——必须经 `try_at_mut`（`17-indexing.md §5.2`）。
- 不要在本 task 中重复定义 W18T3 的 `validate_axis` 或 W18T2 的 `checked_add_step`；直接 `use` 即可。
- 不要尝试给 `Dimension` trait 加 `set_axis` 方法——`02-dimension.md` 的公开面在本 wave 范围之外。
- 所有代码示例依赖前序 wave 已定义的 crate 类型和 trait；若实际名称不同，按现有代码中的同义 API 做最小替换。
- 不添加超出设计文档范围的新公开 API、兼容层或占位功能。
