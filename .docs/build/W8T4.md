#### 语义查询枚举（与 `07-tensor.md §5.3` L370-416 完全对齐）

```rust
/// Physical data location of the tensor payload.
///
/// Current version only supports CPU memory; see `07-tensor.md §5.3` L420.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DataLocation { Cpu }

/// Storage-representation classification returned by [`TensorBase::storage_kind`].
///
/// Reports the underlying storage *representation type*, NOT high-level access
/// semantics. See `07-tensor.md §5.3` L370-375 / L421.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum StorageKind { Owned, View, ViewMut, Shared }

/// Access semantics returned by [`TensorBase::access_semantics`].
///
/// Authoritative variant set (4 variants, see `07-tensor.md §5.3` L378-383):
/// - `ReadOnly`        — plain non-broadcast read-only `ViewRepr`
/// - `SharedReadOnly`  — Arc shared / broadcast / ViewMut-demoted view
/// - `Writable`        — exclusive `ViewMutRepr`
/// - `Owned`           — `Owned<A>` storage
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AccessSemantics { ReadOnly, SharedReadOnly, Writable, Owned }
```

#### 基础查询方法（`RawStorage` bound 即可）

```rust
impl<S, D> TensorBase<S, D>
where
    S: crate::storage::RawStorage,
    D: crate::dimension::Dimension,
{
    /// Axis lengths. Zero-copy delegation to `Dimension::slice()`.
    pub fn shape(&self) -> &[usize] { self.shape.slice() }

    /// Strides in element units (usize, may be 0 for broadcast dims).
    ///
    /// Returns `&[usize]` per `07-tensor.md §5.3` L286-288 and
    /// `06-layout.md §5` Strides<D> contract.
    pub fn strides(&self) -> &[usize] { self.strides.slice() }

    /// Number of dimensions (compile-time const for Ix0–Ix6, runtime for IxDyn).
    pub fn ndim(&self) -> usize { self.shape.ndim() }

    /// Total logical element count = product of all axis lengths.
    ///
    /// O(ndim) per `07-tensor.md §5.3` L298-300; `checked_size()` is guaranteed
    /// to succeed because every safe construction path pre-validates it.
    pub fn len(&self) -> usize { self.shape.checked_size().expect("validated shape") }

    /// `true` iff any axis length is 0 (i.e. logical element count is 0).
    pub fn is_empty(&self) -> bool { self.len() == 0 }

    /// Non-negative offset from storage base to logical first element.
    pub fn offset(&self) -> usize { self.offset }

    /// Full layout flags (F_CONTIGUOUS / ALIGNED / HAS_ZERO_STRIDE).
    pub fn flags(&self) -> crate::layout::LayoutFlags { self.flags }

    /// Physical data location. Hard-coded `Cpu` until GPU support lands; see
    /// `07-tensor.md §5.3` L420.
    pub fn data_location(&self) -> DataLocation { DataLocation::Cpu }
}

impl<S, D> TensorBase<S, D>
where
    S: crate::storage::RawStorage,
    D: crate::dimension::Dimension + Clone,
{
    /// Clone of the dimension descriptor. Requires `D: Clone` (does NOT
    /// promote a generic `D: Clone` bound onto the rest of `TensorBase`).
    pub fn raw_dim(&self) -> D { self.shape.clone() }
}
```

#### `storage_kind()` — 为四个具体存储类型分别 impl

```rust
// `RawStorage` (见 `05-storage.md §5.3` L199-242) 仅定义
// `type Elem / as_ptr / len / is_empty / is_aligned_to / is_aligned`，
// **没有** `STORAGE_KIND` 关联常量，也不允许在本模块新增（Sealed trait）。
// 因此 `storage_kind()` 按 4 种具体存储类型分别 impl；`07-tensor.md §5.3`
// L312 的方法签名未规定分发机制，本 task 选择零开销的类型级专门化。
//
// IMPORTANT: `Arc` is NOT the variant name. Per 07-tensor.md §5.3 L370-375,
// `ArcRepr<A>` reports `StorageKind::Shared`. The `Shared` variant covers all
// Arc-backed shared-ownership storage representations.
use crate::storage::{ArcRepr, Owned, ViewMutRepr, ViewRepr};

impl<A, D> TensorBase<Owned<A>, D>
where
    D: crate::dimension::Dimension,
{
    pub fn storage_kind(&self) -> StorageKind { StorageKind::Owned }
}

impl<'a, A, D> TensorBase<ViewRepr<'a, A>, D>
where
    D: crate::dimension::Dimension,
{
    pub fn storage_kind(&self) -> StorageKind { StorageKind::View }
}

impl<'a, A, D> TensorBase<ViewMutRepr<'a, A>, D>
where
    D: crate::dimension::Dimension,
{
    pub fn storage_kind(&self) -> StorageKind { StorageKind::ViewMut }
}

impl<A, D> TensorBase<ArcRepr<A>, D>
where
    D: crate::dimension::Dimension,
{
    pub fn storage_kind(&self) -> StorageKind { StorageKind::Shared }
}
```

#### `access_semantics()` — 严格按 §5.3 L424 的 5 条规则运行时判定

```rust
impl<S, D> TensorBase<S, D>
where
    S: crate::storage::RawStorage,
    D: crate::dimension::Dimension,
{
    /// Access semantics judged by 5 rules per `07-tensor.md §5.3` L424:
    ///
    /// 1. `storage_kind() == Shared`                              → `SharedReadOnly`
    /// 2. `storage_kind() == ViewMut`                             → `Writable`
    /// 3. `storage_kind() == View` && (`has_zero_stride()` || `derived_from_view_mut`) → `SharedReadOnly`
    /// 4. `storage_kind() == View` && both flags clear            → `ReadOnly`
    /// 5. `storage_kind() == Owned`                               → `Owned`
    ///
    /// A simple `S::ACCESS_SEMANTICS` dispatch is intentionally NOT used:
    /// rule (3) requires combining `has_zero_stride()` and the private
    /// `derived_from_view_mut` field, which a storage-level associated constant
    /// cannot observe.
    pub fn access_semantics(&self) -> AccessSemantics {
        match self.storage_kind() {
            StorageKind::Shared  => AccessSemantics::SharedReadOnly,
            StorageKind::ViewMut => AccessSemantics::Writable,
            StorageKind::View => {
                if self.flags.has_zero_stride() || self.derived_from_view_mut {
                    AccessSemantics::SharedReadOnly
                } else {
                    AccessSemantics::ReadOnly
                }
            }
            StorageKind::Owned => AccessSemantics::Owned,
        }
    }
}
```

测试依据: 覆盖 `07-tensor.md §8.2` 的 `test_tensor_shape_strides`、`test_tensor_len_and_ndim`、`test_tensor_offset_and_flags`、`test_tensor_is_empty`、`test_tensor_data_location`、`test_tensor_storage_kind`、`test_tensor_access_semantics`。`test_tensor_raw_dim` 为本 task 补充（§8.2 未列但 §5.3 L359-365 定义了 `raw_dim()`）。所有测试通过 `Owned::from_vec` + `new_unchecked` 自构造 storage，不依赖 W22 公开构造器。

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::dimension::{Ix1, Ix2};
    use crate::layout::{compute_f_strides, LayoutFlags};
    use crate::storage::Owned;

    /// Helper: construct an Ix2 Owned<i32> tensor with F-contiguous layout.
    ///
    /// NOTE: a generic helper `fn h<D: Dimension>(...) -> TensorBase<Owned<i32>, D>`
    /// (or the previous `-> TensorBase<Owned<i32>, _>` placeholder) is illegal in
    /// Rust function signatures — `_` is not allowed in return position, and a
    /// generic version cannot infer the concrete `D` from an `impl Dimension`
    /// argument. Provide one concrete helper per dimension that the tests need.
    fn f_contig_ix2(data: Vec<i32>, shape: Ix2)
        -> TensorBase<Owned<i32>, Ix2>
    {
        let strides = compute_f_strides(&shape);
        let storage = unsafe { Owned::from_vec(data) };
        let flags = LayoutFlags::F_CONTIGUOUS;
        unsafe { TensorBase::new_unchecked(storage, shape, strides, 0, flags, false) }
    }

    fn f_contig_ix1(data: Vec<i32>, shape: Ix1)
        -> TensorBase<Owned<i32>, Ix1>
    {
        let strides = compute_f_strides(&shape);
        let storage = unsafe { Owned::from_vec(data) };
        let flags = LayoutFlags::F_CONTIGUOUS;
        unsafe { TensorBase::new_unchecked(storage, shape, strides, 0, flags, false) }
    }

    #[test]
    fn test_tensor_shape_strides() {
        let tensor = f_contig_ix2(vec![1_i32; 12], Ix2(3, 4));
        assert_eq!(tensor.shape(), &[3, 4]);
        // F-order strides for shape [3, 4] are [1, 3] (usize, per §5.3).
        assert_eq!(tensor.strides(), &[1_usize, 3]);
    }

    #[test]
    fn test_tensor_len_and_ndim() {
        let tensor = f_contig_ix2(vec![1_i32; 12], Ix2(3, 4));
        assert_eq!(tensor.len(), 12);
        assert_eq!(tensor.ndim(), 2);
    }

    #[test]
    fn test_tensor_offset_and_flags() {
        let tensor = f_contig_ix1(vec![1_i32; 5], Ix1(5));
        assert_eq!(tensor.offset(), 0);
        assert!(tensor.flags().is_f_contiguous());
    }

    #[test]
    fn test_tensor_raw_dim() {
        let tensor = f_contig_ix2(vec![1_i32; 4], Ix2(2, 2));
        let dim = tensor.raw_dim();
        assert_eq!(dim.slice(), &[2, 2]);
    }

    #[test]
    fn test_tensor_is_empty() {
        let tensor = f_contig_ix2(Vec::<i32>::new(), Ix2(0, 3));
        assert!(tensor.is_empty());
    }

    #[test]
    fn test_tensor_data_location() {
        let tensor = f_contig_ix2(vec![1_i32], Ix2(1, 1));
        assert_eq!(tensor.data_location(), DataLocation::Cpu);
    }

    #[test]
    fn test_tensor_storage_kind_owned() {
        let tensor = f_contig_ix2(vec![1_i32; 4], Ix2(2, 2));
        assert_eq!(tensor.storage_kind(), StorageKind::Owned);
    }

    /// Per §5.3 rule (5): Owned storage → `AccessSemantics::Owned`.
    /// Not `ReadWrite` (which is NOT a variant of AccessSemantics).
    #[test]
    fn test_tensor_access_semantics_owned() {
        let tensor = f_contig_ix2(vec![1_i32; 4], Ix2(2, 2));
        assert_eq!(tensor.access_semantics(), AccessSemantics::Owned);
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `strides()` 返回 `&[usize]` | `07-tensor.md §5.3` L286-288 + `06-layout.md §5` Strides<D> 内部用 usize |
| `StorageKind` 4 变体 `{ Owned, View, ViewMut, Shared }`（**不是** `Arc`） | `07-tensor.md §5.3` L370-375 — Arc 表示层报告 `Shared`，对应"共享只读所有权" |
| `AccessSemantics` 4 变体 `{ ReadOnly, SharedReadOnly, Writable, Owned }`（**不是** `ReadWrite`） | `07-tensor.md §5.3` L378-383；Owned 存储独立成一个变体 |
| `access_semantics()` 在 `RawStorage` impl 块内做 5 规则运行时判定，**不**用 `S::ACCESS_SEMANTICS` 关联常量 | `07-tensor.md §5.3` L424 — 规则 (3) 必须联合 `has_zero_stride()` 与 `derived_from_view_mut`，关联常量无法承载这两个动态量 |
| `storage_kind()` 按 4 个具体存储类型分别 impl，**不**用 `S::STORAGE_KIND` 关联常量 | `05-storage.md §5.3` L199-242 的 `RawStorage` trait 没有 `STORAGE_KIND` 关联常量；`07-tensor.md §5.3` L312 仅规定方法签名，未规定分发机制。按具体类型分别 impl 是零开销且对设计文档零依赖扩展的方案 |
| `data_location()` 硬编码返回 `Cpu` | `07-tensor.md §5.3` L420，当前版本仅支持 CPU；未来 GPU 扩展时改为委托 storage trait |
| `raw_dim()` 在独立 `D: Clone` impl 块 | `Dimension` 不要求 `Clone`，单独 impl 避免对非 Clone 维度强加 bound |
| 测试 helper 使用具体 `Ix1`/`Ix2` 类型而非泛型 + `_` 返回类型 | Rust 不允许函数返回类型用 `_`；也不允许从 `impl Dimension` 参数推导泛型返回类型 |

## 注意事项

- `len()` 依赖 `shape.checked_size()`；构造路径必须已在构造时校验，本方法 `expect()` 永不应触发。
- `offset` 是逻辑起点到 storage 起点的偏移量，由构造器维护；本 task 仅查询，不修改。
- View/ViewMut/Shared 存储模式的 `storage_kind`/`access_semantics` 测试在 W8T7/W8T9 视图可构造后补充。
- `alias_class()` 不在本 task 实现 — 在 W8T5 与 `AliasClass` 枚举同步定义。
