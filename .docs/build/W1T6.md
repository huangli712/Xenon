## 实施步骤

### Step 1: 创建 CI 目录结构


### Step 2: 编写 CI workflow 文件

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  CARGO_TERM_COLOR: always
  RUSTFLAGS: "-D warnings"

jobs:
  # ── Format check ──────────────────────────────────────────────
  fmt:
    name: Rustfmt
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt
      - run: cargo fmt --all -- --check

  # ── Clippy lint matrix across feature combos ─────────────────
  # Covers all feature combinations so cfg-gated code paths inside
  # `simd`/`parallel` modules are also lint-checked.
  clippy:
    name: Clippy (${{ matrix.name }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        include:
          - name: no-features
            args: ""
          - name: simd
            args: "--features simd"
          - name: parallel
            args: "--features parallel"
          - name: all-features
            args: "--all-features"
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy
      - run: >
          cargo clippy --all-targets ${{ matrix.args }} --
          -D warnings
          -D clippy::cast_possible_truncation
          -D clippy::cast_possible_wrap
          -D clippy::cast_sign_loss
          -D clippy::cast_precision_loss
          -D clippy::cast_lossless

  # ── MSRV check (Rust 1.85 per 01-architecture §1.4) ──────────
  # Ensures the crate compiles on the declared MSRV; uses --all-features
  # to cover cfg-gated code paths. RUSTFLAGS=-D warnings is intentionally
  # NOT inherited here because new rustc versions may introduce warnings
  # that did not exist when the MSRV was pinned.
  msrv:
    name: MSRV (1.85)
    runs-on: ubuntu-latest
    env:
      RUSTFLAGS: ""
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@1.85
      - run: cargo check --all-features --all-targets

  # ── Test matrix across feature combos ─────────────────────────
  test:
    name: Test (${{ matrix.name }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        include:
          - name: no-features
            args: ""
          - name: simd
            args: "--features simd"
          - name: parallel
            args: "--features parallel"
          - name: simd-parallel
            args: "--features simd,parallel"
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test ${{ matrix.args }} -- --nocapture

  # ── Documentation build smoke check (W1T6 scope) ──────────────
  # Boundary with W30T52:
  #   * W1T6 docs job  = smoke check that `cargo doc` builds with -D warnings
  #     across all features. Prevents broken rustdoc from landing on main
  #     during Wave 2-29 development.
  #   * W30T52 docs.yml = full docs.rs integration: missing-docs lint,
  #     doctest execution, example compilation, and docs.rs preview build.
  # These two jobs intentionally overlap on `cargo doc --no-deps` to
  # provide an early gate (here) and a comprehensive gate (W30T52).
  docs:
    name: Docs (smoke)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo doc --no-deps --all-features
        env:
          RUSTDOCFLAGS: "-D warnings"
```

### Step 3: 等效验证脚本

> **目标文件类型说明**：`.github/workflows/ci.yml` 是 YAML 配置文件，`#[test]` 单元测试
> 无法直接施加。按 `TEMPLATE.md` 「等效验证条款」，本 task 采用真正的 YAML 解析 + 关键
> 字段对照，且脚本失败必非零退出。

**YAML 语法 + 关键字段对照**（任意检查失败必非零退出）:

```bash
set -euo pipefail
python3 - <<'PY'
import sys
from pathlib import Path

try:
    import yaml  # PyYAML, available in GitHub Actions runners and most dev envs
except ImportError:
    print("FAIL: PyYAML missing. Install with: pip install pyyaml", file=sys.stderr)
    sys.exit(2)

ci_path = Path(".github/workflows/ci.yml")
text = ci_path.read_text()
doc = yaml.safe_load(text)  # raises on syntax error → non-zero exit

# 1) Top-level shape
assert doc.get("name") == "CI", f"workflow name must be 'CI', got {doc.get('name')!r}"
assert "on" in doc or True in doc, "missing 'on:' trigger"  # 'on' is YAML boolean true
assert "jobs" in doc, "missing 'jobs:'"

# 2) Required jobs present
required_jobs = {"fmt", "clippy", "msrv", "test", "docs"}
present_jobs = set(doc["jobs"].keys())
missing = required_jobs - present_jobs
assert not missing, f"missing jobs: {missing}"

# 3) Clippy must deny numeric cast lints
clippy_steps = doc["jobs"]["clippy"]["steps"]
clippy_run = " ".join(s.get("run", "") for s in clippy_steps)
required_lints = [
    "clippy::cast_possible_truncation",
    "clippy::cast_possible_wrap",
    "clippy::cast_sign_loss",
    "clippy::cast_precision_loss",
    "clippy::cast_lossless",
]
for lint in required_lints:
    assert lint in clippy_run, f"clippy job missing -D {lint}"

# 4) MSRV job must pin Rust 1.85
msrv_steps = doc["jobs"]["msrv"]["steps"]
msrv_uses = [s.get("uses", "") for s in msrv_steps]
assert any("rust-toolchain@1.85" in u for u in msrv_uses), \
    f"msrv job must use dtolnay/rust-toolchain@1.85, got: {msrv_uses}"

# 5) Test matrix must cover all 4 feature combinations
test_matrix = doc["jobs"]["test"]["strategy"]["matrix"]["include"]
test_names = {entry["name"] for entry in test_matrix}
assert test_names == {"no-features", "simd", "parallel", "simd-parallel"}, \
    f"test matrix names mismatch: {test_names}"

# 6) Clippy matrix must cover at least 4 feature combinations
clippy_matrix = doc["jobs"]["clippy"]["strategy"]["matrix"]["include"]
clippy_names = {entry["name"] for entry in clippy_matrix}
assert clippy_names >= {"no-features", "simd", "parallel", "all-features"}, \
    f"clippy matrix must cover all feature combos, got: {clippy_names}"

# 7) fail-fast must be false for both matrices
assert doc["jobs"]["test"]["strategy"].get("fail-fast") is False
assert doc["jobs"]["clippy"]["strategy"].get("fail-fast") is False

# 8) Global RUSTFLAGS -D warnings present
assert doc.get("env", {}).get("RUSTFLAGS") == "-D warnings", \
    "global env.RUSTFLAGS must be '-D warnings'"

print("OK: ci.yml structure validated", file=sys.stderr)
PY
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `RUSTFLAGS: "-D warnings"`（全局） | 将警告升级为错误，确保 CI 零警告。仅 `msrv` job 局部覆盖为空，避免新 rustc 引入的非 MSRV 期警告破坏构建 |
| 显式 `-D clippy::cast_*` lint | 对齐 `00-coding.md §4.1` 和 §12 的数值 `as` 审计策略；这是 W1T5 的 `.clippy.toml` 无法升级 lint level 的必要补充 |
| Clippy job 也做 feature matrix | cfg-gated 代码路径（`simd`/`parallel`）必须分别在启用/未启用 feature 时被 lint 检查；单一 `--all-features` 无法覆盖 no-feature 路径 |
| 独立 MSRV (1.85) job | `01-architecture.md §1.4` 与 `00-coding.md §11` 声明 MSRV 1.85；使用 `dtolnay/rust-toolchain@1.85` 钉版本，使用 `cargo check` 而非 `cargo test`（测试代码可使用 MSRV 之后的特性） |
| `fail-fast: false` | 不因一个 feature 失败而跳过其他组合 |
| matrix `include` + `args` | 避免 no-feature 场景传入空 `--features` 参数 |
| `--nocapture` 在测试中 | 输出完整测试日志，便于调试 |
| `dtolnay/rust-toolchain` | 工业标准、轻量的 Rust toolchain action |
| docs job 与 W30T52 边界 | W1T6 docs job = 早期 smoke 门禁（确保 cargo doc 不破）；W30T52 docs.yml = 完整 docs.rs 集成（missing-docs / doctest / example）。两者均跑 `cargo doc --no-deps -D warnings` 是预期重叠 |

## 验证方式

> 所有验证命令在失败时必须以非零退出码返回（脚本必须 `set -euo pipefail`）。

1. **结构化解析**: 运行 Step 3 的 Python YAML 解析脚本——`yaml.safe_load` 在语法错误时抛异常，`assert` 在字段不符时返回非零
2. **本地模拟**（可选，开发期）: 使用 `act` 模拟 GitHub Actions
   ```bash
   act -j fmt && act -j clippy && act -j msrv
   ```
3. **CI 自身**：提交 PR 后 GitHub Actions 即为最终验证；本 task 完成依赖：fmt / clippy（4 个 matrix） / msrv / test（4 个 matrix） / docs 全部绿灯

## 注意事项

- CI 同时使用 `dtolnay/rust-toolchain@stable` 与 `dtolnay/rust-toolchain@1.85`：stable 用于日常 lint/test/docs，1.85 用于 MSRV 兼容性校验
- CI 依赖 W1T3 创建 `src/lib.rs` 与 `src/prelude.rs` 占位文件；W1 结束后 fmt、clippy、msrv、test、docs 应可作为通过门禁
- **不要在此添加 bench 或 release workflow**：
  - bench workflow 由 **W28T12**（`.github/workflows/bench.yml`）负责
  - release workflow 当前规划中不存在；如需引入须新增任务条目，不得在此处擅自添加
- **W30T52 不是 release workflow**，而是 `.github/workflows/docs.yml`（docs.rs 集成、missing-docs、doctest、example 编译）；本 task 的 docs job 仅是早期 smoke 门禁，与 W30T52 的边界已在 `docs:` job 注释和决策表中明示
- 不要添加 `cargo deny` 或 `cargo audit`——当前阶段不需要
- 验证脚本依赖 `python3` 3.11+ 与 `PyYAML`（GitHub Actions ubuntu-latest 镜像默认包含 Python 3 与 pip；本地开发若缺 PyYAML 需 `pip install pyyaml`）
