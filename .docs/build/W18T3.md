## 实施步骤

### Step 1: Validate axis

`Dimension` trait（`02-dimension.md §5.1 line 123-153`）的稳定面包括 `slice(&self) -> &[usize]` 与 `ndim()`，但**没有** `to_vec()`。错误诊断需要 `Vec<usize>`，因此通过 `shape.slice().to_vec()` 显式构造。

实现该步骤时只修改任务范围内的目标文件，保持与现有模块风格一致。

```rust
use std::borrow::Cow;

/// `pub(crate)` so W18T4 can reuse it without duplicating the InvalidAxis logic.
pub(crate) fn validate_axis<D: Dimension>(
    shape: &D,
    axis: Axis,
    operation: &'static str,
) -> Result<(), XenonError> {
    if axis.index() >= shape.ndim() {
        return Err(XenonError::InvalidAxis {
            operation: Cow::Borrowed(operation),
            axis: axis.index(),
            ndim: shape.ndim(),
            shape: shape.slice().to_vec(),
        });
    }
    Ok(())
}
```

### Step 2: Implement reduced-axis helper

`RemoveAxis::remove_axis`（`02-dimension.md §5.8 line 567-574`）的签名是 `fn remove_axis(&self, axis: Axis) -> Result<Self::Smaller, XenonError>`：返回新维度，**不**原地修改 `&mut self`。本步骤先用 `validate_axis` 校验轴越界，然后两次调用 `remove_axis(...)?` 分别构造输出维度类型和输出索引。`output` 槽位写回使用 `try_at_mut(...)`（`17-indexing.md §5.2 line 244-266`）而非下标 `output[index]`——`TensorBase` 没有 `IndexMut<D>` impl。

实现该步骤时只修改任务范围内的目标文件，保持与现有模块风格一致。

```rust
use crate::reduction::sum::checked_add_step;

pub(crate) fn sum_axis_impl<S, D, A>(
    tensor: &TensorBase<S, D>,
    axis: Axis,
) -> Result<Tensor<A, D::Smaller>, XenonError>
where
    S: Storage<Elem = A>,
    D: Dimension + RemoveAxis,
    A: Numeric + Copy + 'static,
{
    validate_axis(&tensor.raw_dim(), axis, "sum_axis")?;
    // SAFETY-of-flow: axis is validated above, so remove_axis() cannot fail here.
    // Propagating with `?` keeps the contract symmetric with the trait signature.
    let output_dim = tensor.raw_dim().remove_axis(axis)?;
    let mut output = Tensor::<A, D::Smaller>::zeros(output_dim)?;
    accumulate_axis(tensor, axis, &mut output)?;
    Ok(output)
}

/// Per-slot accumulation over a single axis, mapping input indexed coordinates
/// onto reduced output coordinates. Uses `checked_add_step` (defined in W18T2)
/// so integer overflow panics with element context per 13-reduction §1.1, and
/// float / complex addition follows IEEE 754 via `Numeric + Add`.
fn accumulate_axis<S, D, A>(
    tensor: &TensorBase<S, D>,
    axis: Axis,
    output: &mut Tensor<A, D::Smaller>,
) -> Result<(), XenonError>
where
    S: Storage<Elem = A>,
    D: Dimension + RemoveAxis,
    A: Numeric + Copy + 'static,
{
    for (input_index, &value) in tensor.indexed_iter() {
        // `remove_axis` returns Result<Self::Smaller, _>; axis was pre-validated
        // by `validate_axis(...)` above so this projection cannot fail.
        let output_index = input_index
            .remove_axis(axis)
            .expect("axis pre-validated; remove_axis cannot fail here");
        // `TensorBase` does not implement `IndexMut<D>`; use `try_at_mut`
        // (17-indexing.md §5.2). The lookup cannot fail because
        // `output_index` derives from a coordinate that already maps inside
        // `output`'s logical range.
        let slot = output
            .try_at_mut(output_index)
            .expect("output_index is within reduced-shape bounds");
        *slot = checked_add_step(*slot, value).unwrap_or_else(|| {
            panic!(
                "integer overflow in reduction sum_axis: element_type={}, shape={:?}, input_index={:?}",
                core::any::type_name::<A>(),
                tensor.shape(),
                input_index
            )
        });
    }
    Ok(())
}
```

### Step 3: Add the public method

```rust
impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension + RemoveAxis,
    A: Numeric + Copy + 'static,
{
    /// Reduces along `axis` and removes that axis from the output shape.
    /// See `13-reduction.md §5.1`.
    pub fn sum_axis(&self, axis: Axis) -> Result<Tensor<A, D::Smaller>, XenonError> {
        crate::reduction::sum_axis_impl(self, axis)
    }
}
```

### Step 4: 单元测试

按 `13-reduction.md §7 Wave 2 T3` 测试清单（line 346）添加单元测试，覆盖 `test_sum_axis_2d`、`test_sum_axis_invalid_axis`、`test_sum_axis_zero_len_axis`。

```rust
#[cfg(test)]
mod tests {
    use crate::{Axis, Ix2, Tensor, XenonError};

    #[test]
    fn test_sum_axis_2d() {
        let x = Tensor::<i32, Ix2>::from_shape_vec((2, 3), vec![1, 2, 3, 4, 5, 6]).unwrap();
        let y = x.sum_axis(Axis(1)).unwrap();
        assert_eq!(y.shape(), &[2]);
        assert_eq!(y.as_slice().unwrap(), &[6, 15]);
    }

    #[test]
    fn test_sum_axis_invalid_axis() {
        let x = Tensor::<i32, Ix2>::zeros((2, 3)).unwrap();
        assert!(matches!(
            x.sum_axis(Axis(2)),
            Err(XenonError::InvalidAxis { .. })
        ));
    }

    /// 13-reduction §7 T3 / §8.3 boundary row: zero-length reduced axis
    /// must produce a result whose output slots are all `A::zero()`.
    #[test]
    fn test_sum_axis_zero_len_axis() {
        let x = Tensor::<i32, Ix2>::from_shape_vec((0, 3), vec![]).unwrap();
        let y = x.sum_axis(Axis(0)).unwrap();
        assert_eq!(y.shape(), &[3]);
        assert_eq!(y.as_slice().unwrap(), &[0, 0, 0]);
    }
}
```

## 关键设计决策

- Axis errors use only `XenonError::InvalidAxis` as required by `13-reduction.md §5.2`.
- `D: RemoveAxis` is required only for `sum_axis()`; `13-reduction.md §5.1 line 126-128` 把该约束声明在公开签名上。
- Zero-length reduced axes are handled by leaving output slots at `A::zero()` (zero-length iteration over `indexed_iter()` writes nothing); `test_sum_axis_zero_len_axis` 在本 task 落地，对应 `13-reduction.md §7 T3 line 346`。
- `validate_axis` 升级为 `pub(crate)`，由 W18T4 的 `sum_axis_keepdims_impl` 复用，避免重复定义。
- Inner-loop accumulator 复用 W18T2 的 `checked_add_step`，保持整数 / 浮点 / 复数语义在三条公开 API 之间精确一致（`13-reduction.md §6.1` 不变量表"整数语义"/"浮点/复数语义"行）。

## 注意事项

- Use logical iteration via `indexed_iter()` and index projection (`RemoveAxis::remove_axis`) so non-contiguous F-order views are reduced correctly without C-order assumptions.
- `validate_axis` / `checked_add_step` 由本 task / W18T2 提供，**禁止**在本 task 内创建同名同语义重复函数。
- 不要使用 `tensor[index]` 下标语法访问 `TensorBase` 元素——`07-tensor.md` / `17-indexing.md` 规范入口为 `try_at` / `try_at_mut`。
- 所有代码示例依赖前序 wave 已定义的 crate 类型和 trait；若实际名称不同，按现有代码中的同义 API 做最小替换。
- 不添加超出设计文档范围的新公开 API、兼容层或占位功能。
