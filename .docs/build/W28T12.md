### Step 1: 创建 CI benchmark smoke 工作流

创建 `.github/workflows/bench.yml`，实现三级可选工作流（27-benchmark §8.2）：

```yaml
name: Benchmarks
on:
  workflow_dispatch:
    inputs:
      level:
        description: 'Benchmark level'
        required: true
        type: choice
        options: [smoke, regression, full]
        default: smoke
  pull_request:
    paths:
      - 'benches/**'
      - 'src/**/*.rs'
      - 'Cargo.toml'

jobs:
  bench-smoke:
    if: github.event_name == 'pull_request' || inputs.level == 'smoke'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      # 27-benchmark §5.6 Smoke Test 名单：math.rs / reduction.rs / construction.rs
      - name: Quick smoke — core benches
        run: |
          cargo bench --bench math -- "elem_add_f64" --quick
          cargo bench --bench reduction -- "sum_1d_f64" --quick
          cargo bench --bench construction -- "zeros_1d" --quick
      - name: Quick smoke — comparison benches (feature matrix)
        run: |
          # SIMD comparison: run twice for A-B compare (feature-off vs feature-on)
          cargo bench --bench simd_comparison -- "simd_add_compare" --quick
          cargo bench --bench simd_comparison --features simd -- "simd_add_compare" --quick
          # Parallel comparison: same A-B pattern
          cargo bench --bench parallel_comparison -- "par_add_compare" --quick
          cargo bench --bench parallel_comparison --features parallel -- "par_add_compare" --quick

  bench-regression:
    if: inputs.level == 'regression'
    needs: bench-smoke
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      # 27-benchmark §6.4 基线消费表：elem_add_f64 与 sum_1d_f64 (Medium = 65536)
      - name: Run regression benches and capture output
        run: |
          cargo bench --bench math -- "elem_add_f64" > target/bench-smoke.txt
          cargo bench --bench reduction -- "sum_1d_f64" >> target/bench-smoke.txt
      - name: Report regression analysis
        run: python tools/bench/report.py --input target/bench-smoke.txt --baseline tools/bench/baseline.json

  bench-full:
    if: inputs.level == 'full'
    needs: bench-smoke
    runs-on: ubuntu-latest
    strategy:
      matrix:
        # 27-benchmark §5.6: Full Benchmark = 全部文件 × 4 feature 组合
        # (default / simd / parallel / simd+parallel). 严格按字面要求展开
        # 9 bench × 4 feature = 36 个 job, 覆盖所有可能的 feature gate 组合。
        include:
          # math × 4
          - { bench: math,                features: "" }
          - { bench: math,                features: "--features simd" }
          - { bench: math,                features: "--features parallel" }
          - { bench: math,                features: "--features simd,parallel" }
          # reduction × 4
          - { bench: reduction,           features: "" }
          - { bench: reduction,           features: "--features simd" }
          - { bench: reduction,           features: "--features parallel" }
          - { bench: reduction,           features: "--features simd,parallel" }
          # dot × 4
          - { bench: dot,                 features: "" }
          - { bench: dot,                 features: "--features simd" }
          - { bench: dot,                 features: "--features parallel" }
          - { bench: dot,                 features: "--features simd,parallel" }
          # set × 4
          - { bench: set,                 features: "" }
          - { bench: set,                 features: "--features simd" }
          - { bench: set,                 features: "--features parallel" }
          - { bench: set,                 features: "--features simd,parallel" }
          # broadcast × 4
          - { bench: broadcast,           features: "" }
          - { bench: broadcast,           features: "--features simd" }
          - { bench: broadcast,           features: "--features parallel" }
          - { bench: broadcast,           features: "--features simd,parallel" }
          # shape × 4
          - { bench: shape,               features: "" }
          - { bench: shape,               features: "--features simd" }
          - { bench: shape,               features: "--features parallel" }
          - { bench: shape,               features: "--features simd,parallel" }
          # construction × 4
          - { bench: construction,        features: "" }
          - { bench: construction,        features: "--features simd" }
          - { bench: construction,        features: "--features parallel" }
          - { bench: construction,        features: "--features simd,parallel" }
          # simd_comparison × 4
          - { bench: simd_comparison,     features: "" }
          - { bench: simd_comparison,     features: "--features simd" }
          - { bench: simd_comparison,     features: "--features parallel" }
          - { bench: simd_comparison,     features: "--features simd,parallel" }
          # parallel_comparison × 4
          - { bench: parallel_comparison, features: "" }
          - { bench: parallel_comparison, features: "--features simd" }
          - { bench: parallel_comparison, features: "--features parallel" }
          - { bench: parallel_comparison, features: "--features simd,parallel" }
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - name: Run ${{ matrix.bench }} ${{ matrix.features || '(default)' }}
        run: cargo bench --bench ${{ matrix.bench }} ${{ matrix.features }}
```

### Step 2: 创建 benchmark 报告脚本

创建 `tools/bench/report.py`，解析 bench stdout 输出、与 baseline 对比、按回归阈值分类（27-benchmark §6.4）：

```python
#!/usr/bin/env python3
"""Parse benchmark stdout and annotate performance change bands.

Usage:
    python tools/bench/report.py --input <stdout.txt> --baseline <baseline.json>

Regression bands (27-benchmark §6.4):
    delta > 20%  → failure  (report as regression)
    delta > 5%   → warning  (flag for investigation)
    delta <= 5%  → noise    (within measurement noise)
"""

import argparse
import json
import re
import sys

# Matches three benchmark output formats produced by W28 benches:
#   1. Plain:               "elem_add_f64/65536: 12345 ns"
#   2. 2D shape:            "sum_2d_axis0/256x256: 12345 ns"
#   3. SIMD/parallel path:  "simd_add_compare_f32/65536/simd: 12345 ns"
#                           "par_sum_compare_i64/16777216/parallel: 12345 ns"
# `path` is captured for SIMD/parallel A-B comparison; non-comparison
# entries leave it empty.
BENCH_LINE_RE = re.compile(
    r"^(?P<name>[\w]+)/(?P<size>\d+(?:x\d+)?)(?:/(?P<path>scalar|simd|serial|parallel))?: (?P<ns>\d+) ns"
)


def parse_bench_output(path: str) -> dict[str, int]:
    """Parse stdout lines into {key: median_ns}.

    Key format: "<name>/<size>" or "<name>/<size>/<path>" for comparison
    benches. The path suffix lets SIMD-on vs SIMD-off invocations live in
    the same baseline file without collisions.
    """
    results: dict[str, int] = {}
    with open(path) as fh:
        for line in fh:
            m = BENCH_LINE_RE.search(line)
            if not m:
                continue
            name = m.group("name")
            size = m.group("size")
            path_suffix = m.group("path")
            ns = int(m.group("ns"))
            key = f"{name}/{size}/{path_suffix}" if path_suffix else f"{name}/{size}"
            results[key] = ns
    return results


def classify_delta(delta: float) -> str:
    """Classify performance change against 27-benchmark §6.4 thresholds."""
    if delta > 0.20:
        return "failure"
    if delta > 0.05:
        return "warning"
    return "noise"


def load_baseline(path: str) -> dict[str, int]:
    """Load baseline from JSON file."""
    with open(path) as fh:
        return json.load(fh)


def main() -> None:
    parser = argparse.ArgumentParser(description="Benchmark regression reporter")
    parser.add_argument("--input", required=True, help="Benchmark stdout text file")
    parser.add_argument("--baseline", required=True, help="Baseline JSON file")
    parser.add_argument("--output", default=None, help="Write JSON report (default: stdout)")
    args = parser.parse_args()

    current = parse_bench_output(args.input)
    baseline = load_baseline(args.baseline)

    report = {}
    all_ok = True
    for key, cur_ns in current.items():
        base_ns = baseline.get(key)
        if base_ns is None:
            print(f"WARNING: no baseline for {key}", file=sys.stderr)
            continue
        delta = (cur_ns - base_ns) / base_ns
        band = classify_delta(delta)
        report[key] = {"current_ns": cur_ns, "baseline_ns": base_ns, "delta": delta, "band": band}
        if band == "failure":
            print(f"REGRESSION: {key} ({delta:+.1%})", file=sys.stderr)
            all_ok = False
        elif band == "warning":
            print(f"WARNING: {key} ({delta:+.1%})", file=sys.stderr)

    if args.output:
        with open(args.output, "w") as fh:
            json.dump(report, fh, indent=2)

    if not all_ok:
        sys.exit(1)


if __name__ == "__main__":
    main()
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 使用仓库本地 `harness = false` runner，而非 Criterion 等第三方框架 | 27-benchmark §11 决策 1 要求不引入额外 benchmark 框架 |
| quick 模式保留 filter 与最小输入规模 | 27-benchmark §5.6 和 §8.1 要求 CI smoke 可快速验证 benchmark 入口 |
| benchmark 只记录性能趋势，不定义功能正确性合约 | 27-benchmark §1.1 将功能正确性边界交给 28-tests |
| `BENCH_LINE_RE` 设计为单一正则同时兼容三类输出：`name/size: ns`（普通）、`name/RxC: ns`（2D 形状）、`name/size/path: ns`（对比 bench） | 27-benchmark §5.5 同时存在三类 benchmark 输出格式。`(?P<path>scalar\|simd\|serial\|parallel)?` 为可选捕获组以避免拆分多个正则维护负担。`size = \d+(?:x\d+)?` 兼容 1D 与 2D 规模 |
| CI workflow 拆分为 3 个独立 job（bench-smoke / bench-regression / bench-full）而非单一矩阵 job | 27-benchmark §5.6 明示三级语义不同：smoke 用 `--quick`，regression 跑完整轮次并消费 baseline，full 跑全部 9×4 矩阵。每级触发条件、依赖与时间预算差异显著，独立 job 便于 `needs:` 串接与失败定位 |
| 回归阈值采用 5%/20% 严格 `>` 比较（5% 边界归入 noise 而非 warning） | 27-benchmark §5.7 阈值表写明「> 5% 变慢 = warning / > 20% 变慢 = failure」；严格不等式让噪声边界（5%）落入 noise 段，避免 CI 因测量抖动持续 false positive。Python `classify_delta(0.05) == "noise"` assert 在等效验证条款脚本中固化此语义 |

## 验证方式

1. 编译检查: `cargo check --benches`
2. Lint 检查: `cargo clippy --benches -- -D warnings`
3. 测试验证: `python tools/bench/report.py --input target/bench-smoke.txt --baseline tools/bench/baseline.json`
4. 手动验证: 运行对应 bench 的 `--quick` filter，确认输出包含本任务的 benchmark 名称和 median ns 数值。

## 注意事项

- CI workflow 不阻塞默认 PR 交付，benchmark 结果仅作为可选观察指标。
- regression 阈值（>5% warning, >20% failure）固定写入 `report.py`，通过 `tools/bench/baseline.json` 提供 baseline。
- `baseline.json` 首次由 full bench 运行生成并人工确认质押，后续 CI 对比。
- SIMD/并行对比通过 feature matrix 分别运行同一二进制两次实现，不依赖跨 feature 编译内省。
