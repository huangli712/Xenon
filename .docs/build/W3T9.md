## 实施步骤

### Step 1: 定义 Ix5 结构体

在 `src/dimension/static.rs` 中新增五维静态维度类型。依据 `02-dimension.md` §5.2 (lines 215-222)，Ix5 持有五个公开 `usize` 字段，使用 `#[repr(C)]` 支持连续字段切片视图。derive 集合与设计 §5.2 一致：`Clone, Copy, Debug, PartialEq, Eq, Hash, Default`。

```rust
/// Five-dimensional dimension.
///
/// `#[repr(C)]` is required because `slice()` reinterprets `&Self` as `&[usize; 5]`
/// via pointer cast; this is only safe because `repr(C)` guarantees the `usize`
/// fields are laid out contiguously starting at offset 0.
#[repr(C)]
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Default)]
pub struct Ix5(pub usize, pub usize, pub usize, pub usize, pub usize);
```

### Step 2: 实现 Dimension for Ix5

依据 `02-dimension.md` §5.4（以 Ix3 为例的实现模式）为 Ix5 实现 `Dimension`。五维 shape 的 rank 固定为 5，`checked_size()` 按字段顺序进行 checked 乘法链并在溢出时报告 `offending_dim`。依据 §5.1 设计决策，`into_dyn`/`try_from_dyn` **不**是 trait 方法，本 task 不实现它们。`axis()` 使用 trait 默认实现，本 impl 不重写。

```rust
use std::borrow::Cow;
use crate::error::{InvalidShapeKind, XenonError};
use crate::dimension::Dimension;

impl Dimension for Ix5 {
    const NDIM: Option<usize> = Some(5);

    #[inline]
    fn ndim(&self) -> usize { 5 }

    #[inline]
    fn slice(&self) -> &[usize] {
        // SAFETY: `Ix5` uses `#[repr(C)]` and contains exactly five `usize`
        // fields in declaration order. Reinterpreting `&Ix5` as a contiguous
        // `*const usize` slice of length 5 preserves provenance, alignment, and size.
        // §5.2 compile-time const assertions verify size, alignment, and field
        // offsets against `[usize; 5]` so this layout precondition cannot drift
        // out of sync with the type definition without a build failure.
        unsafe {
            core::slice::from_raw_parts(self as *const Self as *const usize, 5)
        }
    }

    #[inline]
    fn checked_size(&self) -> Result<usize, XenonError> {
        let dims = [self.0, self.1, self.2, self.3, self.4];
        let mut acc = 1usize;
        for (axis, &dim) in dims.iter().enumerate() {
            acc = acc.checked_mul(dim).ok_or(XenonError::InvalidShape {
                operation: Cow::Borrowed("Dimension::checked_size"),
                shape: dims.into(),
                kind: InvalidShapeKind::ProductOverflow,
                offending_dim: Some(axis),
            })?;
        }
        Ok(acc)
    }

    #[inline]
    fn checked(&self) -> Result<(), XenonError> {
        self.checked_size().map(|_| ())
    }

    #[inline]
    fn try_from_slice(slice: &[usize]) -> Result<Self, XenonError> {
        if slice.len() == 5 {
            Ok(Ix5(slice[0], slice[1], slice[2], slice[3], slice[4]))
        } else {
            Err(XenonError::DimensionMismatch {
                operation: Cow::Borrowed("Ix5::try_from_slice"),
                expected: 5,
                actual: slice.len(),
            })
        }
    }

    // `axis()` uses the trait default implementation; out-of-range returns
    // `XenonError::InvalidAxis` automatically.
}
```

### Step 3: 实现 From<(usize, usize, usize, usize, usize)> for Ix5

为 Ix5 显式实现五元素元组转换，避免使用动态维度或数组切片来表示固定 rank shape。

```rust
impl From<(usize, usize, usize, usize, usize)> for Ix5 {
    fn from(t: (usize, usize, usize, usize, usize)) -> Self {
        Ix5(t.0, t.1, t.2, t.3, t.4)
    }
}
```

#[cfg(test)]
mod tests {
    use super::*;

    /// §5.4: Ix5 slice and size calculation.
    #[test]
    fn test_ix5_basic() {
        let dim = Ix5(2, 3, 4, 5, 6);
        assert_eq!(dim.slice(), &[2, 3, 4, 5, 6]);
        assert_eq!(dim.checked_size(), Ok(720));
        assert_eq!(Ix5::from((2, 3, 4, 5, 6)), dim);
    }

    /// §8.3 / §5.4: overflow reports offending_dim.
    #[test]
    fn test_ix5_overflow() {
        let big = Ix5(usize::MAX, 2, 1, 1, 1);
        let err = big.checked_size().unwrap_err();
        if let XenonError::InvalidShape { offending_dim, .. } = err {
            assert_eq!(offending_dim, Some(0));
        } else {
            panic!("expected InvalidShape, got {:?}", err);
        }
    }
}

## 关键设计决策

1. 依据 `02-dimension.md` §5.2，Ix5 的 struct 定义使用 `#[repr(C)]` 保证字段连续布局，derive 集合包含 `Clone, Copy, Debug, PartialEq, Eq, Hash, Default`。
2. 依据 `02-dimension.md` §5.4 实现模式，`checked_size()` 使用循环加 `offending_dim: Some(axis)` 报告第一个溢出轴，不重写 `axis()`（使用 trait 默认实现）。
3. 依据 `02-dimension.md` §5.1 设计决策，`into_dyn`/`try_from_dyn` **不**是 trait 方法；本 task 不实现它们，留给 W3T12 集中作为 inherent 方法添加。

## 注意事项

- `slice()` 返回的切片长度必须等于 `ndim()` 返回的维度数（Ix5 → len=5）。
- `From<tuple>` 元组中所有元素均为 `usize`，不接受其他类型。
- `repr(C)` 是 unsafe 切片构造的前提——不可移除。
- 不要在本 task 实现 `into_dyn`/`try_from_dyn`；留给 W3T12 作为 inherent 方法添加。
- `checked_size()` 溢出时应当使用 `offending_dim: Some(axis)` 标注第一个溢出轴，而非 `None`。
- 不要本 task 重写 `axis()`——trait 默认实现通过 `slice().get(axis.0)` 自动处理越界。
- 不要在本 task 修改 `src/dimension/mod.rs`；公开导出由 W3T15 集中处理。
