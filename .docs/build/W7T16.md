## 实施步骤

### Step 1: Implement ArcRepr shared storage

Create `src/storage/arc.rs` with a shared read-only representation backed by `Arc<SharedBuf<A>>`. Public API stays read-only even if private CoW helpers exist. All constructors must build an `AlignedBuf<A>` directly and then wrap it; do not route through `Owned`.

```rust
use alloc::sync::Arc;
use alloc::vec::Vec;

use crate::element::Element;
use crate::error::XenonError;
use crate::storage::alloc::AlignedAlloc;
use crate::storage::owned::AlignedBuf;
use crate::storage::{RawStorage, Storage, StorageShared, StorageSharedExt};
use crate::storage::traits::IsShared;

pub(crate) struct SharedBuf<A> {
    buf: AlignedBuf<A>,
}

pub struct ArcRepr<A> {
    inner: Arc<SharedBuf<A>>,
}

impl<A> ArcRepr<A> {
    /// Creates an empty `ArcRepr<A>`.
    ///
    /// This is the zero-allocation constructor used by `Default::default()`.
    pub fn new() -> Self {
        Self::from_aligned_buf(AlignedBuf::empty())
    }

    pub(crate) fn from_aligned_buf(buf: AlignedBuf<A>) -> Self {
        Self { inner: Arc::new(SharedBuf { buf }) }
    }

    pub fn from_vec(data: Vec<A>) -> Result<Self, XenonError>
    where
        A: Copy,
    {
        let buf = AlignedBuf::from_vec(data)?;
        Ok(Self::from_aligned_buf(buf))
    }

    pub fn from_vec_aligned(data: Vec<A>) -> Result<Self, XenonError>
    where
        A: Copy,
    {
        let buf = AlignedBuf::from_vec_aligned(data)?;
        Ok(Self::from_aligned_buf(buf))
    }

    pub fn zeros(len: usize) -> Result<Self, XenonError>
    where
        A: Element + Default,
    {
        let buf = AlignedBuf::zeros(len)?;
        Ok(Self::from_aligned_buf(buf))
    }

    pub fn from_elem(len: usize, value: A) -> Result<Self, XenonError>
    where
        A: Element + Clone,
    {
        let buf = AlignedBuf::from_elem(len, value)?;
        Ok(Self::from_aligned_buf(buf))
    }

    pub(crate) fn ref_count(&self) -> usize { Arc::strong_count(&self.inner) }

    pub(crate) fn is_unique(&self) -> bool { Arc::strong_count(&self.inner) == 1 }
}

impl<A> Clone for ArcRepr<A> {
    fn clone(&self) -> Self { Self { inner: Arc::clone(&self.inner) } }
}

unsafe impl<A: Element> RawStorage for ArcRepr<A> {
    type Elem = A;
    fn as_ptr(&self) -> *const A { self.inner.buf.as_ptr() }
    fn len(&self) -> usize { self.inner.buf.len() }
}

unsafe impl<A: Element> Storage for ArcRepr<A> {}
unsafe impl<A: Element> StorageShared for ArcRepr<A> {}

impl<A: Element> StorageSharedExt for ArcRepr<A> {
    fn is_unique(&self) -> bool { self.is_unique() }
    fn ref_count(&self) -> usize { self.ref_count() }
}

impl<A> crate::private::Sealed for ArcRepr<A> {}
unsafe impl<A: Element> IsShared for ArcRepr<A> {}
```

`SharedBuf<A>` does not expose `&mut [A]` publicly. Its underlying `AlignedBuf<A>` owns and drops the allocation with the original layout, so when the last `Arc` is dropped the aligned allocation is released by `AlignedBuf`'s `Drop` implementation. `from_vec_aligned` may take a zero-copy path only when `AlignedBuf` can prove the incoming allocation already satisfies the storage alignment contract; otherwise it must copy into a fresh aligned allocation. ZST and empty buffers must use the `AlignedBuf` dangling-pointer/no-dealloc paths from `05-storage.md §6.1` and §6.3.

参考 `docs/design/05-storage.md` 的「测试计划」为本 task 增加以下测试：

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::storage::alloc::AlignedAlloc;

    #[test]
    fn test_arc_ref_count() {
        let arc = ArcRepr::from_vec(vec![1_i32, 2]).unwrap();
        let cloned = arc.clone();
        assert_eq!(arc.as_slice(), cloned.as_slice());
        assert_eq!(arc.ref_count(), 2);
        assert!(!arc.is_unique());
    }

    #[test]
    fn test_arc_clone_o1() {
        let arc = ArcRepr::from_vec(vec![1_i32, 2, 3]).unwrap();
        let ptr = arc.as_ptr();
        let cloned = arc.clone();

        assert_eq!(arc.as_ptr(), ptr);
        assert_eq!(cloned.as_ptr(), ptr);
        assert_eq!(arc.ref_count(), 2);
    }

    #[test]
    fn test_arc_alignment_preserved() {
        let arc = ArcRepr::from_vec(vec![1_i32, 2, 3, 4]).unwrap();
        assert_eq!((arc.as_ptr() as usize) % AlignedAlloc::DEFAULT_ALIGNMENT, 0);
    }

    #[test]
    fn test_arc_zst() {
        let arc = ArcRepr::<()>::from_elem(1024, ()).unwrap();
        assert_eq!(arc.len(), 1024);
    }

    #[test]
    fn test_arc_empty() {
        let arc = ArcRepr::<i32>::from_vec(Vec::new()).unwrap();
        assert!(arc.is_empty());
        assert!(arc.is_unique());
    }
}
```

CoW tests named `test_arc_cow` and `test_arc_internal_cow_unique` should be added with W7T17 or the later task that introduces the cross-task `into_owned_storage` / internal CoW helper surface. W7T16 must still expose `is_unique` / `ref_count` so that later task can test the CoW fast path without changing the public `StorageShared` marker trait.

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 使用 `Arc<SharedBuf<A>>` 而非 `Arc<[A]>` | `05-storage.md §6.6` / §6.7 要求共享表示继续包装 `AlignedBuf<A>`，保留 64 字节对齐与原始 layout drop 语义 |
| `ArcRepr` 只实现 `RawStorage` / `Storage` / `StorageShared` / `IsShared`，不实现 `StorageMut` | `05-storage.md §5.10` trait 实现矩阵将 `ArcRepr<A>` 定义为共享只读存储 |
| `from_vec` / `from_vec_aligned` / `zeros` / `from_elem` 直接构造 `AlignedBuf`，不调用 `Owned::*` | `PLAN.md` W7 批次8 与 `SUMMARY.md` 第 174 行规定 W7T16 仅依赖 W7T5；`05-storage.md §6.1` 定义底层 `AlignedBuf` helper |
| `ref_count` / `is_unique` 保持 crate-internal helper，而非公开 API | `05-storage.md §5.8` 定义 `StorageSharedExt` 为内部诊断与 CoW helper 边界 |

## 注意事项

- ZST 与空数组必须复用 `AlignedBuf` 的 dangling-pointer/no-dealloc 路径，不能调用 `AlignedAlloc` 分配 0 字节。
- `ArcRepr` 不允许实现 `StorageMut`，公开 API 不得暴露 `&mut A` 或 `&mut [A]`。
- W7T16 不得依赖 W7T8/W7T12，也不得调用 `Owned::from_vec`、`Owned::zeros`、`Owned::from_elem` 或 `Owned::into_shared`。
- `tests/test_storage.rs` 明确禁止新增；集成覆盖应放入现有 tensor/index/ffi/iterator 测试文件或模块内测试。
