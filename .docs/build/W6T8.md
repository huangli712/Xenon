## 目标

替换 W6T3 写下的 `has_zero_stride` 占位实现，使其按 `06-layout §5.11` 公式 `HAS_ZERO_STRIDE := any(stride == 0) && product(shape) > 0` 进行检测。语义上分离为两个函数：

- `has_zero_stride`：**原始检测器**，只判断 stride 数组中是否含 0，不考虑 shape；W6T11 `compute_layout_flags` 在 §6.1 算法 step 1 中调用它的结果与 `product(shape) > 0` 组合产出最终 flag。
- `should_set_zero_stride_flag`（`pub(crate)`）：**flag 赋值守卫**，组合 `has_zero_stride` 与 `product(shape) > 0` 检查；W6T11 直接调用此守卫写入 `HAS_ZERO_STRIDE`。

参照 `docs/design/06-layout.md §5.1`（"零步长 helper 与 flag 赋值分离"）、§5.11（HAS_ZERO_STRIDE 形式化定义）、§6.1（算法 step 1）。

## 实施步骤

### Step 1: Implement zero-stride detection

替换 W6T3 占位体；在同一文件追加 `pub(crate) fn should_set_zero_stride_flag`。

```rust
/// Raw zero-stride detector: returns `true` iff any stride value equals 0.
///
/// **This is NOT the same as the `HAS_ZERO_STRIDE` flag value**: the flag
/// is set only when `product(shape) > 0` additionally holds. Use
/// `should_set_zero_stride_flag(shape, strides)` for flag assignment in
/// `compute_layout_flags` (`06-layout §5.11`, §6.1).
pub fn has_zero_stride<D: Dimension>(strides: &Strides<D>) -> bool {
    strides.as_slice().iter().any(|&s| s == 0)
}

/// Flag-assignment guard for `HAS_ZERO_STRIDE`.
///
/// Returns `true` iff `any(stride == 0) && product(shape) > 0`, which is
/// the formal definition from `06-layout §5.11`. Empty-array degenerate
/// metadata (`product(shape) == 0`) is excluded by this guard, so
/// `compute_layout_flags` MUST call this helper instead of bare
/// `has_zero_stride` when writing the bit.
pub(crate) fn should_set_zero_stride_flag<D: Dimension>(
    shape: &D,
    strides: &Strides<D>,
) -> bool {
    if !has_zero_stride(strides) {
        return false;
    }
    // product(shape) > 0 ⇔ every axis has extent > 0 (and product fits usize).
    // We do NOT need the exact product; just whether it is nonzero.
    shape.slice().iter().all(|&e| e > 0)
}
```

> **避免重复乘法溢出**：`product(shape) > 0` 等价于所有 extent > 0；无须实际计算累乘（`Dimension::checked_size` 已是 shape 的权威乘积函数），既避免重复溢出检查也保持函数零失败语义（不返回 Result）。

参考 `06-layout §8.2` 高优先级用例 `test_zero_stride_detect`（区分广播零步长与空数组退化零步长）：

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::dimension::Ix2;

    #[test]
    fn test_zero_stride_detect() {
        // §8.2 high priority: raw detector ignores shape.
        assert!(has_zero_stride(&Strides::new(Ix2(1, 0))));
        assert!(!has_zero_stride(&Strides::new(Ix2(1, 2))));
    }

    #[test]
    fn test_should_set_zero_stride_flag_broadcast() {
        // §5.11: non-empty shape with zero stride ⇒ broadcast ⇒ flag should be set.
        let shape = Ix2(5, 1);
        let strides = Strides::new(Ix2(1, 0));
        assert!(should_set_zero_stride_flag(&shape, &strides));
    }

    #[test]
    fn test_should_set_zero_stride_flag_empty() {
        // §5.11: empty shape (product == 0) ⇒ degenerate zero stride
        // ⇒ flag MUST NOT be set, even if strides contain 0.
        let shape = Ix2(0, 3);
        let strides = Strides::new(Ix2(1, 0));
        assert!(!should_set_zero_stride_flag(&shape, &strides));
    }

    #[test]
    fn test_should_set_zero_stride_flag_no_zero() {
        // §5.11: no zero stride ⇒ flag MUST NOT be set, regardless of shape.
        let shape = Ix2(5, 4);
        let strides = Strides::new(Ix2(1, 5));
        assert!(!should_set_zero_stride_flag(&shape, &strides));
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `has_zero_stride` 仅检测原始步长值是否为 0 | `06-layout §5.1` 注释「零步长 helper 与 flag 赋值分离」：原始检测器不判断语义；flag 赋值逻辑负责区分广播与空数组退化 |
| `should_set_zero_stride_flag` 加 `product(shape) > 0` 守卫 | `06-layout §5.11`：`HAS_ZERO_STRIDE := any(stride==0) && product(shape) > 0`；空数组的退化零步长不等于广播零步长，不应设置 `HAS_ZERO_STRIDE` |
| `should_set_zero_stride_flag` 标 `pub(crate)` | 仅供同 crate 的 `compute_layout_flags`（W6T11）使用；不向外暴露 |
| `product(shape) > 0` 等价于 `all(extent > 0)` | 避免重复乘法 + 溢出检查；`Dimension::checked_size` 已是 shape 乘积的唯一权威入口 |
| 两个函数分离 | `06-layout §5.1` 和 §6.1：调用点不同——`has_zero_stride` 用于调试/断言（暴露），flag 守卫用于 flags 赋值（crate 内） |
| 测试参数使用 `Ix2` | `has_zero_stride` 与 `should_set_zero_stride_flag` 的签名 `<D: Dimension>`；`[usize; N]` 仅实现 `IntoDimension` |

## 验证方式

1. 编译检查: `cargo check -p xenon`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test layout::strides::tests::test_zero_stride_detect`、`cargo test layout::strides::tests::test_should_set_zero_stride_flag_broadcast`、`...flag_empty`、`...flag_no_zero`
4. 手动验证: 广播 `(shape=[5,1], strides=[1,0])` → `should_set_zero_stride_flag` true；空数组 `(shape=[0,3], strides=[1,0])` → false。

## 注意事项

- `should_set_zero_stride_flag` 的可见性是 `pub(crate)`，不在 `pub use` 中暴露；外部模块查询零步长状态应通过 `LayoutFlags::has_zero_stride()`（W6T5）或 `LayoutFlags::classify()`。
- 替换 W6T3 占位体时只修改 `has_zero_stride` 的函数体；W6T1 mod.rs 的 `pub use ... has_zero_stride ...` 导出语句保持不变。
- W6T11 `compute_layout_flags` 在 `06-layout §6.1` 算法 step 1 中必须调用 `should_set_zero_stride_flag(shape, strides)`，而非直接调用 `has_zero_stride`。
