## 目标

创建 `src/broadcast/mod.rs` 模块入口：声明 `shape` / `view` 子模块；按 `15-broadcast.md §5.1` 公开三个 shape 自由函数；按 §5.1 line 134 与 §5.2 line 172 把 `broadcast_with` 限定为 `pub(crate)`；`broadcast_to` 作为 `TensorBase` 的 inherent 方法（W11T3 骨架，W11T7-T8 实现），通过 `TensorBase` 类型自动可见，不需在模块顶层 re-export。

本 task **只**在 `src/lib.rs` 新增 `pub mod broadcast;` 一行（依据 `W1T3.md` 协议表第 171 行）；**不修改** `src/prelude.rs` —— `01-architecture.md §7` 第 540-577 行的 prelude 导出清单为封闭白名单，未包含 broadcast 模块的任何函数。

## 实施步骤

### Step 1: 创建 src/broadcast/mod.rs

仅完成模块声明与 re-export，不引入任何实现。`broadcast_with` 严格按 `15-broadcast.md §5.1` 限定为 `pub(crate)`：

```rust
//! Broadcasting utilities.
//!
//! Public API list (see `15-broadcast.md §5.1`):
//! - `broadcast_shape(a, b) -> Result<IxDyn, XenonError>`
//! - `can_broadcast(a, b) -> bool`
//! - `broadcast_strides(orig_shape, orig_strides, target_shape) -> Result<Vec<usize>, XenonError>`
//! - `TensorBase::broadcast_to<E: IntoDimension>(&self, shape: E)`
//!   — inherent method on `TensorBase`, defined in `view.rs`; visible via `TensorBase`.
//! - `broadcast_with(a, b)` — `pub(crate)` dual-input entry consumed by `math` / `overload`.

mod shape;
mod view;

pub use shape::{broadcast_shape, broadcast_strides, can_broadcast};

// `broadcast_with` is `pub(crate)` per 15-broadcast.md §5.1 line 134 / §5.2 line 172:
// dual-input broadcasting is an internal entry point consumed by `math` / `overload`,
// NOT part of Xenon's public surface. Widening to `pub` would violate the API contract.
pub(crate) use view::broadcast_with;

// NOTE: `broadcast_to` is an inherent method on `TensorBase` (defined in view.rs per §5.1
// line 124-132). It is automatically visible through `TensorBase` and must NOT be
// re-exported as a free function here.
```

### Step 2: 接入 crate root

按 `W1T3.md`「lib.rs 模块声明演进协议」表（第 171 行），W11 的 lib.rs 改动**仅限于新增一行** `pub mod broadcast;`：

```rust
// src/lib.rs（在已有 pub mod tensor; / pub mod layout; 等声明之后新增此一行）
pub mod broadcast;
```

**禁止**：在本 task 内修改 `src/prelude.rs`，或在 `src/lib.rs` 中扩展 `pub mod prelude { ... }`。`01-architecture.md §7` 第 540-577 行的 prelude 导出清单为**封闭白名单**，不包含 broadcast 模块的任何函数；下游用户必须通过完整路径 `xenon::broadcast::{broadcast_shape, broadcast_strides, can_broadcast}` 访问。

### Step 3: 单元测试

> **强制要求**:
> - 本步骤必须包含一个或者多个单元测试。
> - 测试函数名称和测试内容必须参考对应设计文档的 **「测试计划」** 一节。
> - 编译检查与Lint检查不等同于单元测试。
> - 如果测试没有通过需要修复直至测试通过。
> - **无测试 = 任务未完成。**

> 注意: 本 task 仅创建模块骨架与导出入口，下游函数（`can_broadcast`、`broadcast_shape`、`broadcast_strides`）此时为 W11T2 的 `todo!()` stub。Step 3 测试**仅**验证导出可访问性（签名编译检查），不调用任何 stub（调用会 panic）。功能正确性测试从 W11T4-T6 逐步引入。

```rust
#[cfg(test)]
mod tests {
    use crate::broadcast::{broadcast_shape, broadcast_strides, can_broadcast};
    use crate::dimension::IxDyn;
    use crate::error::XenonError;

    /// Compile-only check that the broadcast module's public exports are reachable
    /// from `crate::broadcast` with the exact signatures declared in
    /// `15-broadcast.md §5.1`. Does NOT call the functions (W11T2 stubs panic).
    #[test]
    fn test_broadcast_module_exports_compile() {
        let _: fn(&[usize], &[usize]) -> bool = can_broadcast;
        let _: fn(&[usize], &[usize]) -> Result<IxDyn, XenonError> = broadcast_shape;
        let _: fn(&[usize], &[usize], &[usize]) -> Result<Vec<usize>, XenonError> = broadcast_strides;
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `broadcast_with` 暴露为 `pub(crate)`，不进入 crate 公共 API | 15-broadcast §5.1 line 134、§5.2 line 172：明确为 `pub(crate)` 自由函数 |
| 不在 prelude 中重导出 broadcast 模块的任何函数 | 01-architecture.md §7 第 540-577 行 prelude 导出清单为封闭白名单，未包含 broadcast 项 |
| `broadcast_to` 不通过 `pub use` 暴露 | 15-broadcast §5.1 line 124-132、§5.2 line 172：作为 `TensorBase` 的 inherent 方法天然可见 |
| `src/lib.rs` 仅新增 `pub mod broadcast;` 一行 | W1T3.md 模块声明演进协议表第 171 行 |

## 验证方式

1. 编译检查: `cargo check`（确认 `src/lib.rs` 与 `src/broadcast/mod.rs` 联合可编译；下游 `shape::*` / `view::broadcast_with` 的 `todo!()` stub 可被引用）
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test --lib broadcast::tests::test_broadcast_module_exports_compile`
4. 反向验证: 在临时 example 中尝试 `use xenon::prelude::broadcast_shape;` 必须**编译失败**（确认 prelude 未被污染）；`use xenon::broadcast::broadcast_shape;` 必须成功。

## 注意事项

- 本 task 不实现任何函数逻辑；shape 三函数与 `broadcast_with` 的功能由 W11T2-T9 逐步引入。
- `broadcast_to` 是 `TensorBase` 的 inherent 方法（W11T3 定义 `todo!()` 骨架；W11T7-T8 实现），通过 `TensorBase` 类型自动可见，不能也不应该通过 `pub use` 在 broadcast 模块顶层重导出。
- 本 task 必须在 `src/lib.rs` 添加 `pub mod broadcast;`（依据 `W1T3.md` 协议表第 171 行）；**禁止**修改 `src/prelude.rs` 或在 `src/lib.rs` 中重写 `pub mod prelude { ... }`。
- `broadcast_with` 的 `pub(crate)` 可见性是设计契约，W11T9 实现时不得放宽为 `pub`。
