## 实施步骤

### Step 1: 确认实现边界

依据 `17-indexing §5.1`：本 task 产出 `SliceInfoElem`、`SliceInfoIndices`、`SliceInfo<I, D>` 三类公开类型，外加 `SliceInfo::new` 构造器与 getter（`indices()` / `input_dim()` / `output_dim()`）。

构造器需完成 **三条** 结构性校验（设计文档 line 219–223）：
1. `indices.len() == in_dim.ndim()`
2. `out_dim.ndim() == count_of(Range)`
3. **每个 `Range { start, end }` 必须满足 `start <= end`**

shape 边界校验（Range.end ≤ shape[axis]、Index < shape[axis]）由 W21T6 的 `TensorBase::slice(info)` 负责，本 task **不**做。

`SliceInfoIndices` 必须按设计 line 232 的"优先 Inline"规则选择表示：`indices.len() <= 6` 走 `Inline`，否则走 `Dynamic`。

### Step 2: 实现任务目标

```rust
use std::borrow::Cow;

use crate::dimension::Dimension;
use crate::error::{InvalidArgumentKind, Result, XenonError};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SliceInfoElem {
    Index(usize),
    Range { start: usize, end: usize },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SliceInfoIndices {
    /// Fixed-capacity inline representation; covers Ix0..Ix6 slice descriptors
    /// without heap allocation (17-indexing §5.1 line 232).
    Inline { len: u8, elems: [Option<SliceInfoElem>; 6] },
    /// Heap-backed fallback for IxDyn with rank > 6.
    Dynamic(Vec<SliceInfoElem>),
}

impl SliceInfoIndices {
    /// Constructor that automatically selects the optimal representation per
    /// 17-indexing §5.1 line 232: prefer `Inline` whenever possible.
    pub fn from_vec(elems: Vec<SliceInfoElem>) -> Self {
        if elems.len() <= 6 {
            let mut buf: [Option<SliceInfoElem>; 6] = [None; 6];
            let len = elems.len() as u8;
            for (slot, elem) in buf.iter_mut().zip(elems.into_iter()) {
                *slot = Some(elem);
            }
            Self::Inline { len, elems: buf }
        } else {
            Self::Dynamic(elems)
        }
    }

    /// Inline constructor for compile-time-sized slice descriptors. Enables
    /// `SliceInfoIndices::from_array([SliceInfoElem::Index(0), ...])` without
    /// any heap touch.
    pub fn from_array<const N: usize>(arr: [SliceInfoElem; N]) -> Self {
        // const_assert at compile-time: N <= 6 for the Inline branch.
        // For N > 6, fall back to Dynamic.
        if N <= 6 {
            let mut buf: [Option<SliceInfoElem>; 6] = [None; 6];
            for (slot, elem) in buf.iter_mut().zip(arr.iter()) {
                *slot = Some(*elem);
            }
            Self::Inline { len: N as u8, elems: buf }
        } else {
            Self::Dynamic(arr.to_vec())
        }
    }

    pub fn len(&self) -> usize {
        match self {
            Self::Inline { len, .. } => *len as usize,
            Self::Dynamic(v) => v.len(),
        }
    }

    pub fn is_empty(&self) -> bool {
        self.len() == 0
    }

    /// Yields each `SliceInfoElem` by value — `SliceInfoElem: Copy`, so
    /// by-value iteration is cheap and unifies the Inline/Dynamic storage
    /// without a self-referential iterator struct.
    pub fn iter(&self) -> SliceInfoIter<'_> {
        SliceInfoIter { source: self, pos: 0 }
    }
}

/// Iterator over `SliceInfoIndices` yielding `SliceInfoElem` by value.
pub struct SliceInfoIter<'a> {
    source: &'a SliceInfoIndices,
    pos: usize,
}

impl Iterator for SliceInfoIter<'_> {
    type Item = SliceInfoElem;

    fn next(&mut self) -> Option<Self::Item> {
        match self.source {
            SliceInfoIndices::Inline { len, elems } => {
                if self.pos < *len as usize {
                    // INVARIANT (established by SliceInfoIndices::from_vec /
                    // ::from_array): the prefix `elems[..len]` is always
                    // Some(..). We assert this in debug builds and use
                    // unwrap_unchecked in release to avoid the unwrap branch
                    // on the hot iteration path.
                    let slot = &elems[self.pos];
                    debug_assert!(
                        slot.is_some(),
                        "SliceInfoIndices::Inline invariant violated at pos {}",
                        self.pos
                    );
                    // SAFETY: SliceInfoIndices construction guarantees that
                    // `elems[..len]` are all Some. `self.pos < len` was checked
                    // by the outer `if`. debug_assert above confirms invariant
                    // under debug_assertions.
                    let elem = unsafe { slot.unwrap_unchecked() };
                    self.pos += 1;
                    Some(elem)
                } else {
                    None
                }
            }
            SliceInfoIndices::Dynamic(v) => {
                let elem = *v.get(self.pos)?;
                self.pos += 1;
                Some(elem)
            }
        }
    }
}

pub struct SliceInfo<I: Dimension, D: Dimension> {
    indices: SliceInfoIndices,
    in_dim: D,
    out_dim: I,
}

impl<I: Dimension, D: Dimension> SliceInfo<I, D> {
    /// Constructs a `SliceInfo` with structural validation.
    ///
    /// Per 17-indexing §5.1, performs three checks (and ONLY these three;
    /// shape-aware bounds are deferred to `TensorBase::slice(info)`):
    /// 1. `indices.len() == in_dim.ndim()`
    /// 2. `out_dim.ndim() == count_of(Range)`
    /// 3. each `Range { start, end }` satisfies `start <= end`
    pub fn new(indices: SliceInfoIndices, in_dim: D, out_dim: I) -> Result<Self> {
        // Check 1: rank match.
        if indices.len() != in_dim.ndim() {
            return Err(XenonError::InvalidArgument {
                operation: Cow::Borrowed("SliceInfo::new"),
                kind: InvalidArgumentKind::OperationSpecific {
                    reason: Cow::Borrowed("slice rank does not match input dimension"),
                },
            });
        }
        // Check 2: output rank == Range count.
        let ranges = indices
            .iter()
            .filter(|elem| matches!(elem, SliceInfoElem::Range { .. }))
            .count();
        if ranges != out_dim.ndim() {
            return Err(XenonError::InvalidArgument {
                operation: Cow::Borrowed("SliceInfo::new"),
                kind: InvalidArgumentKind::OperationSpecific {
                    reason: Cow::Borrowed("slice output rank does not match Range count"),
                },
            });
        }
        // Check 3 (required by 17-indexing §5.1 line 223): Range start <= end.
        for (axis, elem) in indices.iter().enumerate() {
            if let SliceInfoElem::Range { start, end } = *elem {
                if start > end {
                    return Err(XenonError::InvalidArgument {
                        operation: Cow::Borrowed("SliceInfo::new"),
                        kind: InvalidArgumentKind::RangeStartAfterEnd { axis, start, end },
                    });
                }
            }
        }
        Ok(Self { indices, in_dim, out_dim })
    }

    pub fn indices(&self) -> &SliceInfoIndices { &self.indices }
    pub fn input_dim(&self) -> &D { &self.in_dim }
    pub fn output_dim(&self) -> &I { &self.out_dim }
}
```

> 实现注记：`SliceInfoIter` 的实现是为统一 `Inline { elems: [Option<_>; 6] }` 与 `Dynamic(Vec<_>)` 元素表示的差异（前者是 `Option<SliceInfoElem>`，后者是 `SliceInfoElem`）。由于 `SliceInfoElem: Copy + Debug + PartialEq + Eq`，迭代器按**值**产出 `Item = SliceInfoElem`（**不是** `&SliceInfoElem`）—— 这样 Inline / Dynamic 两个分支可以走同一个 `next()` 路径，避免自引用迭代器结构和生命周期纠葛。W21T6 在 `for elem in info.indices().iter()` 处直接按值绑定 `elem: SliceInfoElem`，与本实现契合。

#[cfg(test)]
mod tests {
    use super::*;
    use crate::dimension::{Ix1, Ix2};
    use crate::error::InvalidArgumentKind;

    #[test]
    fn test_slice_basic() {
        // Per 17-indexing §8.2 priority "高": valid SliceInfo construction.
        let info = SliceInfo::new(
            SliceInfoIndices::from_vec(vec![
                SliceInfoElem::Index(1),
                SliceInfoElem::Range { start: 0, end: 3 },
            ]),
            Ix2(2, 3),
            Ix1(3),
        );
        assert!(info.is_ok());
    }

    #[test]
    fn test_slice_info_rank_mismatch() {
        // Check 1: indices.len() != in_dim.ndim().
        let err = SliceInfo::new(
            SliceInfoIndices::from_vec(vec![SliceInfoElem::Index(0)]),
            Ix2(2, 3),
            Ix1(0),
        )
        .unwrap_err();
        assert!(matches!(
            err,
            XenonError::InvalidArgument { kind: InvalidArgumentKind::OperationSpecific { .. }, .. }
        ));
    }

    #[test]
    fn test_slice_info_output_rank_mismatch() {
        // Check 2: out_dim.ndim() != count_of(Range). Two Ranges, but out_dim is Ix1.
        let err = SliceInfo::new(
            SliceInfoIndices::from_vec(vec![
                SliceInfoElem::Range { start: 0, end: 2 },
                SliceInfoElem::Range { start: 0, end: 3 },
            ]),
            Ix2(2, 3),
            Ix1(2),
        )
        .unwrap_err();
        assert!(matches!(
            err,
            XenonError::InvalidArgument { kind: InvalidArgumentKind::OperationSpecific { .. }, .. }
        ));
    }

    #[test]
    fn test_slice_info_range_start_after_end() {
        // Check 3 (per 17-indexing §5.1 line 223): Range start > end.
        let err = SliceInfo::new(
            SliceInfoIndices::from_vec(vec![
                SliceInfoElem::Range { start: 5, end: 2 },
                SliceInfoElem::Index(0),
            ]),
            Ix2(10, 3),
            Ix1(3),
        )
        .unwrap_err();
        assert!(matches!(
            err,
            XenonError::InvalidArgument {
                kind: InvalidArgumentKind::RangeStartAfterEnd { axis: 0, start: 5, end: 2 },
                ..
            }
        ));
    }

    #[test]
    fn test_slice_info_indices_prefers_inline() {
        // Per 17-indexing §5.1 line 232: prefer Inline when len <= 6.
        let indices = SliceInfoIndices::from_vec(vec![
            SliceInfoElem::Index(0),
            SliceInfoElem::Range { start: 0, end: 2 },
        ]);
        assert!(matches!(indices, SliceInfoIndices::Inline { len: 2, .. }));
    }

    #[test]
    fn test_slice_info_indices_falls_back_to_dynamic() {
        // len > 6 → must use Dynamic (IxDyn high rank).
        let elems: Vec<SliceInfoElem> = (0..7).map(SliceInfoElem::Index).collect();
        let indices = SliceInfoIndices::from_vec(elems);
        assert!(matches!(indices, SliceInfoIndices::Dynamic(_)));
    }
}

## 关键设计决策

1. 依据 `17-indexing §5.1 line 219–223`，`SliceInfo::new` 执行 **三条** 结构性校验（rank / output rank / `start <= end`），**缺一不可**。第三条是本次修订补齐的；没有它，下游 `end - start` 在 W21T6 会触发 `usize` 减法下溢 panic。
2. 依据 `17-indexing §5.1 line 232`，`SliceInfoIndices::from_vec` 必须根据 `len <= 6` 自动选择 `Inline` 分支，使 `Inline` 成为默认路径而非死代码；`from_array` 进一步避免堆分配。
3. 依据 `26-error §5`，所有结构性校验失败返回 `XenonError::InvalidArgument { kind: InvalidArgumentKind::* }` 的结构化形式；不得退化为 `Cow<str>` 自由文本。
4. 依据 `17-indexing §5.1`，shape 边界校验（`Range.end <= shape[axis]`、`Index < shape[axis]`）**明确不在**本 task 范围，由 W21T6 负责。
5. 依据 Wave 21 依赖层级，本 task 不新增第三方依赖，也不改变 W2 / W3 的 public contract。

## 注意事项

- `SliceInfoElem: Copy`，`SliceInfoIter` 按值产出即可，不需要自引用结构；实施时若生命周期仍有问题，可改为返回 `impl Iterator<Item = SliceInfoElem>` 进一步简化。
- `Inline` 分支必须在 W21T6 中正确处理 `Option<SliceInfoElem>` 的展开（prefix `[..len]` 保证 `Some(..)` 的不变式由 `from_vec` / `from_array` 维护）。
- 不做 shape 边界校验（留给 W21T6）；不引入 `RangeFrom` / `RangeTo` 省略语法（设计文档 line 230：进入 `SliceInfoElem::Range` 前已规范化为显式 `start` / `end`）。
