recomputation, 1D no-op composition, view storage kind, Ix6/IxDyn boundaries
(`tests/test_shape.rs`), and property-test invariants per 16-shape.md §8.1
line 299 (`tests/property/test_shape.rs`: len preservation, involution, data
invariance).

use xenon::{ArcTensor, Ix0, Ix1, Ix2, Ix3, StorageKind, Tensor, Tensor1};

#[test]
fn test_shape_integration_transpose_2d() {
    let x = Tensor::<i32, Ix2>::from_shape_vec((2, 3), vec![1, 2, 3, 4, 5, 6]).unwrap();
    let y = x.transpose();
    assert_eq!(y.shape(), &[3, 2]);
    // Per 16-shape.md §5.4 and 17-indexing.md §5: `[]` indexing is
    // intentionally not implemented; element access uses `try_at`.
    assert_eq!(
        *y.try_at(&[0_usize, 0][..]).unwrap(),
        *x.try_at(&[0_usize, 0][..]).unwrap(),
    );
    assert_eq!(
        *y.try_at(&[2_usize, 1][..]).unwrap(),
        *x.try_at(&[1_usize, 2][..]).unwrap(),
    );
}

#[test]
fn test_shape_integration_transpose_3d() {
    let x = Tensor::<i32, Ix3>::zeros((2, 3, 4)).unwrap();
    assert_eq!(x.transpose().shape(), &[4, 3, 2]);
}

```rust
#[test]
fn test_shape_integration_transpose_view_kind() {
    let x = Tensor::<i32, Ix2>::zeros((2, 3)).unwrap();
    assert_eq!(x.transpose().storage_kind(), StorageKind::View);
}

#[test]
fn test_shape_integration_transpose_arc_tensor_view_kind() {
    // ArcRepr → ViewRepr demotion (16-shape.md §5.3): storage_kind() must
    // report View, not Shared, after transpose.
    let x = ArcTensor::<i32, Ix2>::zeros((2, 3)).unwrap();
    assert_eq!(x.transpose().storage_kind(), StorageKind::View);
}

#[test]
fn test_shape_integration_transpose_with_index() {
    // transpose + index: verify that element access works after axis reversal.
    // Per 16-shape.md §5.4 and 17-indexing.md §5: `[]` indexing is intentionally
    // not implemented; element access uses `try_at`.
    let x = Tensor::<i32, Ix2>::from_shape_vec((2, 3), vec![1, 2, 3, 4, 5, 6]).unwrap();
    let y = x.transpose();
    // Check that elements accessed via the reversed axes match originals
    for i in 0..2_usize {
        for j in 0..3_usize {
            assert_eq!(
                *y.try_at(&[j, i][..]).unwrap(),
                *x.try_at(&[i, j][..]).unwrap(),
                "element mismatch at original [{},{}]",
                i,
                j,
            );
        }
    }
}

#[test]
#[ignore = "depends on W11 broadcast module"]
fn test_shape_integration_transpose_with_broadcast() {
    // transpose + broadcast: verify that shape logic composes correctly.
    // After broadcast expands dimensions, transpose still reverses them.
    // Extend when broadcast module is available.
    // e.g.: let y = broadcast.transpose(); assert_eq!(y.shape(), ...);
}

// Boundary: high static rank (Ix6)
#[test]
fn test_shape_integration_transpose_6d() {
    // Full axis reversal with 6D — verify axes reversed correctly.
    // Use zeros to avoid needing large data array.
    use xenon::Ix6;
    let x = Tensor::<f64, Ix6>::zeros((2, 3, 4, 5, 6, 7)).unwrap();
    let y = x.transpose();
    assert_eq!(y.shape(), &[7, 6, 5, 4, 3, 2]);
    assert_eq!(y.transpose().shape(), x.shape());
}

// Boundary: dynamic rank transpose
#[test]
fn test_shape_integration_transpose_dyn() {
    use xenon::IxDyn;
    let x = Tensor::<i32, IxDyn>::zeros(IxDyn(&[2, 3, 4, 5, 6])).unwrap();
    let y = x.transpose();
    assert_eq!(y.shape(), &[6, 5, 4, 3, 2]);
    assert_eq!(y.len(), x.len());
    assert_eq!(y.transpose().strides(), x.strides());
}

// Boundary: large array O(1) — 16-shape.md §7 T3 line 283 "大数组 O(1) 行为" /
// §8.3 line 322 "`[3162, 3162]` 转置 O(1)". Validates the zero-copy contract
// of transpose by observing that the resulting view:
//   1. reports `StorageKind::View` (no new allocation, no element copy);
//   2. preserves `len()` and the round-trip shape/strides identity
//      (double-transpose returns to the original metadata);
//   3. has its logical-first pointer unchanged from the source — transpose
//      preserves `offset`, so `as_ptr()` must equal the source's.
// We deliberately avoid wall-clock assertions: `[3162, 3162]` allocates
// ~40 MiB of `f64` and is handled at source-construction time; the transpose
// itself is O(ndim) metadata work and cannot touch the 10^7 elements
// without breaking at least one of the invariants above.
#[test]
fn test_shape_integration_transpose_large_array_2d() {
    let x = Tensor::<f64, Ix2>::zeros((3162, 3162)).unwrap();
    let src_ptr = x.as_ptr();
    let y = x.transpose();
    assert_eq!(y.storage_kind(), StorageKind::View);
    assert_eq!(y.shape(), &[3162, 3162]);
    assert_eq!(y.len(), x.len());
    // Zero-copy: logical-first pointer unchanged (offset preserved).
    assert_eq!(y.as_ptr(), src_ptr);
    // Involution on metadata.
    assert_eq!(y.transpose().shape(), x.shape());
    assert_eq!(y.transpose().strides(), x.strides());
}
```

## 关键设计决策

- Integration tests cover public behavior rather than private constructor details.
- 0D and 1D transpose preserve rank and length.
- Storage-kind verification protects the zero-copy contract; both `Tensor`
  (Owned) and `ArcTensor` (`ArcRepr`) sources are covered to validate the
  16-shape.md §5.3 storage demotion table.
- **属性测试目录独立**：严格遵循设计 §8.1 line 299 的测试分类，属性测试
  位置为 `tests/property/test_shape.rs`，与集成测试 `tests/test_shape.rs`
  分离；不合并目录。
- **Cargo 集成测试子目录不自动发现**：Rust/Cargo 只对 `tests/` 顺位的 `.rs`
  文件自动创建 test target；子目录如 `tests/property/` 中的文件必须
  通过入口文件的 `mod` 声明串联。本 task 采用**中间层转发**：
  `tests/property_tests.rs` 追加 `mod property;`，该声明查找
  `tests/property/mod.rs`（本 task 创建，含 `pub mod test_shape;`），后者
  转发到 `tests/property/test_shape.rs`。不能直接在 `tests/property_tests.rs`
  中写 `mod test_shape;`，因为该声明会查找 `tests/test_shape.rs`（集成
  测试文件，已存在）造成冲突。与 W29T22 同一机制，后续同一入口
  文件复用 `mod property;`，同一 `tests/property/mod.rs` 追加
  `pub mod tensor_props;` 等。
- **`[]` 索引语法不可用**：所有元素访问按 16-shape.md §5.4 / 17-indexing.md §5
  使用 `try_at`，而不是 `tensor[[i, j]]`。
