## 目标

Reduction/dot semantic + tolerance tests: float/complex/int SIMD entry condition constraints。

本任务在 `src/simd/vector.rs` 内 `#[cfg(all(test, feature = "simd"))] mod tests` 中追加 reduction/dot 语义、容差与 entry condition 测试。W14T9 不测试 add/sub/mul/div/neg（归 W14T8）；本 task 只覆盖 sum/dot 的浮点、复数、整数准入和非有限值边界。

浮点和复数 sum tolerance 引用 `13-reduction.md §6.3` 动态公式；dot tolerance 以 `12-matrix.md` 的 dot 语义为调用入口，并复用 13-reduction.md §6.3 的分量级 reduction merge 容差。不得硬编码 `1e-10` 或 `1e-5` 作为无来源容差。

- W14T3 提供 f32/f64 sum facade，W14T4 提供 i32 admission（i64 无 SIMD facade），W14T5 提供 Complex sum，W14T6 提供 float/complex dot，W14T8 建立同一 `#[cfg(test)]` 测试模块框架。
- 阅读 `src/simd/vector.rs` 现有测试模块，在 W14T8 的 `#[cfg(all(test, feature = "simd"))] mod tests` 中追加本 task 测试，不提升 `pub(crate)` API 可见性。
- 对照 08-simd §5.8、§6.6、§8.2-§8.4 和 §8.6，确认 threshold、ISA gating、platform rejection、NaN/Inf/±0.0 与 cancellation 边界均被测试或在代码注释中显式约束。
- W14T9 不测 add/sub/mul/div/neg（归 W14T8）；W14T8 不测 sum/dot（归本 task）。

## 实施步骤

### Step 1: Add tolerance checks for f32/f64 sum and dot

Add f32 and f64 sum/dot tolerance tests only. Use dynamic tolerance from `13-reduction.md §6.3`:

```rust
let tol = 4.0 * f64::EPSILON * (n as f64) * max_abs_input;
```

For f32 tests, compute the same formula in `f32` using `f32::EPSILON`, then compare as `f32`. The tolerance comment must include: `tolerance per 13-reduction.md §6.3: 4·ε·n·max_abs_input`.

### Step 2: Add complex sum and dot checks over non-trivial real/imag values

Add complex tests only in this step. Complex sum must cover `try_sum_complex_f64` with at least 1024 elements and compare real/imag components independently. Complex dot must compare `(simd.re - scalar.re)` and `(simd.im - scalar.im)` separately instead of using `.norm()`.

Also add f32 variants for `try_sum_complex_f32` and `try_dot_complex_f32`. Complex dot must preserve the `sum(conj(lhs_i) * rhs_i)` contract.

### Step 3: Assert integer admission rules (i32 only; i64 has no SIMD facade)

Use i32 as the only integer SIMD admission type. Test `try_sum_i32` at its documented threshold and `try_dot_i32` at its documented threshold, accepting `None` on platforms where widening is unavailable and verifying exact scalar equality when `Some` is returned. The i32 facade narrows its internal `i64` accumulator back to `i32` via `i32::try_from`; the test's scalar baseline also performs checked sum/dot in `i32` so that `Some` outputs line up.

Do not test `try_sum_i64` or `try_dot_i64`: these symbols do not exist in the SIMD module. i64 sum/dot stay entirely in the caller's scalar `checked_*` path per 08-simd §6.6 and W14T7 facade export boundary. Introducing a `try_sum_i64(...).is_none()` assertion would reference a non-existent symbol and fail to compile.

### Step 4: Cover entry conditions, feature gating, and platform rejection

Add `test_entry_threshold_boundary` for sum f64 with `len=1023 -> None` and `len=1024 -> Some` when the platform admits SIMD. Add `test_isa_gating_fallback` as a cfg-documented test showing that without `feature = "simd"`, these internal `try_*` functions are not compiled into the module. Add `test_admission_platform_rejection` as a comment-backed test that documents platforms without required widening return `None`.

### Step 5: Cover non-finite and boundary reduction values

Add tests for NaN propagation, ±Inf sign consistency, large positive/negative cancellation, and boundary lengths `SIMD_WIDTH` and `SIMD_WIDTH + 1`. NaN comparisons should only check `is_nan()`. Inf and signed zero checks must not be hidden by finite-value tolerance.

### Step 6: 单元测试

添加覆盖设计文档测试计划的单元测试，包含 entry condition、dynamic tolerance、complex real/imag 分量、i32 admission（i64 无 facade，不在测试范围内）、NaN/Inf/cancellation 和边界长度。

```rust
#[cfg(all(test, feature = "simd"))]
mod tests {
    use super::*;
    use crate::complex::Complex;

    const SIMD_WIDTH: usize = 64;

    fn tolerance_f64(data: &[f64]) -> f64 {
        let n = data.len();
        let max_abs_input = data.iter()
            .copied()
            .map(f64::abs)
            .fold(0.0_f64, f64::max);
        // tolerance per 13-reduction.md §6.3: 4·ε·n·max_abs_input
        4.0 * f64::EPSILON * (n as f64) * max_abs_input
    }

    fn tolerance_f32(data: &[f32]) -> f32 {
        let n = data.len();
        let max_abs_input = data.iter()
            .copied()
            .map(f32::abs)
            .fold(0.0_f32, f32::max);
        // tolerance per 13-reduction.md §6.3: 4·ε·n·max_abs_input
        4.0 * f32::EPSILON * (n as f32) * max_abs_input
    }

    fn assert_within_tolerance_f64(actual: f64, expected: f64, tol: f64) {
        if expected.is_nan() || actual.is_nan() {
            assert!(actual.is_nan() && expected.is_nan());
        } else if expected.is_infinite() || actual.is_infinite() {
            assert_eq!(actual, expected);
        } else {
            assert!((actual - expected).abs() <= tol.max(4.0 * f64::MIN_POSITIVE));
        }
    }

    fn assert_within_tolerance_f32(actual: f32, expected: f32, tol: f32) {
        if expected.is_nan() || actual.is_nan() {
            assert!(actual.is_nan() && expected.is_nan());
        } else if expected.is_infinite() || actual.is_infinite() {
            assert_eq!(actual, expected);
        } else {
            assert!((actual - expected).abs() <= tol.max(4.0 * f32::MIN_POSITIVE));
        }
    }

    fn data_f64(len: usize) -> Vec<f64> {
        (0..len).map(|i| ((i as f64) * 0.25).sin()).collect()
    }

    fn data_f32(len: usize) -> Vec<f32> {
        (0..len).map(|i| ((i as f32) * 0.25).sin()).collect()
    }

    #[test]
    fn test_simd_vector_semantics_reduction_dot() {
        test_sum_tolerance_f64_within_documented_bounds();
        test_dot_tolerance_f64_within_documented_bounds();
        test_complex_dot_tolerance_real_imag_components();
        test_sum_dispatch_simd_int_admission();
        test_dot_dispatch_simd_int_admission();
    }

    #[test]
    fn test_entry_threshold_boundary() {
        let below = vec![1.0_f64; 1023];
        assert!(try_sum_f64(&below).is_none());

        let at_threshold = vec![1.0_f64; 1024];
        let simd = try_sum_f64(&at_threshold).expect("len=1024 must enter f64 sum SIMD when feature=simd");
        assert_within_tolerance_f64(simd, 1024.0, tolerance_f64(&at_threshold));
    }

    #[test]
    fn test_isa_gating_fallback() {
        // With feature="simd" disabled, this module is not compiled and
        // try_* SIMD facade functions are unavailable. That cfg behavior is
        // validated by `cargo test` without `--features simd`.
        assert!(cfg!(feature = "simd"));
    }

    #[test]
    fn test_admission_platform_rejection() {
        // On platforms without the required widening ISA, integer admission
        // returns None instead of emulating a SIMD result with weaker checked
        // semantics. The i32 facade narrows its i64 accumulator back to i32;
        // the scalar baseline mirrors that narrowing.
        let data: Vec<i32> = (0..512).collect();
        if let Some(simd) = try_sum_i32(&data) {
            let scalar_i64: i64 = data.iter().map(|&value| value as i64).sum();
            let scalar_i32 = i32::try_from(scalar_i64).expect("test fixture stays within i32 range");
            assert_eq!(simd, scalar_i32);
        }
    }

    #[test]
    fn test_sum_tolerance_f64_within_documented_bounds() {
        let data = data_f64(2048);
        let scalar: f64 = data.iter().sum();
        if let Some(simd) = try_sum_f64(&data) {
            assert_within_tolerance_f64(simd, scalar, tolerance_f64(&data));
        }
    }

    #[test]
    fn test_sum_tolerance_f32_within_documented_bounds() {
        let data = data_f32(2048);
        let scalar: f32 = data.iter().sum();
        if let Some(simd) = try_sum_f32(&data) {
            assert_within_tolerance_f32(simd, scalar, tolerance_f32(&data));
        }
    }

    #[test]
    fn test_dot_tolerance_f64_within_documented_bounds() {
        let lhs = data_f64(1024);
        let rhs: Vec<f64> = data_f64(1024).into_iter().map(|value| value * -0.5).collect();
        let scalar: f64 = lhs.iter().zip(rhs.iter()).map(|(&lhs, &rhs)| lhs * rhs).sum();
        if let Some(simd) = try_dot_f64(&lhs, &rhs) {
            let max_abs_input = lhs.iter()
                .zip(rhs.iter())
                .map(|(&lhs, &rhs)| (lhs * rhs).abs())
                .fold(0.0_f64, f64::max);
            // tolerance per 13-reduction.md §6.3: 4·ε·n·max_abs_input
            let tol = 4.0 * f64::EPSILON * (lhs.len() as f64) * max_abs_input;
            assert_within_tolerance_f64(simd, scalar, tol);
        }
    }

    #[test]
    fn test_dot_tolerance_f32_within_documented_bounds() {
        let lhs = data_f32(1024);
        let rhs: Vec<f32> = data_f32(1024).into_iter().map(|value| value * -0.5).collect();
        let scalar: f32 = lhs.iter().zip(rhs.iter()).map(|(&lhs, &rhs)| lhs * rhs).sum();
        if let Some(simd) = try_dot_f32(&lhs, &rhs) {
            let max_abs_input = lhs.iter()
                .zip(rhs.iter())
                .map(|(&lhs, &rhs)| (lhs * rhs).abs())
                .fold(0.0_f32, f32::max);
            // tolerance per 13-reduction.md §6.3: 4·ε·n·max_abs_input
            let tol = 4.0 * f32::EPSILON * (lhs.len() as f32) * max_abs_input;
            assert_within_tolerance_f32(simd, scalar, tol);
        }
    }

    #[test]
    fn test_complex_sum_tolerance_real_imag_components() {
        let data: Vec<Complex<f64>> = (0..2048)
            .map(|i| Complex::new((i as f64).sin(), (i as f64 * 0.5).cos()))
            .collect();
        let scalar: Complex<f64> = data.iter().copied().sum();
        if let Some(simd) = try_sum_complex_f64(&data) {
            let real: Vec<f64> = data.iter().map(|value| value.re).collect();
            let imag: Vec<f64> = data.iter().map(|value| value.im).collect();
            assert_within_tolerance_f64(simd.re, scalar.re, tolerance_f64(&real));
            assert_within_tolerance_f64(simd.im, scalar.im, tolerance_f64(&imag));
        }
    }

    #[test]
    fn test_complex_sum_tolerance_f32_real_imag_components() {
        let data: Vec<Complex<f32>> = (0..2048)
            .map(|i| Complex::new((i as f32).sin(), (i as f32 * 0.5).cos()))
            .collect();
        let scalar: Complex<f32> = data.iter().copied().sum();
        if let Some(simd) = try_sum_complex_f32(&data) {
            let real: Vec<f32> = data.iter().map(|value| value.re).collect();
            let imag: Vec<f32> = data.iter().map(|value| value.im).collect();
            assert_within_tolerance_f32(simd.re, scalar.re, tolerance_f32(&real));
            assert_within_tolerance_f32(simd.im, scalar.im, tolerance_f32(&imag));
        }
    }

    #[test]
    fn test_complex_dot_tolerance_real_imag_components() {
        let lhs: Vec<Complex<f64>> = (0..1024)
            .map(|i| Complex::new(i as f64 * 0.25, i as f64 * -0.5))
            .collect();
        let rhs: Vec<Complex<f64>> = (0..1024)
            .map(|i| Complex::new((i as f64).cos(), (i as f64).sin()))
            .collect();
        let products: Vec<Complex<f64>> = lhs.iter()
            .zip(rhs.iter())
            .map(|(lhs, rhs)| lhs.conj() * *rhs)
            .collect();
        let scalar: Complex<f64> = products.iter().copied().sum();
        if let Some(simd) = try_dot_complex_f64(&lhs, &rhs) {
            let real: Vec<f64> = products.iter().map(|value| value.re).collect();
            let imag: Vec<f64> = products.iter().map(|value| value.im).collect();
            assert_within_tolerance_f64(simd.re, scalar.re, tolerance_f64(&real));
            assert_within_tolerance_f64(simd.im, scalar.im, tolerance_f64(&imag));
        }
    }

    #[test]
    fn test_complex_dot_tolerance_f32_real_imag_components() {
        let lhs: Vec<Complex<f32>> = (0..1024)
            .map(|i| Complex::new(i as f32 * 0.25, i as f32 * -0.5))
            .collect();
        let rhs: Vec<Complex<f32>> = (0..1024)
            .map(|i| Complex::new((i as f32).cos(), (i as f32).sin()))
            .collect();
        let products: Vec<Complex<f32>> = lhs.iter()
            .zip(rhs.iter())
            .map(|(lhs, rhs)| lhs.conj() * *rhs)
            .collect();
        let scalar: Complex<f32> = products.iter().copied().sum();
        if let Some(simd) = try_dot_complex_f32(&lhs, &rhs) {
            let real: Vec<f32> = products.iter().map(|value| value.re).collect();
            let imag: Vec<f32> = products.iter().map(|value| value.im).collect();
            assert_within_tolerance_f32(simd.re, scalar.re, tolerance_f32(&real));
            assert_within_tolerance_f32(simd.im, scalar.im, tolerance_f32(&imag));
        }
    }

    #[test]
    fn test_sum_dispatch_simd_int_admission() {
        // i32 SIMD facade narrows i64 accumulator back to i32 via checked narrowing.
        // i64 sum/dot has no SIMD facade (see 08-simd §6.6 and W14T7); callers stay
        // on the scalar `checked_add` path. There is no try_sum_i64 symbol to test.
        let data: Vec<i32> = (0..1024).collect();
        if let Some(simd) = try_sum_i32(&data) {
            let scalar_i64: i64 = data.iter().map(|&value| value as i64).sum();
            let scalar_i32 = i32::try_from(scalar_i64).expect("test fixture stays within i32 range");
            assert_eq!(simd, scalar_i32);
        }
    }

    #[test]
    fn test_dot_dispatch_simd_int_admission() {
        // i32 SIMD facade narrows i64 accumulator back to i32 via checked narrowing.
        // i64 sum/dot has no SIMD facade; there is no try_dot_i64 symbol to test.
        let lhs: Vec<i32> = (0..512).collect();
        let rhs: Vec<i32> = (0..512).map(|value| value - 128).collect();
        if let Some(simd) = try_dot_i32(&lhs, &rhs) {
            let scalar_i64: i64 = lhs.iter()
                .zip(rhs.iter())
                .map(|(&lhs, &rhs)| (lhs as i64) * (rhs as i64))
                .sum();
            let scalar_i32 = i32::try_from(scalar_i64).expect("test fixture stays within i32 range");
            assert_eq!(simd, scalar_i32);
        }
    }

    #[test]
    fn test_sum_nan_propagation() {
        let mut data = vec![1.0_f64; 2048];
        data[1024] = f64::NAN;
        if let Some(simd) = try_sum_f64(&data) {
            assert!(simd.is_nan());
        }
    }

    #[test]
    fn test_sum_inf_sign_consistency() {
        let mut positive = vec![1.0_f64; 2048];
        positive[7] = f64::INFINITY;
        if let Some(simd) = try_sum_f64(&positive) {
            assert_eq!(simd, f64::INFINITY);
        }

        let mut negative = vec![-1.0_f64; 2048];
        negative[7] = f64::NEG_INFINITY;
        if let Some(simd) = try_sum_f64(&negative) {
            assert_eq!(simd, f64::NEG_INFINITY);
        }
    }

    #[test]
    fn test_sum_positive_negative_cancel() {
        let mut data = vec![1.0_f64; 2048];
        for value in data.iter_mut().take(8) {
            *value = -256.0;
        }
        let scalar: f64 = data.iter().sum();
        if let Some(simd) = try_sum_f64(&data) {
            assert_within_tolerance_f64(simd, scalar, tolerance_f64(&data));
        }
    }

    #[test]
    fn test_boundary_length_values() {
        for len in [SIMD_WIDTH, SIMD_WIDTH + 1] {
            let data = data_f64(len);
            if let Some(simd) = try_sum_f64(&data) {
                let scalar: f64 = data.iter().sum();
                assert_within_tolerance_f64(simd, scalar, tolerance_f64(&data));
            }
        }
    }
}
```

| 决策 | 依据 |

| Complex 比较必须按 real/imag 分量分别断言 | 08-simd §6.6 和测试决策要求复数 sum/dot 分量级 tolerance，禁止用 `.norm()` 掩盖分量误差 |

## 注意事项

- SIMD module does not own scalar fallback loops; callers keep the serial baseline.
- All SIMD entries are internal `pub(crate)` APIs and must stay feature-gated.
- Unsafe code requires explicit length, tail, and alignment proof before vector load/store.
- **FMA 使用规则**（08-simd §1.2/§6.6）：element-wise 与 dot per-element 主循环禁用 FMA（保持与标量逐位一致）；仅 horizontal reduction merge 阶段可在记录容差且 FMA capability bit 独立检测确认后使用。pulp 0.18 的 FMA capability 通过 spike（W14T0）确认。
- `test_isa_gating_fallback` 通过 cfg 注释说明无 `feature = "simd"` 时 `try_*` facade 不编译进入测试模块；实际默认 feature 编译由 `cargo test` 覆盖。
- 所有代码注释和 Rust 标识符使用英文，文档说明保持当前实施方案风格。
- 不添加新的第三方依赖，除非设计文档已在 Cargo feature 中声明。
