## 关键设计决策

| 决策 | 依据 |
|------|------|
| 存储能力通过 trait 层次表达 | `05-storage §5.2` 定义 `RawStorage -> Storage -> StorageMut -> StorageOwned` |
| Owned 使用内部对齐缓冲而非裸 Vec | `05-storage §6.2` 要求 64 字节对齐并避免错误 dealloc 布局 |
| `ArcRepr` 公开只读 | `05-storage §5.1` 与 §6.7 明确共享可写不属于 storage 公共 API |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test storage`
4. 手动验证: 构造 `Owned -> ViewRepr -> ArcRepr` 的最小路径，检查内容、长度和对齐查询。

## 注意事项

- ZST 与空数组不能触发未定义行为，也不能错误调用 dealloc。
- `ViewMutRepr` 不允许实现 `Clone` 或 `Copy`。
- 上述 `pub use` 是 staged re-export 前置声明；对应子模块占位文件必须先声明最小占位类型/trait，后续 W7T6/W7T8/W7T14-W7T18 会填充正式实现并最终整理导出。
- `tests/test_storage.rs` 明确禁止新增；集成覆盖应放入现有 tensor/index/ffi/iterator 测试文件或模块内测试。
