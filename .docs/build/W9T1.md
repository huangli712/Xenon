## 目标

为 W9T4 / W9T5 / W9T6 提供结构化的 `XenonError::Workspace` 构造辅助函数，保证错误诊断信息（operation 名、borrow conflict 上下文、增长溢出参数）不丢失。
本任务在 SUMMARY.md 中的目标是 "WorkspaceErrorCategory wired into XenonError::Workspace"，如上文说明：WorkspaceErrorCategory 本身已由 W2T1 提供，本任务负责 "wired into XenonError::Workspace" 的部分 —— 在 `impl XenonError` 上添加 3 个构造辅助函数。

## 实施步骤

### Step 1: 实现核心代码

在 `src/error.rs` 中追加为 W9T4 / W9T5 / W9T6 服务的 `XenonError::Workspace` 构造辅助函数。

全部辅助枚举（`WorkspaceErrorCategory` / `WorkspaceBorrowKind` / `WorkspaceBorrowState` / `TypedViewRejection`）**已由 W2T1 在 `src/error.rs` 定义**（与 `26-error.md §306-360` 逐字对齐）。本任务 **不重复定义**这些枚举，仅依赖 W2T1 提供的类型增加 `impl XenonError` 构造辅助函数。

```rust
// 前置：W2T1 已在本文件（src/error.rs）定义 WorkspaceErrorCategory /
// WorkspaceBorrowKind / WorkspaceBorrowState / TypedViewRejection。
// 同文件内直接可见，无需 use 导入。

// --- XenonError::Workspace constructor helpers (used by W9T4, W9T5, W9T6) ---
//
// Each helper preserves the `operation` field and accepts structured
// borrow / overflow context so callers (the borrow/split/expand modules)
// never lose diagnostic fidelity. The `operation` string is `&'static str`
// to remain `Cow::Borrowed`-friendly with no allocation.

impl XenonError {
    pub fn workspace_split_oob(
        operation: &'static str,
        mid: usize,
        len: usize,
    ) -> Self {
        XenonError::Workspace {
            operation: alloc::borrow::Cow::Borrowed(operation),
            category: WorkspaceErrorCategory::SplitOutOfBounds { mid, len },
            cause: None,
        }
    }

    pub fn workspace_borrow_conflict(
        operation: &'static str,
        requested: WorkspaceBorrowKind,
        current: WorkspaceBorrowState,
    ) -> Self {
        XenonError::Workspace {
            operation: alloc::borrow::Cow::Borrowed(operation),
            category: WorkspaceErrorCategory::BorrowConflict { requested, current },
            cause: None,
        }
    }

    pub fn workspace_grow_overflow(
        operation: &'static str,
        current_capacity: usize,
        additional: usize,
    ) -> Self {
        XenonError::Workspace {
            operation: alloc::borrow::Cow::Borrowed(operation),
            category: WorkspaceErrorCategory::GrowOverflow {
                current_capacity,
                additional,
            },
            cause: None,
        }
    }
}
```

测试依据: `test_workspace_workspace_error_category`（24-workspace.md §8.2）验证所有 7 个 `WorkspaceErrorCategory` 变体（含 `SplitCountInvariant` / `TypedViewRejected`）和 3 个构造函数 helper 均可诊断；`test_typed_view_rejection_variants` 覆盖 `TypedViewRejection` 的 3 个变体。

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_workspace_workspace_error_category() {
        // InvalidLayout
        let cat = WorkspaceErrorCategory::InvalidLayout { size: 0, align: 3 };
        assert!(format!("{cat:?}").contains("InvalidLayout"));

        // AllocFailed
        let cat = WorkspaceErrorCategory::AllocFailed { size: 1024, align: 64 };
        assert!(format!("{cat:?}").contains("AllocFailed"));

        // BorrowConflict — note `current` uses the official `SplitActive { count }` variant.
        let cat = WorkspaceErrorCategory::BorrowConflict {
            requested: WorkspaceBorrowKind::Exclusive,
            current: WorkspaceBorrowState::SplitActive { count: 2 },
        };
        assert!(format!("{cat:?}").contains("BorrowConflict"));
        assert!(format!("{cat:?}").contains("SplitActive"));

        // SplitOutOfBounds — field name MUST be `mid` (not `split_at`).
        let cat = WorkspaceErrorCategory::SplitOutOfBounds { mid: 42, len: 10 };
        assert!(format!("{cat:?}").contains("SplitOutOfBounds"));
        assert!(format!("{cat:?}").contains("mid: 42"));

        // SplitCountInvariant
        let cat = WorkspaceErrorCategory::SplitCountInvariant {
            detail: alloc::borrow::Cow::Borrowed("underflow"),
        };
        assert!(format!("{cat:?}").contains("SplitCountInvariant"));

        // GrowOverflow — field names MUST be `current_capacity` and `additional`.
        let cat = WorkspaceErrorCategory::GrowOverflow {
            current_capacity: usize::MAX,
            additional: 1,
        };
        assert!(format!("{cat:?}").contains("GrowOverflow"));
        assert!(format!("{cat:?}").contains("current_capacity"));
        assert!(format!("{cat:?}").contains("additional"));

        // TypedViewRejected
        let cat = WorkspaceErrorCategory::TypedViewRejected {
            detail: TypedViewRejection::ZeroSizedType,
        };
        assert!(format!("{cat:?}").contains("TypedViewRejected"));
    }

    #[test]
    fn test_typed_view_rejection_variants() {
        let r = TypedViewRejection::ZeroSizedType;
        assert!(format!("{r:?}").contains("ZeroSizedType"));

        let r = TypedViewRejection::AlignmentMismatch { required: 8, actual: 1 };
        assert!(format!("{r:?}").contains("AlignmentMismatch"));

        let r = TypedViewRejection::TypedByteLengthOverflow { count: usize::MAX, elem_size: 4 };
        assert!(format!("{r:?}").contains("TypedByteLengthOverflow"));
    }

    #[test]
    fn test_workspace_constructor_helpers() {
        // split_oob carries `operation`, `mid`, `len`.
        let err = XenonError::workspace_split_oob("Workspace::split_at_mut", 10, 5);
        let s = format!("{err:?}");
        assert!(s.contains("Workspace::split_at_mut"));
        assert!(s.contains("SplitOutOfBounds"));
        assert!(s.contains("mid: 10"));

        // borrow_conflict carries `operation`, `requested`, `current`.
        let err = XenonError::workspace_borrow_conflict(
            "Workspace::borrow",
            WorkspaceBorrowKind::Shared,
            WorkspaceBorrowState::Exclusive,
        );
        let s = format!("{err:?}");
        assert!(s.contains("Workspace::borrow"));
        assert!(s.contains("BorrowConflict"));
        assert!(s.contains("Shared"));
        assert!(s.contains("Exclusive"));

        // grow_overflow carries `operation`, `current_capacity`, `additional`.
        let err = XenonError::workspace_grow_overflow(
            "Workspace::ensure_capacity",
            usize::MAX,
            1,
        );
        let s = format!("{err:?}");
        assert!(s.contains("Workspace::ensure_capacity"));
        assert!(s.contains("GrowOverflow"));
        assert!(s.contains("current_capacity"));
        assert!(s.contains("additional"));
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `WorkspaceErrorCategory` 为 closed enum + `#[non_exhaustive]` | `26-error.md §304` 允许未来扩展不破坏匹配穷尽性 |
| 7 个变体（含 `SplitCountInvariant` / `TypedViewRejected`） | `26-error.md §306-334` 完整变体集 |
| `WorkspaceBorrowState::SplitActive { count }` 携带计数 | `26-error.md §343-349`，供 `current_borrow_state` helper 报告 |
| `TypedViewRejection` 独立枚举 + `#[non_exhaustive]` | `26-error.md §351-360`；typed view 拒绝原因封闭集 |
| 构造 helper 强制传入 `operation: &'static str` | 保留 `XenonError::Workspace.operation` 诊断字段，避免下游 helper 占位丢失 |
| `GrowOverflow` 字段为 `current_capacity` / `additional` | `26-error.md §329` 字段名约束 |
| `SplitOutOfBounds` 字段为 `mid` 而非 `split_at` | `26-error.md §317`、`24-workspace.md §808` |

## 注意事项

- 本任务只在 `src/error.rs` 中新增类型与 helper，不修改 `XenonError::Workspace` 枚举本身（W2T2 已定义其 `{ operation, category, cause }` 形状）。
- 所有 helper 必须保留 `operation` 字段，禁止使用空字符串或默认占位符。
- `WorkspaceErrorCategory` 与 `TypedViewRejection` 必须保持 `#[non_exhaustive]`，下游 `match` 必须含 `_ => ..` 分支。
- 借用期间不得重新分配或扩容（运行时不变量，由 W9T5/W9T6 强制）。
- typed view 只能在 Element 闭集内使用，并由调用方证明初始化（由 W9T4 实施）。
- Workspace 和所有 guard 保持 `!Send + !Sync`（由 W9T3 PhantomData 强制）。
