## 实施步骤

### Step 1: 定义 Ix4 结构体

在 `src/dimension/static.rs` 中新增四维静态维度类型。Ix4 持有四个公开 `usize` 字段，并使用 `#[repr(C)]` 支持后续切片视图。derive 集合与设计 §5.2 一致：`Clone, Copy, Debug, PartialEq, Eq, Hash, Default`。

```rust
#[repr(C)]
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Default)]
pub struct Ix4(pub usize, pub usize, pub usize, pub usize);
```

### Step 2: 实现 Dimension for Ix4

为 Ix4 实现 `Dimension`。四维 shape 的 rank 固定为 4，`slice()` 暴露 4 个轴，`checked_size()` 使用循环跟踪溢出轴。依据 `02-dimension.md` §5.1，`into_dyn` 与 `try_from_dyn` 不作为 trait 方法实现，留给 W3T12 作为 inherent 方法添加。`axis()` 使用 trait 默认实现，无需手动重写。

```rust
use std::borrow::Cow;
use crate::error::{InvalidShapeKind, XenonError};
use crate::dimension::Dimension;

impl Dimension for Ix4 {
    const NDIM: Option<usize> = Some(4);

    #[inline]
    fn ndim(&self) -> usize { 4 }

    #[inline]
    fn slice(&self) -> &[usize] {
        unsafe { std::slice::from_raw_parts(&self.0 as *const usize, 4) }
    }

    #[inline]
    fn checked_size(&self) -> Result<usize, XenonError> {
        let mut size = 1usize;
        let axes = [self.0, self.1, self.2, self.3];
        for (i, &ax) in axes.iter().enumerate() {
            size = size.checked_mul(ax).ok_or_else(|| XenonError::InvalidShape {
                operation: Cow::Borrowed("Dimension::checked_size"),
                shape: axes.to_vec(),
                kind: InvalidShapeKind::ProductOverflow,
                offending_dim: Some(i),
            })?;
        }
        Ok(size)
    }

    #[inline]
    fn checked(&self) -> Result<(), XenonError> {
        let _ = self.checked_size()?;
        Ok(())
    }

    #[inline]
    fn try_from_slice(slice: &[usize]) -> Result<Self, XenonError> {
        if slice.len() == 4 {
            Ok(Ix4(slice[0], slice[1], slice[2], slice[3]))
        } else {
            Err(XenonError::DimensionMismatch {
                operation: Cow::Borrowed("Ix4::try_from_slice"),
                expected: 4,
                actual: slice.len(),
            })
        }
    }

    // `axis()` uses the trait default implementation; out-of-range returns
    // `XenonError::InvalidAxis` automatically.
}
```

### Step 3: 实现 From<(usize, usize, usize, usize)> for Ix4

为 Ix4 显式实现四元素元组转换，保证构造时元组长度由 Rust 类型系统检查。

```rust
impl From<(usize, usize, usize, usize)> for Ix4 {
    fn from(t: (usize, usize, usize, usize)) -> Self {
        Ix4(t.0, t.1, t.2, t.3)
    }
}
```

## 关键设计决策

1. 依据 `02-dimension.md` §5.2，Ix4 使用 `#[repr(C)]` 保证四个 `usize` 字段连续排列，这是 `slice()` 通过指针 reinterpret 构造切片的安全前提。
2. 依据 `02-dimension.md` §5.1，`into_dyn` / `try_from_dyn` **不**是 trait 方法；本 task 不实现它们，留给 W3T12 集中作为 inherent 方法添加。
3. 依据 `02-dimension.md` §5.4，`checked_size()` 使用循环遍历四轴并跟踪 `offending_dim`，在溢出时提供精确的错误定位。
4. 公开导出由 W3T15 集中处理，本 task **不**修改 `src/dimension/mod.rs`。

## 注意事项

- `slice()` 返回的切片长度必须等于 `ndim` 返回的维度数（Ix4 → len=4）。
- `From<tuple>` 元组中所有元素均为 `usize`，不接受其他类型。
- `repr(C)` 是 unsafe 切片构造的前提——不可移除。
- 不要在本 task 实现 `into_dyn` / `try_from_dyn`；留给 W3T12。
- 不要在本 task 修改 `src/dimension/mod.rs`；公开导出由 W3T15 集中处理。
