## 实施步骤

### Step 1: Implement value accessors

Add by-value accessors in the existing `impl<T: ComplexFloat> Complex<T>` block. Returning `T` is correct because `ComplexFloat` requires `Copy`.

```rust
impl<T: ComplexFloat> Complex<T> {
    #[inline]
    pub fn re(self) -> T {
        self.re
    }

    #[inline]
    pub fn im(self) -> T {
        self.im
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 只支持 `Complex<f32>` 与 `Complex<f64>` | `04-complex §5.2` 使用 sealed `ComplexFloat` 封闭实现范围 |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test --lib complex::tests::test_complex_accessors`
4. 手动验证: 构造 `Complex::new(3.0, 4.0)`，调用 `.re()` / `.im()`，验证返回值分别为 3.0 和 4.0。

## 注意事项

- 不实现跨精度运算，也不实现 `Complex<T> op T` 便捷运算符。
- `NaN != NaN` 由底层浮点 `PartialEq` 自然保证，不要实现 `Eq`。
- FFI 布局测试必须覆盖 size、align 和字段偏移意图。
