### Step 2: add 一致性（§5.20 高优，Tier 1 精确）

```rust
#[test]
fn test_simd_add_consistency() {
    // add 是路径无关运算 → Tier 1 精确（ulp_eq_f64_exact）
    let n = 1024;
    let a = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| i as f64).collect()).unwrap();
    let b = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| (i * 2) as f64).collect()).unwrap();
    let simd_result = (&a + &b).unwrap();

    // 显式标量 baseline
    let scalar: Vec<f64> = a.iter().zip(b.iter()).map(|(x, y)| x + y).collect();
    let baseline = Tensor1::<f64>::from_shape_vec([n], scalar).unwrap();
    assert_tensor_exact_real(&simd_result, &baseline, "SIMD add vs scalar baseline");
}
```

### Step 3: sum / dot 一致性（§5.20 高优，Tier 2 跨路径容差）

```rust
#[test]
fn test_simd_sum_consistency() {
    let n = 1024;
    let t = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| i as f64).collect()).unwrap();
    // 13-reduction.md §5.1 L120：sum() -> A 标量。
    let simd_sum: f64 = t.sum();
    let scalar: f64 = t.iter().copied().sum();
    // 实证 W29T1 L140/L161：cross_path_sum(n) 需 n；ulp_eq_f64_with_tolerance 取 MathTolerance。
    let tol = MathTolerance::cross_path_sum(n);
    assert!(
        ulp_eq_f64_with_tolerance(simd_sum, scalar, tol),
        "SIMD sum vs scalar baseline: simd={simd_sum}, scalar={scalar}, ulp={}", tol.ulp
    );
}

#[test]
fn test_simd_dot_consistency() {
    let n = 512;
    let a = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| (i + 1) as f64).collect()).unwrap();
    let b = Tensor1::<f64>::from_shape_vec([n], (0..n).map(|i| ((i % 7) + 1) as f64).collect()).unwrap();
    // 12-matrix.md §5.1 L171：dot() -> Result<A, _>。
    let simd_dot: f64 = a.dot(&b).unwrap();
    let scalar: f64 = a.iter().zip(b.iter()).map(|(x, y)| x * y).sum();
    let tol = MathTolerance::cross_path_dot(n);
    assert!(
        ulp_eq_f64_with_tolerance(simd_dot, scalar, tol),
        "SIMD dot vs scalar baseline: simd={simd_dot}, scalar={scalar}, ulp={}", tol.ulp
    );
}
```

### Step 4: fallback（§5.20 中优，必须验证 fallback 语义）

```rust
#[test]
fn test_simd_fallback_small() {
    // 长度小于 SIMD 阈值（典型阈值 ≥ 8 个元素）的张量必须回退到标量路径，
    // 结果与显式标量 baseline 逐位一致（fallback 语义意味着走的就是标量代码）。
    let small = Tensor1::<f64>::from_shape_vec([3], vec![1.0, 2.0, 3.0]).unwrap();
    let other = Tensor1::<f64>::from_shape_vec([3], vec![10.0, 20.0, 30.0]).unwrap();

    let simd_path = (&small + &other).unwrap();
    let scalar: Vec<f64> = small.iter().zip(other.iter()).map(|(x, y)| x + y).collect();
    let baseline = Tensor1::<f64>::from_shape_vec([3], scalar).unwrap();
    // fallback 走标量 → ULP==0
    assert_tensor_exact_real(&simd_path, &baseline, "SIMD fallback for small input must match scalar");
}
```

### Step 5: complex path（§5.20 中优）

```rust
#[test]
fn test_simd_complex_path() {
    use xenon::Complex;
    let n = 256;
    let a = Tensor1::<Complex<f64>>::from_shape_vec(
        [n], (0..n).map(|i| Complex::new(i as f64, (i + 1) as f64)).collect()
    ).unwrap();
    let b = Tensor1::<Complex<f64>>::from_shape_vec(
        [n], (0..n).map(|i| Complex::new((i * 2) as f64, (i + 3) as f64)).collect()
    ).unwrap();
    let simd_result = (&a + &b).unwrap();

    // 显式标量 baseline
    let scalar: Vec<Complex<f64>> = a.iter().zip(b.iter()).map(|(x, y)| *x + *y).collect();
    let baseline = Tensor1::<Complex<f64>>::from_shape_vec([n], scalar).unwrap();

    // 复数 add 也是路径无关；逐元素 ULP==0
    for i in 0..n {
        let s = simd_result.try_at(&[i]).unwrap();
        let r = baseline.try_at(&[i]).unwrap();
        assert!(ulp_eq_f64_exact(s.re, r.re) && ulp_eq_f64_exact(s.im, r.im),
            "SIMD complex add mismatch at {i}: {s:?} vs {r:?}");
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| add Tier 1 精确（`assert_tensor_exact_real`） | 28-tests §6.3.3 L987 说明 add 路径无关 |
| sum / dot 跨路径 Tier 2（`MathTolerance::cross_path_sum/dot`） | §6.2 Tier 2 文档化容差 |
| `test_simd_fallback_small` 比对 SIMD-enabled build 下的小张量与显式标量 baseline | §5.20 L659「小数组 SIMD 回退到标量」 |
| 复数路径 add 仍按路径无关处理，逐分量 ULP==0 | §6.3.3 / 04-complex.md |
| 测试整体 `#![cfg(feature = "simd")]` | §7-T20 / §8.3 |
