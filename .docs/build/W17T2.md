| 预估工时 | 10 min |

## 目标

将 W17T1 的 `Ok(A::zero())` 桩替换为**带完整前置校验的 dot 实现**：
1. `a.ndim() != 1` → `XenonError::InvalidArgument { operation, kind: OperationSpecific { argument: "a", constraint: "rank == 1" } }`
2. `b.ndim() != 1` → 同上 `argument: "b"`
3. `a.len() != b.len()` → `XenonError::ShapeMismatch { operation, left_shape, right_shape }`
4. 校验通过后**暂时仍返回 `Ok(A::zero())`**——真实标量内积由 W17T3 通过 `DotAccumulate` trait 替换。

校验路径在本 task 完成后必须能被 W17T7 集成测试中的 `test_dot_shape_mismatch` 与 `test_dot_high_rank_invalid_argument` 全程复用。

- 在修改前运行 `cargo check` 与 `cargo test matrix::dot::tests` 获取基线。

## 实施步骤

### Step 1: 引入 error 模块依赖

在 `src/matrix/dot.rs` 文件头 use 列表中追加 error 类型引用。保留 W17T1 已有的 use 声明，仅新增 `XenonError::ShapeMismatch` 与 `InvalidArgumentKind` 所需的导入。

```rust
use std::borrow::Cow;

use crate::dimension::Dimension;
use crate::element::Numeric;
use crate::error::{InvalidArgumentKind, XenonError};
use crate::storage::Storage;
use crate::tensor::TensorBase;
```

### Step 2: 引入 `validate_dot_inputs` 私有 helper

helper 集中执行 §6.1 step 1-3 校验，错误字段严格使用 26-error §5.1 的封闭枚举形式；`operation` 与 `argument` / `constraint` 使用 `Cow::Borrowed` 持有 `&'static str` 字面量，避免不必要的堆分配。

```rust
/// Validate the dot product preconditions per 12-matrix §6.1 step 1-3.
///
/// Returns:
///   * `Err(InvalidArgument)` if either input is not logically 1-D.
///   * `Err(ShapeMismatch)` if both are 1-D but their lengths differ.
///   * `Ok(())` otherwise.
fn validate_dot_inputs<S1, S2, A, D1, D2>(
    a: &TensorBase<S1, D1>,
    b: &TensorBase<S2, D2>,
) -> Result<(), XenonError>
where
    S1: Storage<Elem = A>,
    S2: Storage<Elem = A>,
    D1: Dimension,
    D2: Dimension,
{
    if a.ndim() != 1 {
        return Err(invalid_rank("a"));
    }
    if b.ndim() != 1 {
        return Err(invalid_rank("b"));
    }
    if a.len() != b.len() {
        return Err(XenonError::ShapeMismatch {
            operation: Cow::Borrowed("dot"),
            left_shape: a.shape().to_vec(),
            right_shape: b.shape().to_vec(),
        });
    }
    Ok(())
}

/// Build the canonical `InvalidArgument` error for non-1-D dot inputs.
///
/// Per 26-error §5.1 the `kind` field uses `OperationSpecific` because
/// "must be rank == 1" is an operation-specific constraint, not a
/// shared generic argument kind.
fn invalid_rank(argument: &'static str) -> XenonError {
    XenonError::InvalidArgument {
        operation: Cow::Borrowed("dot"),
        kind: InvalidArgumentKind::OperationSpecific {
            argument: Cow::Borrowed(argument),
            constraint: Cow::Borrowed("rank == 1"),
        },
    }
}
```

### Step 3: 在 `dot()` 中接入校验

替换 W17T1 桩函数体——保留 `Ok(A::zero())` 作为校验通过后的临时返回值（W17T3 替换为真实标量内积）。

```rust
pub fn dot<S1, S2, A, D1, D2>(
    a: &TensorBase<S1, D1>,
    b: &TensorBase<S2, D2>,
) -> Result<A, XenonError>
where
    S1: Storage<Elem = A>,
    S2: Storage<Elem = A>,
    A: Numeric,
    D1: Dimension,
    D2: Dimension,
{
    validate_dot_inputs(a, b)?;

    // W17T2 boundary: validated path returns the additive identity as a
    // temporary placeholder. W17T3 replaces this with the per-type
    // `DotAccumulate` scalar inner product. Signature is final.
    Ok(A::zero())
}
```

### Step 4: 单元测试

按 12-matrix §8.2 line 463、§8.2 line 474 添加校验路径测试。本 task 不验证数值正确性（W17T3 起接管）；本 task 仅验证错误分支。

`test_dot_high_rank_invalid_argument` 使用 `Tensor::<i32, Ix2>::from_shape_vec((1, 1), vec![1])`——构造 2-D 张量，避免依赖 W8 之后的 `Tensor::zeros()` 是否已对外暴露。

**实施提示**：以下 `mod tests` 块**与 W17T1 共享同一个 `#[cfg(test)] mod tests { ... }` 声明**。同文件多个 `mod tests` 声明会编译失败（"the name `tests` is defined multiple times"）。本 task 的实际实施动作是：合并 W17T1/W17T2 的 use 列表（追加 `Ix2` + `Tensor`，最终为 `use crate::{Ix1, Ix2, Tensor, Tensor1};`），并把下方 3 个测试函数追加到 W17T1 已有的 2 个 skeleton 测试之后。

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::{Ix1, Ix2, Tensor, Tensor1};

    #[test]
    fn test_dot_shape_mismatch() {
        let a = Tensor1::from_shape_vec(Ix1(2), vec![1_i32, 2]).unwrap();
        let b = Tensor1::from_shape_vec(Ix1(3), vec![1_i32, 2, 3]).unwrap();
        let err = dot(&a, &b).unwrap_err();
        match err {
            XenonError::ShapeMismatch {
                ref operation,
                ref left_shape,
                ref right_shape,
            } => {
                assert_eq!(operation.as_ref(), "dot");
                assert_eq!(left_shape.as_slice(), &[2]);
                assert_eq!(right_shape.as_slice(), &[3]);
            }
            other => panic!("expected ShapeMismatch, got {other:?}"),
        }
    }

    #[test]
    fn test_dot_high_rank_invalid_argument() {
        let a = Tensor::<i32, Ix2>::from_shape_vec((1, 1), vec![1_i32]).unwrap();
        let b = Tensor1::from_shape_vec(Ix1(1), vec![1_i32]).unwrap();
        let err = dot(&a, &b).unwrap_err();
        match err {
            XenonError::InvalidArgument {
                ref operation,
                kind: InvalidArgumentKind::OperationSpecific {
                    ref argument,
                    ref constraint,
                },
            } => {
                assert_eq!(operation.as_ref(), "dot");
                assert_eq!(argument.as_ref(), "a");
                assert_eq!(constraint.as_ref(), "rank == 1");
            }
            other => panic!("expected InvalidArgument::OperationSpecific, got {other:?}"),
        }
    }

    #[test]
    fn test_dot_rhs_high_rank_invalid_argument() {
        // Symmetric coverage: ensure the rhs branch also fires distinct
        // "b" argument diagnostics rather than masquerading as "a".
        let a = Tensor1::from_shape_vec(Ix1(1), vec![1_i32]).unwrap();
        let b = Tensor::<i32, Ix2>::from_shape_vec((1, 1), vec![1_i32]).unwrap();
        let err = dot(&a, &b).unwrap_err();
        match err {
            XenonError::InvalidArgument {
                kind: InvalidArgumentKind::OperationSpecific { ref argument, .. },
                ..
            } => assert_eq!(argument.as_ref(), "b"),
            other => panic!("expected InvalidArgument::OperationSpecific for b, got {other:?}"),
        }
    }
}
```

## 关键设计决策

- `validate_dot_inputs` 与 `invalid_rank` 在本 task 落地，后续 W17T4-T6 直接复用，避免在每个 ExecPath 分支重复校验逻辑（与 12-matrix §6.1 "Validation happens before dispatch so all paths share identical recoverable errors" 的设计一致）。
- 错误诊断字段全部使用 `Cow::Borrowed` + `&'static str` 字面量，零运行时分配，符合 26-error §5.1 的字段优先选择。
- W17T2 校验通过后仍返回 `Ok(A::zero())`——本 task 显式延迟数值实现到 W17T3，与设计 §7 "Wave 2: 前置校验与标量执行" 的阶段切分一致。
- 不在本 task 添加 `TensorBase::dot` 方法——该方法依赖 W17T3 引入的 `DotAccumulate` sealed trait（`pub` 但通过 `Numeric → Element → Sealed` 链结构化封闭）。
