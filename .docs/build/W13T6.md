## 目标

在 `src/ffi/offset.rs` 中作为 `TensorBase` 的 inherent methods 实现 2 个索引转换 API：

| 方法 | 签名 | 失败语义 |
|---|---|---|
| `try_offset_of` | `&self, index: &[usize] -> Result<usize, XenonError>` | rank 失配 → `DimensionMismatch`；index 越界 → `IndexOutOfBounds`；checked arithmetic 溢出 → `InvalidLayout { reason: AccessRangeExceedsStorage }` |
| `try_ptr_at` | `&self, index: &[usize] -> Result<*const A, XenonError>` | 通过 `try_offset_of` 转发，再用 `as_ptr().add(offset)` 计算 |

**返回的 `offset` 是相对于 `as_ptr()`（逻辑首元素指针）的元素位移**，不再加 `self.offset()`。

### Step 2: `try_offset_of` — 三类错误严格映射

按 `23-ffi.md` §5.13 line 1100-1144 完整复刻。注意 `offset` 从 0 起算（不加 `self.offset()`），因为 `try_ptr_at` 会用 `as_ptr().add(offset)` —— `as_ptr()` 已经吸收了 tensor 的 base offset。

```rust
impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
{
    /// Converts a multi-dimensional index to an element offset relative
    /// to the **logical first element pointer** (`self.as_ptr()`).
    ///
    /// `offset = Σ(stride[i] * index[i])` for all `i` in `[0, ndim)`.
    ///
    /// Both multiplication and accumulation use checked arithmetic, and
    /// any overflow is reported as a recoverable error rather than panic
    /// or wraparound (`23-ffi.md` §6.2).
    ///
    /// # Errors
    ///
    /// | Failure | Variant |
    /// |---------|---------|
    /// | `index.len() != self.ndim()` | `XenonError::DimensionMismatch` |
    /// | `index[i] >= shape[i]` | `XenonError::IndexOutOfBounds` |
    /// | `strides[i] * index[i]` or accumulator overflows `usize` | `XenonError::InvalidLayout { reason: AccessRangeExceedsStorage }` |
    pub fn try_offset_of(&self, index: &[usize]) -> Result<usize, XenonError> {
        if index.len() != self.ndim() {
            return Err(XenonError::DimensionMismatch {
                operation: Cow::Borrowed("ffi::try_offset_of"),
                expected: self.ndim(),
                actual: index.len(),
            });
        }
        let shape = self.shape();
        let strides = self.strides();
        // Build storage_kind tag once: tensor's StorageKind maps 1:1 to
        // StorageKindTag and is needed by every InvalidLayout branch.
        let storage_kind: StorageKindTag = self.storage_kind().into();
        let mut offset: usize = 0;
        for axis in 0..self.ndim() {
            if index[axis] >= shape[axis] {
                return Err(XenonError::IndexOutOfBounds {
                    operation: Cow::Borrowed("ffi::try_offset_of"),
                    attempted_index: index.to_vec(),
                    axis,
                    shape: shape.to_vec(),
                });
            }
            let term =
                strides[axis]
                    .checked_mul(index[axis])
                    .ok_or_else(|| XenonError::InvalidLayout {
                        operation: Cow::Borrowed("ffi::try_offset_of"),
                        storage_kind,
                        shape: shape.to_vec(),
                        strides: strides.to_vec(),
                        offset: self.offset(),
                        storage_len: self.storage_len(),
                        reason: InvalidLayoutReason::AccessRangeExceedsStorage,
                    })?;
            offset = offset.checked_add(term).ok_or_else(|| XenonError::InvalidLayout {
                operation: Cow::Borrowed("ffi::try_offset_of"),
                storage_kind,
                shape: shape.to_vec(),
                strides: strides.to_vec(),
                offset: self.offset(),
                storage_len: self.storage_len(),
                reason: InvalidLayoutReason::AccessRangeExceedsStorage,
            })?;
        }
        Ok(offset)
    }
}
```

> **关键**：返回的 `offset` 是相对 `as_ptr()` 的位移，初始化为 `0`。`as_ptr()` 内部已通过 `self.offset()` 完成 `storage_base + offset` 计算（07-tensor §5.4），所以 `try_ptr_at` 用 `as_ptr().add(offset)` 不会双重计入。

### Step 3: `try_ptr_at` — `as_ptr().add(offset)` 转发

按 `23-ffi.md` §5.13 line 1156-1160 复刻。

```rust
impl<S, D, A> TensorBase<S, D>
where
    S: Storage<Elem = A>,
    D: Dimension,
{
    /// Converts a multi-dimensional index to a raw pointer to the
    /// corresponding element.
    ///
    /// # Safety
    ///
    /// Returns a raw pointer; the caller is responsible for ensuring the
    /// pointer is dereferenced only while `self` remains valid. The
    /// offset is validated to be within the tensor's metadata range
    /// (no zero-stride / no overflow / no out-of-bounds index), but
    /// pointer dereference safety remains the caller's responsibility
    /// at the FFI boundary (`23-ffi.md` §5.13 / §1.2 minimum-constraint
    /// principle).
    pub fn try_ptr_at(&self, index: &[usize]) -> Result<*const A, XenonError> {
        let offset = self.try_offset_of(index)?;
        // SAFETY: `try_offset_of` validates `index < shape` per axis;
        // for a well-constructed tensor the resulting offset always lies
        // within the storage range covered by `as_ptr() ..
        // as_ptr().add(storage_len - self.offset())`.
        Ok(unsafe { self.as_ptr().add(offset) })
    }
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use crate::dimension::{Ix1, Ix2};
    use crate::layout::Strides;
    use crate::tensor::TensorView;

    /// Helper: build a TensorView<Ix2> on top of a Vec via W8T7 `from_raw_parts`.
    /// Returns the (view, vec) pair; the Vec owner must outlive the view.
    fn make_view_ix2<'a>(data: &'a [i32], shape: [usize; 2], strides: [usize; 2]) -> TensorView<'a, i32, Ix2> {
        // SAFETY: shape/strides describe an F-order layout fully within data.len().
        unsafe {
            TensorView::<'a, i32, Ix2>::from_raw_parts(
                data.as_ptr(),
                data.len(),
                Ix2(shape[0], shape[1]),
                Strides::from_slice(&strides).unwrap(),
                0,
            )
        }
        .expect("valid F-order layout")
    }

    /// §8.2 test_try_offset_of_various — F-order [2, 3] tensor,
    /// shape=[2,3], strides=[1,2]; index [1, 2] → 1*1 + 2*2 = 5.
    #[test]
    fn test_try_offset_of_various() {
        let data = vec![1_i32, 2, 3, 4, 5, 6];
        let t = make_view_ix2(&data, [2, 3], [1, 2]);
        assert_eq!(t.try_offset_of(&[0, 0]).unwrap(), 0);
        assert_eq!(t.try_offset_of(&[1, 2]).unwrap(), 5);
        // Out-of-bounds along axis 0.
        let err = t.try_offset_of(&[2, 0]).unwrap_err();
        match err {
            XenonError::IndexOutOfBounds { axis, attempted_index, shape, .. } => {
                assert_eq!(axis, 0);
                assert_eq!(attempted_index, vec![2, 0]);
                assert_eq!(shape, vec![2, 3]);
            }
            other => panic!("expected IndexOutOfBounds, got {other:?}"),
        }
    }

    /// Rank mismatch ⇒ `DimensionMismatch`.
    #[test]
    fn test_try_offset_of_rank_mismatch() {
        let data = vec![1_i32, 2, 3, 4, 5, 6];
        let t = make_view_ix2(&data, [2, 3], [1, 2]);
        let err = t.try_offset_of(&[0]).unwrap_err();
        match err {
            XenonError::DimensionMismatch { expected, actual, .. } => {
                assert_eq!(expected, 2);
                assert_eq!(actual, 1);
            }
            other => panic!("expected DimensionMismatch, got {other:?}"),
        }
    }

    /// §8.2 test_try_offset_of_checked_overflow — checked arithmetic on
    /// `strides * index` overflow must yield `InvalidLayout { reason:
    /// AccessRangeExceedsStorage }`, never panic.
    ///
    /// **构造路径分析**：
    ///   - `validate_access_range` 结构（W8T7 Step 2 / 07-tensor.md §6.2）：
    ///       Step 1: shape.checked_size() → len
    ///       Step 2: if len == 0: 早返回 Ok(())  ← 本测试依赖这个早返回路径
    ///       Step 3: stride > isize::MAX  → StrideExceedsIsizeMax
    ///       Step 4-5: span/max_offset 计算
    ///   - shape=[3, 0] → len=0 → Step 2 早返回，**跳过 Step 3 的 isize::MAX 检查**
    ///     这让载体张量能够携带 `stride[0] = usize::MAX` 通过构造期校验。
    ///   - try_offset_of(&[2, 0]): axis 0 计算 `2 < 3 ✓ → term = usize::MAX * 2`，
    ///     **checked_mul 溢出** → InvalidLayout { reason: AccessRangeExceedsStorage }。
    ///   - axis 1 (index=0) 不参与乘法溢出，不影响测试语义。
    #[test]
    fn test_try_offset_of_checked_overflow() {
        let data = Vec::<u8>::new();  // empty storage
        // SAFETY: shape=[3,0] has product 0 → validate_access_range early-returns
        // at the len==0 gate (W8T7 Step 2), bypassing the stride>isize::MAX check.
        // The huge stride[0] propagates into the constructed view, where
        // try_offset_of will hit the checked_mul overflow path.
        let t = unsafe {
            crate::tensor::TensorView::<u8, Ix2>::from_raw_parts(
                data.as_ptr(),       // ptr: *const u8
                data.len(),          // storage_len: usize = 0
                Ix2(3, 0),           // shape: Ix2
                Strides::from_slice(&[usize::MAX, 1]).unwrap(),  // strides: Strides<Ix2>
                0,                   // offset: usize
            )
        }
        .expect("shape=[3, 0] with size=0 should pass validate_access_range's empty-tensor early-return path");

        // Now try_offset_of with index=[2, 0]:
        //   axis 0: 2 < 3 ✓ → term = usize::MAX * 2 → checked_mul OVERFLOW
        //   Expected: InvalidLayout { reason: AccessRangeExceedsStorage }
        let err = t.try_offset_of(&[2, 0]).unwrap_err();
        match err {
            XenonError::InvalidLayout { reason, .. } => {
                assert!(matches!(reason, InvalidLayoutReason::AccessRangeExceedsStorage));
            }
            other => panic!("expected InvalidLayout, got {other:?}"),
        }
    }

    /// §8.2 test_try_ptr_at_various — pointer dereference yields the
    /// element at the indexed position.
    #[test]
    fn test_try_ptr_at_various() {
        let data = vec![10_i32, 20, 30];
        // SAFETY: F-order [3] view over data.
        let t = unsafe {
            crate::tensor::TensorView::<i32, Ix1>::from_raw_parts(
                data.as_ptr(),
                data.len(),
                Ix1(3),
                Strides::from_slice(&[1]).unwrap(),
                0,
            )
        }
        .expect("valid F-order [3]");
        let ptr0 = t.try_ptr_at(&[0]).unwrap();
        let ptr1 = t.try_ptr_at(&[1]).unwrap();
        let ptr2 = t.try_ptr_at(&[2]).unwrap();
        // SAFETY: pointers borrow t for its lifetime; data outlives t.
        unsafe {
            assert_eq!(*ptr0, 10);
            assert_eq!(*ptr1, 20);
            assert_eq!(*ptr2, 30);
        }
        // Out-of-bounds propagates `IndexOutOfBounds`.
        let err = t.try_ptr_at(&[3]).unwrap_err();
        assert!(matches!(err, XenonError::IndexOutOfBounds { .. }));
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `try_offset_of` / `try_ptr_at` 实现为 `TensorBase` 的 inherent methods | `23-ffi.md` §5.13 line 1077-1161 字面 `impl TensorBase { pub fn ... }`；调用形式 `tensor.try_offset_of(&[i, j])?` |

   - 主路径返回正确 element-units offset 与正确指针值

## 注意事项

- **`offset` 起算点错误是最易出现的回归点**：`try_offset_of` 返回值必须可直接喂给 `as_ptr().add(offset)`，因此**不**加 `self.offset()`。如果未来重构需要让该函数返回相对 storage base 的位移，必须同步修改 `try_ptr_at` 改用 `as_storage_ptr().add(offset)`，并更新设计文档。
- `IndexOutOfBounds` 字段名严格按 `26-error.md` §5.1：`attempted_index` (Vec)、`axis` (usize)、`shape` (Vec)。不存在 `index` / `max` 字段。
- `InvalidLayoutReason::AccessRangeExceedsStorage` 是封闭枚举变体；不要自创 `OffsetOverflow` 或类似名字。
- 大规模 checked-arithmetic 溢出测试归属 property test（`23-ffi.md` §8.4）；本 task 单元测试覆盖主路径 + rank/bounds 两类错误变体的字段断言。完整「zeros 语义」集成测试以及 property fuzz 都推迟到 **W29T18**。
- **`from_raw_parts` 调用参数顺序**必须是 `(ptr, storage_len, shape, strides, offset)`，以符合 W8T7 Step 4 与 07-tensor.md §5.7 的权威签名。`strides` 参数是 `Strides<D>` 类型，需要通过 `Strides::from_slice(&[...]).unwrap()` 构造（设计文档 06-layout.md §5.5 已定义该 API）；**不要**直接传裸数组 `[usize::MAX, 1]`。
- **Receiver 类型必须是 `TensorView`**（即 `TensorBase<ViewRepr<'a, A>, D>` 类型别名），而非 `Tensor`（`TensorBase<Owned<A>, D>`）。`Owned` 存储不提供 `from_raw_parts` inherent method，试图调用 `Tensor::<u8, Ix2>::from_raw_parts(...)` 会触发 method not found 编译错误。
