## 实施步骤

### Step 1: 建立目标文件骨架

按 27-benchmark §5.1 和 §5.8 的 `harness = false` 模式创建或更新目标文件，保留 `--quick` 与名称 filter 入口，确保单个 bench 可独立运行。

```rust
use std::hint::black_box;
use std::time::Instant;

use xenon::prelude::*;

mod utils;
use utils::{generators, SIZES_1D, SIZES_2D};

const WARMUP_ITERATIONS: usize = 10;
const ROUNDS: usize = 10;
const ITERATIONS_PER_ROUND: usize = 100;

fn run_timed<F>(quick: bool, mut operation: F) -> u128
where
    F: FnMut(),
{
    let (rounds, iterations) = if quick { (1, 10) } else { (ROUNDS, ITERATIONS_PER_ROUND) };
    for _ in 0..WARMUP_ITERATIONS {
        operation();
    }
    let mut timings = Vec::with_capacity(rounds);
    for _round in 0..rounds {
        let started_at = Instant::now();
        for _iteration in 0..iterations {
            operation();
        }
        timings.push(started_at.elapsed().as_nanos());
    }
    timings.sort_unstable();
    timings[timings.len() / 2]
}

fn bench_sum_1d_f64(quick: bool) {
    for &size in SIZES_1D {
        let lhs = generators::sequential_1d(size);
        let median = run_timed(quick, || {
            let _result = black_box(lhs.sum());
        });
        println!("sum_1d_f64/{size}: {median} ns");
    }
}

fn bench_sum_2d_axis0(quick: bool) {
    for &(rows, cols) in SIZES_2D {
        let data = generators::sequential_2d(rows, cols);
        let median = run_timed(quick, || {
            // 13-reduction.md §5: sum_axis(axis: Axis) -> Result<...>
            let _result = black_box(data.sum_axis(Axis(0)).expect("axis 0 within rank"));
        });
        println!("sum_2d_axis0/{rows}x{cols}: {median} ns");
    }
}

fn bench_sum_2d_axis1(quick: bool) {
    for &(rows, cols) in SIZES_2D {
        let data = generators::sequential_2d(rows, cols);
        let median = run_timed(quick, || {
            // 13-reduction.md §5: sum_axis(axis: Axis) -> Result<...>
            let _result = black_box(data.sum_axis(Axis(1)).expect("axis 1 within rank"));
        });
        println!("sum_2d_axis1/{rows}x{cols}: {median} ns");
    }
}

fn bench_sum_2d_keepdims(quick: bool) {
    for &(rows, cols) in SIZES_2D {
        let data = generators::sequential_2d(rows, cols);
        let median = run_timed(quick, || {
            // 13-reduction.md §5: sum_axis_keepdims(axis: Axis) -> Result<...>
            let _result = black_box(
                data.sum_axis_keepdims(Axis(1)).expect("axis 1 within rank"),
            );
        });
        println!("sum_2d_keepdims/{rows}x{cols}: {median} ns");
    }
}

fn bench_sum_sliced(quick: bool) {
    // 27-benchmark §5.5: sum_sliced runs at Medium scale only (single row).
    // StridedFixture1D owns the F-order 2×n buffer; the view is taken per
    // iteration inside the timed loop to honor the borrow contract.
    const SLICED_SIZE: usize = 65_536;
    let fixture = generators::strided_view_1d(SLICED_SIZE);
    let median = run_timed(quick, || {
        let sliced = fixture.view();
        // 13-reduction.md §5: pub fn sum(&self) -> A — not a Result.
        let _result = black_box(sliced.sum());
    });
    println!("sum_sliced/{SLICED_SIZE}: {median} ns");
}

fn should_run(filter: Option<&str>, name: &str) -> bool {
    filter.map_or(true, |needle| name.contains(needle))
}

fn main() {
    let args = std::env::args().skip(1).collect::<Vec<_>>();
    let quick = args.iter().any(|arg| arg == "--quick");
    let filter = args.iter().find(|arg| !arg.starts_with("--")).map(String::as_str);

    let benches: &[(&str, fn(bool))] = &[
        ("sum_1d_f64", bench_sum_1d_f64),
        ("sum_2d_axis0", bench_sum_2d_axis0),
        ("sum_2d_axis1", bench_sum_2d_axis1),
        ("sum_2d_keepdims", bench_sum_2d_keepdims),
        ("sum_sliced", bench_sum_sliced),
    ];

    for &(name, func) in benches {
        if should_run(filter, name) {
            func(quick);
        }
    }
}
```

### Step 2: 覆盖 benchmark 参数矩阵

Step 1 的 `bench_*` 函数已直接遍历 `SIZES_1D` / `SIZES_2D`（与 27-benchmark §5.4.1 的 Small/Medium/Large 对齐），`sum_sliced` 固定 Medium 单档（与 §5.5 一致），并在 hot loop 内用 `std::hint::black_box` 包裹被测操作。`run_timed(quick, ...)` 的 `quick` 参数即对应 27-benchmark §5.6 / §8.1 的 quick smoke 口径。

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_filter_runs_matching_benchmark() {
        assert!(should_run(Some("sum"), "sum_1d_f64"));
        assert!(!should_run(Some("missing"), "sum_1d_f64"));
    }

    #[test]
    fn test_quick_mode_uses_single_round() {
        let mut calls = 0usize;
        let median = run_timed(true, || calls += 1);
        assert!(median <= u128::MAX);
        assert!(calls >= WARMUP_ITERATIONS + 10);
    }
}

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 使用仓库本地 `harness = false` runner，而非 Criterion 等第三方框架 | 27-benchmark §11 决策 1 要求不引入额外 benchmark 框架 |
| quick 模式保留 filter 与最小输入规模 | 27-benchmark §5.6 和 §8.1 要求 CI smoke 可快速验证 benchmark 入口 |
| benchmark 只记录性能趋势，不定义功能正确性合约 | 27-benchmark §1.1 将功能正确性边界交给 28-tests |

## 验证方式

1. 编译检查: `cargo check --benches`
2. Lint 检查: `cargo clippy --benches -- -D warnings`
3. 测试验证: `cargo bench --bench reduction -- sum_1d_f64 --quick`
4. 手动验证: 运行对应 bench 的 `--quick` filter，确认输出包含本任务的 benchmark 名称和 median ns 数值。

## 注意事项

- `black_box` 必须包裹被测结果，避免编译器消除热路径。
- benchmark 输入生成应固定、可重复，避免随机噪声污染趋势判断。
- SIMD/并行对比只在对应 feature 组合下解释性能差异，不得改变默认 API 行为。
