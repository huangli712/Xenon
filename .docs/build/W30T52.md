## 实施步骤

### Step 1: 创建 docs workflow

在 `.github/workflows/docs.yml` 中添加独立 docs workflow，覆盖 29-documentation §5.11.1 的 Gate 1-Gate 6，并保留 sealed trait 文档检查。

```yaml
name: Docs

on:
  pull_request:
  push:
    branches: [main]

jobs:
  docs:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@1.95
        with:
          components: clippy
      - name: Gate 1 — rustdoc warnings
        run: RUSTDOCFLAGS="-D warnings" cargo doc --all-features --no-deps
      - name: Gate 2 — documentation clippy lints
        run: cargo clippy --all-features -- -D clippy::missing_errors_doc -D clippy::missing_panics_doc -D clippy::missing_safety_doc
      - name: Gate 3 — doctest
        run: cargo test --doc --all-features
      - name: Gate 4 — build examples
        run: cargo build --examples --all-features
      - name: Gate 4 — run key examples (default features)
        run: |
          cargo run --example basic
          cargo run --example broadcasting
          cargo run --example workspace
          cargo run --example complex
          cargo run --example ffi
      - name: Gate 4 — run feature-gated examples
        run: |
          cargo run --example features --features parallel,simd
          cargo run --example simd --features simd
      - name: Gate 7 — std env audit (W30T50 integration)
        run: |
          set -euo pipefail
          # 源于 W30T50 Step 5 审计脚本：检查越界平台声明不得残留。
          [ -f src/lib.rs ] || { echo 'Missing src/lib.rs (W30T1 prereq incomplete)'; exit 1; }
          [ -f README.md ] || { echo 'Missing README.md (W30T3 prereq incomplete)'; exit 1; }
          [ -d examples/ ] || { echo 'Missing examples/ (W30T43-T49 prereq incomplete)'; exit 1; }
          if grep -rnPE 'no_std|nostd|\balloc(-only)?\b|wasm|webassembly|embedded|bare[-_. ]metal|freestanding' \
                  src/lib.rs README.md examples/ ; then
              echo '✗ Out-of-scope platform declarations remain'
              exit 1
          fi
          grep -q 'Xenon supports only the .std. environment' src/lib.rs \
              || { echo 'Missing std-only declaration in src/lib.rs'; exit 1; }
          echo 'OK: std env audit gate passed'
      - name: Docs — sealed trait grep
        run: |
          set -euo pipefail
          # 白名单：§5.4.3 列出的公开 sealed trait
          WHITELIST=(
            "Dimension" "Reverse"
            "Element" "Numeric" "RealScalar" "ComplexScalar" "CastElement"
            "RawStorage" "RawStorageMut" "Storage" "StorageMut" "StorageOwned" "StorageShared"
            "IsOwned" "IsView" "IsViewMut" "IsShared"
            "CastTo"
          )
          fail=0
          for name in "${WHITELIST[@]}"; do
            # 找到该 trait 的 pub trait 声明位置
            loc=$(grep -rn "pub trait ${name}\b" src/ || true)
            if [ -z "$loc" ]; then
              echo "::warning::Sealed trait ${name} not found (may be feature-gated)."
              continue
            fi
            # 检查前置 /// 块内是否包含 "# Sealed"
            file=$(echo "$loc" | head -1 | cut -d: -f1)
            line=$(echo "$loc" | head -1 | cut -d: -f2)
            start=$((line - 30))
            [ $start -lt 1 ] && start=1
            block=$(sed -n "${start},${line}p" "$file" | grep -B0 -E '^///' || true)
            if ! echo "$block" | grep -q "# Sealed"; then
              echo "::error file=$file,line=$line::Sealed trait ${name} missing '# Sealed' doc section"
              fail=1
            fi
          done
          [ $fail -eq 0 ]
      - name: Gate 5 — full clippy
        run: cargo clippy --all-features -- -D warnings
      - name: Gate 6 — compile warnings
        run: RUSTFLAGS="-D warnings" cargo check --all-features
```

### Step 2: 添加 rustdoc 与 clippy 文档门禁

设置 `RUSTDOCFLAGS="-D warnings" cargo doc --all-features --no-deps`，并加入 `missing_errors_doc`、`missing_panics_doc`、`missing_safety_doc` 的 clippy 检查。

### Step 3: 添加 doctest 与 examples 验证

执行 `cargo test --doc --all-features` 和 `cargo build --examples --all-features`。关键示例 `basic`、`broadcasting`、`workspace` 必须在 workflow 中通过 `cargo run --example ...` 实际运行。

### Step 4: 添加 sealed trait 文档检查

嵌入 29-documentation §5.5.3 的 sealed trait grep shell hook，扫描公开 sealed trait 前置 doc comment 是否包含 `# Sealed`，并将该 hook 作为 workflow step 执行。

### Step 5: 单元测试

> **强制要求**: docs workflow 是 YAML 配置，使用本地等价命令验证所有门禁。

```bash
set -euo pipefail
```

## 关键设计决策

- 公开 sealed trait 必须在自身 doc comment 中包含 `# Sealed`，但不暴露 `crate::private::Sealed` 实现细节。
- 所有 Rust doc comment、README 和 examples 使用英文，实施方案说明保持中文以匹配现有 build 文档。
- 示例优先写成可运行 doctest 或 `main() -> xenon::Result<()>`，并使用 `?` 与断言满足 29-documentation §5.6。
- 本 task 依赖只声明 W30T40（覆盖 Wave 3 的 iter/convert/format/overload，是 doctest 矩阵的代表 task）+ W30T43-W30T49（examples）。这是 PLAN.md 行 753 + SUMMARY 行 528 的共同结论。若希望严格覆盖整个 Wave 3 doctest，可在实施时扩展依赖到 W30T29-W30T42 全集；但 CI 工作流在 `cargo test --doc` 命令层面已天然覆盖所有 doctest，无需依赖图层面也声明全集。

## 验证方式

1. 编译检查: `RUSTFLAGS="-D warnings" cargo check --all-features`
2. Lint 检查: `cargo clippy --all-features -- -D warnings`
3. 文档构建: `RUSTDOCFLAGS="-D warnings" cargo doc --all-features --no-deps`
4. Doctest 验证: `cargo test --doc --all-features`
5. 示例验证: `cargo build --examples --all-features`
6. 手动验证: 打开生成的 rustdoc 或目标 Markdown，确认章节非空、链接有效、示例与任务目标一致。

## 注意事项

- workflow 不应使用 nightly-only `doc_cfg`。
- Gate 4 当前必须运行 `basic`、`broadcasting`、`workspace` 三个关键示例。
- sealed trait grep 必须检查 trait 声明之前的连续 `///` 块。
