## 实施步骤

### Step 1: Strengthen ViewMutRepr Send safety comment

Keep only the `Send` impl with `A: Send`; document that moving an exclusive mutable view transfers the unique write capability.

```rust
// SAFETY: `ViewMutRepr` represents an exclusive mutable borrow of a logical
// tensor region. Moving it to another thread transfers that exclusive access;
// it does not create aliases. Moving contained element access across threads is
// sound exactly when `A: Send`.
unsafe impl<'a, A: Send> Send for ViewMutRepr<'a, A> {}

// Intentionally no `Sync` impl: sharing `&ViewMutRepr` would share an exclusive
// write capability and violate the aliasing model described in 25-safety §5.1.
```

Assert Send for `ViewMutRepr<'_, f64>`. Represent the `!Sync` guarantee with a compile-fail doc example or the repository's existing compiletest pattern.

```rust
#[test]
fn test_view_mut_cross_thread_write() {
    let mut tensor = Tensor1::from_shape_vec([2], vec![1_i32, 2]).unwrap();
    std::thread::scope(|scope| {
        let mut view = tensor.view_mut();
        let handle = scope.spawn(move || {

        });
        handle.join().unwrap();
    });

}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| 仅实现 Send，显式不实现 Sync | `25-safety §5.1` 与 §11 决策 2 要求独占可写视图可跨线程移动但不可共享。不写 `impl Sync` 即可让编译器拒绝共享引用跨线程传递 |
| `!Sync` 由 `*mut A` 字段关闭 auto-trait + 刻意不写 `unsafe impl Sync` 共同保证 | `25-safety §5.7` mechanism 段（行 263-287）明确：(1) `ptr: *mut A` 字段使 `ViewMutRepr` 默认退出 `Send`/`Sync` auto-trait；(2) 通过 `unsafe impl<'a, A: Send> Send` 显式恢复 `Send`；(3) 故意不提供对应的 `unsafe impl Sync`，使 `!Sync` 保持。`_marker: PhantomData<&'a mut A>` 仅是 variance/dropck 标记，不是 `!Sync` 的成因（因为 `&mut T: Sync` 当 `T: Sync`，PhantomData 单独不能排除 Sync） |
| 负向 Sync 测试使用 compile_fail | `25-safety §8.7` 要求编译期验证 `ViewMutRepr` 不满足 Sync。`compile_fail` 文档测试是标准方式 |

## 验证方式

1. 编译检查: `cargo check`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test test_view_mut_send test_view_mut_cross_thread_write`
4. 手动验证: 确认普通代码无法满足 `ViewMutRepr<'_, f64>: Sync` bound。

## 注意事项

- 不要实现 `Sync`，即使内部字段看似可自动推导。
- 并行写路径必须通过独占拆分后的子视图，而不是共享同一个 `ViewMutRepr`。
- 所有 unsafe 注释使用英文 `SAFETY:`，符合代码注释规范。
