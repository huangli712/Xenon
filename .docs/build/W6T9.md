## 目标

替换 W6T3 写下的 `is_aligned_to` / `is_aligned` 占位实现。按 `06-layout §5.9` 签名采用 `*const u8`（与 `compute_layout_flags` 接收的 `ptr.cast::<u8>()` 一致）。非法 `align`（0 或非 2 的幂）返回 `false`，永不 panic（§5.9、§6.5）。

参照 `docs/design/06-layout.md §5.9`（API 定义、错误处理）、§6.5（安全性论证）。

## 实施步骤

### Step 1: Implement alignment helpers

替换 W6T3 占位体；签名严格按 `06-layout §5.9` 使用 `*const u8`。调用方在 `compute_layout_flags` 中把 `*const A` 转换为 `*const u8`（W6T11 实现），与设计文档保持单一签名口径。

```rust
/// Check whether the logical-first pointer satisfies the alignment
/// requirement (`06-layout §5.9`).
///
/// Returns `false` for `align == 0` or non-power-of-two `align`; never
/// panics. The pointer is inspected only as an integer address (modulo
/// `align`); it is **not** dereferenced, and is permitted to be dangling
/// (e.g., for empty tensors; see §6.5).
#[inline]
pub fn is_aligned_to(ptr: *const u8, align: usize) -> bool {
    if align == 0 || !align.is_power_of_two() {
        return false;
    }
    (ptr as usize) % align == 0
}

/// Check whether the logical first-element pointer is 64-byte aligned
/// (cache-line size; the minimum useful for most SIMD paths).
/// See `06-layout §5.9`.
#[inline]
pub fn is_aligned(ptr: *const u8) -> bool {
    is_aligned_to(ptr, 64)
}
```

### Step 2: 单元测试

> **强制要求**:
> - 本步骤必须包含一个或者多个单元测试。

参考 `06-layout §8.2`「`test_alignment_aligned`」、「`test_alignment_unaligned`」（均为高优先级）：

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_alignment_aligned() {
        // §8.2 high priority: 64-byte aligned allocation passes is_aligned.
        // Use `std::alloc` to obtain a guaranteed 64-byte aligned address.
        use std::alloc::{alloc, dealloc, Layout};
        let layout = Layout::from_size_align(256, 64).expect("valid layout");
        // SAFETY: layout is non-zero size with valid align.
        let ptr = unsafe { alloc(layout) };
        assert!(!ptr.is_null(), "allocator returned null");
        assert!(is_aligned(ptr));
        assert!(is_aligned_to(ptr, 64));
        assert!(is_aligned_to(ptr, 32));
        assert!(is_aligned_to(ptr, 1));
        // SAFETY: ptr was obtained from `alloc(layout)`.
        unsafe { dealloc(ptr, layout); }
    }

    #[test]
    fn test_alignment_unaligned() {
        // §8.2 high priority: a byte slice offset by 1 cannot satisfy
        // 64-byte alignment in general; also test the invalid-align guard.
        let values = [1_u8, 2, 3];
        // SAFETY: `.add(1)` stays within the allocation of `values`.
        let ptr = unsafe { values.as_ptr().add(1) };
        assert!(!is_aligned_to(ptr, 64));
        // §5.9: invalid align (0 / non-power-of-two) ⇒ false, never panic.
        assert!(!is_aligned_to(values.as_ptr(), 0));
        assert!(!is_aligned_to(values.as_ptr(), 3));
    }
}
```

## 关键设计决策

| 决策 | 依据 |
|------|------|
| `is_aligned_to` 对 `align == 0` 或非 2 的幂返回 `false` | `06-layout §5.9` 非法对齐不 panic；调用方可通过 `debug_assert` 检测 |
| `is_aligned` 默认对齐为 64 字节 | `06-layout §5.9` 缓存行大小对齐，适用于 SIMD 和内存屏障 |
| 签名采用 `*const u8`（不用泛型 `*const T`） | `06-layout §5.9` 显式定义；调用方在 `compute_layout_flags` 中用 `ptr.cast::<u8>()` 转换；保持单一签名口径 |
| 测试中先 alloc 后 free，避免泄漏 | 单元测试不应改变运行时堆状态；同时保证 ptr 在 `is_aligned` 调用期间有效 |

## 验证方式

1. 编译检查: `cargo check -p xenon`
2. Lint 检查: `cargo clippy --all-targets`
3. 测试验证: `cargo test layout::strides::tests::test_alignment_aligned`、`...test_alignment_unaligned`
4. 手动验证: 用 `std::alloc::alloc` 申请 `Layout::from_size_align(256, 64)` → ptr 必然满足 `is_aligned(ptr) == true`；栈上偏移 1 字节地址 → `false`；`align=0` → `false`。

## 注意事项

- 签名严格按设计文档 §5.9 使用 `*const u8`；上游 `compute_layout_flags`（W6T11）接收 `*const A`，必须 `ptr.cast::<u8>()` 后再传入。
- `is_aligned_to(ptr, 0)` 与 `is_aligned_to(ptr, 3)` 都返回 `false`，不计算 modulo；这保证 modulo by 0 永不发生（否则 UB）。
- 整数地址 modulo 不解引用指针；空张量传入 dangling pointer 也是合法用法（§6.5）。
- 替换 W6T3 的 placeholder 时只修改函数体；W6T1 mod.rs 的 `pub use ... is_aligned, is_aligned_to ...` 导出语句保持不变。
